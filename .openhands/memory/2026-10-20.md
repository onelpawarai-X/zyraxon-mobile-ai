
## v6.0.0 / v6.1.0 — provider connect, model loading, failover (2026-10-29)

### The bug the user kept reporting: "model selector stays empty"
Root cause found by **unzipping the shipped APK and grepping the dex**:
`dist/ZYRAXON-v5.1.0.apk` contained `ProviderCatalog: 0` and `verifyProviderKey: 0`.
The whole catalogue/verification layer was never in the shipped build — `saveProviderKey`
only wrote the key to `SharedPreferences` and nothing ever fetched a model list. So no
amount of UI work on the selector could have helped. **Lesson: when the user says a
feature "does nothing", verify what is actually inside the released artifact before
touching source.** `unzip -o apk -d /tmp/x 'classes*.dex' && strings /tmp/x/classes*.dex | grep -c Name`.

### Fixes shipped
- `fetchLiveModels()` now loads all 8 providers **in parallel** and pushes each provider's
  models through a progress callback, so the selector fills as answers arrive instead of
  waiting on the slowest (or a dead) endpoint. Before: sequential with 20s timeout each →
  blank for minutes.
- ZYRAXON's own catalogue is **public** (`catalogIsPublic = true`), so its 10 models list
  with no key; chat on that line still needs one.
- `saveProviderKey` verifies against the provider's catalogue and only says connected when
  the provider answered; failures show the provider's own words.
- Settings gained **ZYRAXON and OpenCode key rows** — both were reachable in the engine but
  had no UI field. Removed a hardcoded green "OpenCode connected" banner that was always
  green regardless of truth.
- **Failover** (`callModelWithFailover` + `failoverCandidates`): on quota/limit, retry the
  next keyed provider in `speedRank` order, each with **its own** seed model id (sending the
  primary's id elsewhere would 404). Switch is announced in chat.

  is missing"); **sudo works**, so prefix apt with `sudo`.
- Downloading the Android SDK + Gradle takes ~6 minutes total; run in the background and poll.

### Aura: the two real bugs (both in `assets/aura/aura.html`)
1. **Drifted to the top of the screen.** The stage used flex centring plus
   `body { height: 100vh }`. Android's WebView mis-measures `100vh` whenever the
   system bars change, so the orb slid up under the toolbar. Fix: absolute
   `top:50%/left:50%` + `translate(-50%,-50%)` on `.aura-stage`. Never centre a
   WebView page with `100vh` on Android.
2. **Glow looked sliced/broken.** `.atmosphere` was a 220px circle with `blur(85px)`
   inside a 360dp WebView - the blur ran past the edge and the hard boundary cut it.
   Fix: `blur(48px)` plus a radial `mask-image` that fades to transparent at 82%.
   Also removed the `@media (max-width:420px) { transform: scale(0.84) }` rule - a
   360dp WebView always matched it and the extra transform fought the centring.

`AuraWebView` used to size itself `Modifier.size(360.dp)`; it is now `fillMaxSize()`
+ `clipToBounds()` so small phones cannot clip the aura either.

### The aura is now user-tunable via CSS variables
`aura.html` reads `--aura-hue`, `--aura-size`, `--aura-glow`, `--aura-speed` on
`:root`; `AuraWebView` writes them with `evaluateJavascript("window.ZyraxonAuraLook(...)")`.
The page also gained a `ZyraxonAuraLook` bridge function. All colours are
`hsl(var(--aura-hue) ...)` now - there is **no hard-coded pink left**, which is what
makes the hue slider work. `AuraHtmlTest` asserts centring, the mask, the four
variables and the absence of `100vh`/`#ff3cac`.

The live listening/speaking pulse used to set `stage.style.transform`, which fought
the CSS centring translate; it now scales `orb.style.transform` instead.

### UI is white glass now (`ui/theme/Glass.kt`)
The panels were `Color(0xD90B0A1E)` (near-opaque black). New `Glass` object:
`fill(alpha)` = white at the user's alpha, `sheetFill`, `rowFill`, plus near-black
text tokens (`textPrimary` `0xFF0A0C14`) and dark accents readable on white.
`panelAlpha` is a ViewModel setting (default 0.22, range 0.06-0.6). Every component
was swept: ZyraxonApp, ChatPanels, Sheets, ChatComponents, CodePanel, PermissionPanel.

কেন্দ্রীয় সিক্রেট নেই, তাই ফাঁস বা revoke করার কিছু নেই। টোকেন মেয়াদের আগেই refresh হয়।

**টুল নাম:** `<serverId>__<tool>` (দুই আন্ডারস্কোর)। দুই সার্ভারে একই নামের টুল থাকলে সংঘর্ষ হয় না।
`mcp_connect` / `mcp_list` / `mcp_disconnect` — এজেন্ট নিজেই সার্ভার সামলাতে পারে।

**যাচাই:** আসল GitHub MCP → 46 টুল; আসল `get_file_contents` কল সফল। Cloudflare ও Supabase
authorize → HTTP 200। ১২টি নতুন টেস্ট আসল HTTP সার্ভারের বিরুদ্ধে (JSON-RPC, SSE framing,
session-id echo, 401)। PKCE RFC 7636 ভেক্টর মিলিয়ে দেখা। মোট ৩৬ টেস্ট, ০ ব্যর্থ।
