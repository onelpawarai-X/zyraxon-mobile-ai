ક્લાઉડ, નેટવર્ક, મોડલ અને સહાયકો
## ક્લાઉડ અને ઇન્ટરનેટ
- `web_search` (નેટવર્ક): વાસ્તવિક વેબ પર શોધો. `read_url` (નેટવર્ક): ટેક્સ્ટ તરીકે પેજ મેળવો. `http_request` (નેટવર્ક): હેડર અને બોડી સાથે કોઈપણ HTTP કૉલ (GET, POST, PUT, PATCH, DELETE) `verify_url` (નેટવર્ક): એક લિંક ખરેખર અસ્તિત્વમાં છે તે તપાસો અને સાચું સ્ટેટસ મેળવો. `download_file` (વ્યક્તિગત, નેટવર્ક): ફાઇલમાં URL ડાઉનલોડ કરો.
- જ્યારે તમે તેને પૂછો ત્યારે જ એજન્ટ લિંક ખોલે છે.
- AI મોડલ્સ તમે ઉમેરેલા પ્રદાતાઓ દ્વારા ક્લાઉડમાં ચાલે છે (ZYRAXON, ZYRAXON Apex ક્લાઉડ એજન્ટ, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode). મોડેલ સૂચિ લાઇવ લોડ થાય છે અને દરેક પ્રદાતાના જવાબો મુજબ ભરાય છે.
- બિલ્ડ, પ્રકાશિત અને પુલ વિનંતીઓ GitHub અને Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git`).
- "ઓન-ડિવાઈસ" (ઓટોમેશન સેટિંગ્સ) પર સ્વિચ કરો અને કોઈ ક્લાઉડ કૉલ બિલકુલ કરવામાં આવતો નથી: કોઈ પ્રદાતા, કોઈ વેબ, કોઈ અપલોડ નથી.

## MCP સર્વર્સ
MCP બહારની સેવાઓને એજન્ટને વધારાના સાધનો આપવા દે છે. Canva, Cloudflare, Supabase, GitHub અથવા તમારા પોતાના સર્વરને તેના સરનામા (વૈકલ્પિક ટોકન) દ્વારા કનેક્ટ કરો. કનેક્ટેડ સર્વરના ટૂલ્સ એજન્ટની ટૂલ લિસ્ટમાં `server__tool` તરીકે જોડાય છે.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (જુઓ શું જોડાયેલ છે અને કયા સાધનો અસ્તિત્વમાં છે), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (ફેરફારો માટે સંસાધન જુઓ), `mcp_complete` (સ્વતઃપૂર્ણ દલીલો), `mcp_ping`, `mcp_log_level`. તેમના કૉલ્સ નેટવર્ક કૉલ્સ છે, અને અજાણ્યા MCP સાધનો મૂળભૂત રીતે પરવાનગી માંગે છે.
- MCP સ્ક્રીન દરેક સર્વરને કનેક્ટેડ સ્ટેટસ, તેના ટૂલ્સ, સંસાધનો અને પ્રોમ્પ્ટ ટેમ્પ્લેટ્સ અને ઉમેરો, ડિસ્કનેક્ટ, દૂર કરો, મંજૂરી આપો બટનો સાથે સૂચિબદ્ધ કરે છે.

## સબ-એજન્ટ્સ
`sub_agent` (સિસ્ટમ): બેકગ્રાઉન્ડમાં ચાલતા હેલ્પર એજન્ટોને મોટા કામના ભાગો. ક્રિયાઓ: સ્પાન, સ્થિતિ, સૂચિ, પરિણામ, સંદેશ, રોકો, રાહ જુઓ. દરેક તેના પોતાના મોડેલનો ઉપયોગ કરી શકે છે. એજન્ટ "થઈ ગયું" કહેતા પહેલા તેમના પરિણામો ભેગા કરે છે અને તપાસે છે.

## ઉપકરણ પરનું મોડેલ
`on_device_model` (સિસ્ટમ): ઈન્ટરનેટ વિના ફોન પર રહેતું ભાષા મોડેલ સૂચિબદ્ધ કરો, લોડ કરો અને ચલાવો. સેટિંગ્સ → મોડલ અને ઓળખ → ઉપકરણ પર તમે મોડલ ડાઉનલોડ કરો છો (નાનાથી મોટા: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B…); Hugging Face ટોકન વૈકલ્પિક છે અને ફક્ત ગેટેડ ફાઇલો માટે જ જરૂરી છે. લોડ થયેલ મોડેલને યાદ કરવામાં આવે છે અને લોંચ સમયે ફરીથી લોડ કરવામાં આવે છે.

## મેસેજિંગ ચેનલો
`channel_post` (સિસ્ટમ) ખુલે છે Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail અથવા તમારા ટેક્સ્ટ તૈયાર સાથે SMS. તમે તમારી જાતને મોકલો દબાવો.
