મુશ્કેલીનિવારણ
- કોઈ જવાબ નથી: તમારી ઇન્ટરનેટ અને API કી તપાસો (સેટિંગ્સ → પ્રદાતાઓ અને API વાસ્તવિક ભૂલ બતાવે છે). અન્ય મૉડલ અથવા ઑન-ડિવાઈસ મૉડલ અજમાવી જુઓ.
- માઇક્રોફોન કંઈ કરતું નથી: માઇક્રોફોનને પરવાનગી આપો; "માઇક ચાલુ રાખો" તપાસો; ઓળખની ભાષા તપાસો.
- ZYRAXON પોતે સાંભળે છે: આ ટેક્સ્ટ દ્વારા ફિલ્ટર કરવામાં આવે છે; જો તે હજુ પણ થાય, તો વોલ્યુમ ઓછું કરો અથવા હેડફોનનો ઉપયોગ કરો.
- વાક્ય બે વાર દેખાય છે: વર્તમાન સંસ્કરણોમાં નિશ્ચિત; એપ્લિકેશન અપડેટ કરો.
- તે સ્ક્રીનને ટેપ અથવા વાંચશે નહીં: ઍક્સેસિબિલિટી સેવા પર સ્વિચ કરો (સેટિંગ્સ → પરવાનગીઓ).
- તે પૃષ્ઠભૂમિમાં અટકે છે: સૂચનાઓ અને બેટરી ઓપ્ટિમાઇઝેશન મુક્તિને મંજૂરી આપો; તરતી આંખ માટે ઓવરલે.
- એક સાધન પરવાનગી માંગવાનું ચાલુ રાખે છે: સેટિંગ્સ → ઓટોમેશનમાં સ્તર બદલો, અથવા કાર્ડનો જવાબ આપો.
- Play Protect કંઈક અવરોધે છે: પરવાનગી પ્રકરણ જુઓ, અથવા એજન્ટને પગલાંઓનું માર્ગદર્શન કરવા દો.
- ટર્મિનલ અથવા Linux શરૂ થતું નથી: એપ્લિકેશન શરૂ થવા પર પ્રથમ વખત અનપૅક થવાની રાહ જુઓ; મફત સંગ્રહ તપાસો.
- અપડેટ ઇન્સ્ટોલ થશે નહીં: ઇન્સ્ટોલ સ્ત્રોત તરીકે ZYRAXON ને મંજૂરી આપો.
- પ્રકાશિત કરી શકાતું નથી: GitHub માટે GitHub ટોકન ઉમેરો; સાર્વજનિક લિંક માટે એજન્ટ ટનલનો ઉપયોગ કરી શકે છે.
- એક પ્રકરણ અંગ્રેજી બતાવે છે: તે પ્રકરણમાં આ બિલ્ડમાં તમારી ભાષામાં કોઈ ટેક્સ્ટ નથી; એપ્લિકેશન અપડેટ કરો.
- કંઈક વિચિત્ર: સ્વચ્છ શરૂ કરવા માટે સેટિંગ્સ → નેવિગેશન → નવા સત્રનો ઉપયોગ કરો (તે ફક્ત ચેટ ઇતિહાસને સાફ કરે છે; મેમરી રહે છે).
