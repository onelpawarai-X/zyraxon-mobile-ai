દરેક સેટિંગ્સ સ્ક્રીન, એક પછી એક
સેટિંગ્સમાં આઠ વિભાગો છે. દરેક વિભાગમાં તેની પેટા-સ્ક્રીન માટે ગોળીઓ છે. તમે ઉપયોગ કરેલો છેલ્લો વિભાગ આગલી વખતે ફરીથી ખોલવામાં આવશે.

## 1. ભાષા અને અનુવાદ → એપ્લિકેશન અને સાધનની ભાષા
સમગ્ર એપ્લિકેશન અને એજન્ટના ટૂલ સંદેશાઓની ભાષા પસંદ કરો. સૂચિ શોધો અને એક પર ટેપ કરો. સ્ક્રીન વર્તમાન ભાષા અને UI અનુવાદ અને સાધન-સંદેશ અનુવાદ ચાલુ છે કે કેમ તે બતાવે છે. 60 ભાષાઓ ઉપલબ્ધ છે. ભાષા પ્રકરણ જુઓ.

## 2. વૉઇસ અને માઇક
- વૉઇસ પ્રોફાઇલ: સ્ત્રી અથવા પુરુષ વૉઇસ, સ્પીડ, પિચ, "જવાબ મોટેથી વાંચો", ટેસ્ટ વૉઇસ, બંગાળી વૉઇસ ડાઉનલોડ સંકેત પસંદ કરો.
- માઇક અને ભાષા: ઓળખની ભાષા, માઇક ચાલુ રાખો, જ્યારે તમે બોલવાનું બંધ કરો ત્યારે સ્વતઃ મોકલો.
- લાઇવ વૉઇસ: સ્પીચ-ટુ-સ્પીચ ઑન/ઑફ, સ્ટેટસ, રીઅલટાઇમ મૉડલ્સની સૂચિ.

## 3. પ્રદાતાઓ અને API
- AI પ્રદાતાઓ: તમારી પોતાની API કી (ZYRAXON, OpenCode ફ્રી ક્વોટા, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter) અને ZYRAXON Apex ક્લાઉડ એજન્ટ. સાચવેલી કી પ્રદાતાની વાસ્તવિક સૂચિ વાંચીને ચકાસવામાં આવે છે અને મોડેલની સંખ્યા અથવા ચોક્કસ ભૂલ બતાવે છે. એક બટન ZYRAXON વેબસાઇટ ખોલે છે જ્યાં તમે કી બનાવો છો.
- GitHub: પ્રકાશન માટે તમારું GitHub એક્સેસ ટોકન (રેપો સ્કોપની જરૂર છે), Git પુશ અને પુલ વિનંતીઓ. ટોકન સાચવો અથવા તેને કાઢી નાખો; સ્થિતિ બતાવે છે કે તે સેટ છે.

## 4. અપડેટ્સ → એપ્લિકેશન અપડેટ
વર્તમાન સંસ્કરણ બતાવે છે, નવી રિલીઝ માટે તપાસે છે, તેને પ્રોગ્રેસ બાર વડે ડાઉનલોડ કરે છે અને તેને ઇન્સ્ટોલ કરે છે. તમારી ચેટ્સ, મેમરી અને સેટિંગ્સ રહે છે. જો Android ને ઇન્સ્ટોલ કરવા માટે પરવાનગીની જરૂર હોય, તો એક બટન તે સેટિંગ ખોલે છે.

## 5. મોડલ અને ઓળખ
- ઓળખ: પાત્ર પસંદ કરો (પાત્ર પ્રકરણ જુઓ).
- મોડલ: શોધ બોક્સ, "બધા મોડલ્સ" અને "કસ્ટમ" ફિલ્ટર્સ સાથે લાઇવ મોડલ કેટલોગ; ઝડપી મોડેલો પ્રથમ.
- ઉપકરણ પર: ઑફલાઇન ચાલતા મોડલ ડાઉનલોડ કરો, લોડ કરો અને અનલોડ કરો; નાનાથી મોટા ક્રમાંકિત; વૈકલ્પિક Hugging Face ટોકન; લોડ થયેલ, લોડીંગ અને નિષ્ફળ સ્થિતિઓ દર્શાવે છે.

## 6. ઓરા અને થીમ
- થીમ: હોરર, ડાર્ક અથવા લાઇટ.
- ઓરા અને બેકગ્રાઉન્ડ: ઓરા શૈલી અને રંગ (લોહી, ગુલાબી, વાયોલેટ, આકાશ, લીલો, અગ્નિ) દંડ રંગ નિયંત્રણ સાથે; ઓરા કદ, ગ્લો સ્ટ્રેન્થ, રોટેશન સ્પીડ, પેનલ પારદર્શિતા; તરતી આંખ (ચાલુ/બંધ, ડિઝાઇન, સ્ક્રીન એજ, વૉઇસ કમાન્ડ/વેક શબ્દો, તમારા પોતાના ઉમેરો); શેડર મોડ; કસ્ટમ પૃષ્ઠભૂમિ URL (mp4, gif અથવા છબી); એનિમેશન ઝડપ.

## 7. સુરક્ષા અને ગોપનીયતા
- એપ લોક: પાસવર્ડ (4-8 અંક) અથવા 3×3 ડોટ પેટર્ન; તેને બે વાર દાખલ કરીને પુષ્ટિ કરો; લોક દૂર કરો.
- પરવાનગીઓ: Play Protect ની મદદ સાથે પરવાનગી પ્રકરણમાં સૂચિ.
- ગોપનીયતા અને ડેટા: તમામ ડેટા ફોન પર રહે છે. બટનો: બધી મેમરી કાઢી નાખો, ચેટ ઇતિહાસ કાઢી નાખો, GitHub ટોકન કાઢી નાખો.

## 8. સિસ્ટમ
આ વિભાગમાં બટનોની પોતાની પંક્તિ છે જે બાજુમાં સ્ક્રોલ કરે છે, તેથી કંઈપણ સ્ક્વિઝ થતું નથી.
- ઓટોમેશન: મંજૂરી સ્તર અને ફક્ત ઉપકરણ પર (મંજૂરી સ્તર જુઓ).
- નેવિગેશન: જવા માટેના ક્ષેત્રોની સૂચિ — "ટોચ પર કોઈ બટન નથી, બધું અહીં છે" — ⌘ ZX સિસ્ટમ શેલ, "નવું સત્ર" બટન (સ્વચ્છ શરૂઆત માટે ચેટ ઇતિહાસ ભૂંસી નાખે છે), સંદેશની સંખ્યા અને માઇક ટૉગલ સહિત.
- મેમરી: હકીકતો સાથેની સ્થાનિક SQL મેમરી ZYRAXON યાદ રાખે છે; કી અને મૂલ્ય ઉમેરો; બધા કાઢી નાખો.
- કૌશલ્ય માર્ગદર્શિકા: ઉદાહરણની ક્ષમતાઓ (મેસેજિંગ એપ્લિકેશન્સ, વેબસાઇટ બિલ્ડીંગ, સ્ક્રીન રીડર, ટોર્ચ, કેમેરા, Wi-Fi અને સેટિંગ્સ) ઉદાહરણ શબ્દસમૂહો સાથે ઝડપી સૂચિ.
- ઓટોમેશન હબ: કૌશલ્ય, ઓટોપાયલટ, પૈસા, સમયરેખા, મગજ અને કોલ એજન્ટ એક જ જગ્યાએ (ઓટોમેશન હબ જુઓ).

## 9. દસ્તાવેજીકરણ
સેટિંગ્સમાં તેનો પોતાનો વિભાગ, સિસ્ટમથી અલગ. આ માર્ગદર્શિકા: એકવીસ પ્રકરણો, શોધ બોક્સ અને ભાષા ચિપ પંક્તિ. એપ્લિકેશનની દરેક ભાષા પહેલેથી જ એપ્લિકેશનની અંદર સંપૂર્ણ રીતે લખેલી છે - તમારા ફોન પર કંઈપણ અનુવાદિત નથી અને તેને વાંચવા માટે કોઈ ઇન્ટરનેટની જરૂર નથી.
