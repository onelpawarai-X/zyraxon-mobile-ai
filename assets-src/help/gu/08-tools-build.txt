બિલ્ડીંગ: સાઇટ્સ, એપ્લિકેશન્સ, પૂર્વાવલોકન અને પ્રકાશન
## કેવી રીતે પૂછવું
- "મારી કોફી શોપ માટે મને એક લેન્ડિંગ પેજ બનાવો." એજન્ટ તેને તરત જ બનાવે છે, તેને તમારા ફોન પર શરૂ કરે છે અને તેને પૂર્વાવલોકનમાં ખોલે છે. તમને તેનું વર્ણન કરતી 2-3 પંક્તિઓ મળે છે. જ્યાં સુધી તમે પૂછો નહીં ત્યાં સુધી કંઈપણ પ્રકાશિત થતું નથી.
- "ટૂ-ડૂ એપ્લિકેશન બનાવો." એક સમજદાર સ્ટેક સાથે સીધું બિલ્ટ, ચલાવો અને બતાવવામાં આવે છે. જો તમે પૂછો તો જ બેક એન્ડ, ડેટાબેઝ અથવા લોગિન.
- "એક પૂર્ણ-સ્ટેક એપ્લિકેશન બનાવો." એજન્ટ સૌપ્રથમ બેક-એન્ડ લેંગ્વેજ, ડેટાબેઝ, લોગિન અને તે ક્યાં ચાલે છે તે વિશે, ભલામણ કરેલ ડિફોલ્ટ્સ સાથે એક નાનો પ્રશ્ન પૂછે છે, પછી તે બધાને બીજ ડેટા સાથે બનાવે છે અને એક સંપૂર્ણ પ્રવાહનું પરીક્ષણ કરે છે.
- "એક Windows/ZYRAXON OS/macOS/Android પ્રોગ્રામ બનાવો." સોર્સ લખવામાં આવે છે, બિલ્ડ વર્કફ્લો ઉમેરવામાં આવે છે, તેને GitHub ક્રિયાઓ સાથે ક્લાઉડમાં પુશ અને બિલ્ટ કરવામાં આવે છે અને તમને વાસ્તવિક ડાઉનલોડ લિંક મળે છે.

## સાધનો
- `edit_file` અને `write_file`: વાસ્તવિક ફાઇલો લખો (સંપૂર્ણ કોડ, ક્યારેય સ્ટબ નહીં). `code_box` તેમને જીવંત બતાવે છે.
- `preview` (સલામત): બિલ્ટ-ઇન વાસ્તવિક બ્રાઉઝર. ક્રિયાઓ: ખોલો (એક લિંક, `localhost:PORT` અથવા ફાઇલ), ફરીથી લોડ કરો, પાછળ, આગળ, સ્ક્રીનશૉટ, સ્ક્રોલ કરો, ક્લિક કરો, ટાઇપ કરો, પૃષ્ઠ ટેક્સ્ટ વાંચો, કન્સોલ ભૂલો, ઇવેલ. એજન્ટ કહે તે પહેલા તેનું પોતાનું કામ જુએ છે.
- `serve_local` (સિસ્ટમ): ફોલ્ડર માટે ફોન પર વેબ સર્વર શરૂ કરે છે અને તમારા Wi-Fi પરના અન્ય ઉપકરણો ખોલી શકે છે તે LAN સરનામું પરત કરે છે.
- `publish_website` (સિસ્ટમ): ફોનથી સાર્વજનિક પોર્ટ પર સાઇટ સેવા આપે છે. `publish_cloudflare` (સિસ્ટમ): Cloudflare ટનલ દ્વારા કોઈ એકાઉન્ટ વિનાની સાઇટ ઇન્ટરનેટ પર મૂકે છે અને જાહેર https લિંક પરત કરે છે. `publish_github` (સિસ્ટમ): તમારા ટોકન સાથે GitHub રિપોઝીટરી (પૃષ્ઠો) પર પ્રોજેક્ટ પ્રકાશિત કરે છે.
- `git` (સિસ્ટમ): તમારા સાચવેલા ટોકન સાથે ક્લોન, ઇનિટ, સ્ટેટસ, એડ, કમિટ, પુશ, પુલ, બ્રાન્ચ, ચેકઆઉટ, લોગ, ડિફ. `github_pr` (સિસ્ટમ): પુલ વિનંતીઓ બનાવો, સૂચિબદ્ધ કરો, મર્જ કરો અને ટિપ્પણી કરો. `github_actions` (સિસ્ટમ): વર્કફ્લોની સૂચિ બનાવો, તેમને ચલાવો, મતદાન ચલાવો અને લોગ વાંચો, તેથી બિલ્ડ્સ ફોનમાંથી ક્લાઉડમાં ચાલે છે.
- `build_app` (સિસ્ટમ): ફોન પર ગ્રેડલ સાથે આ પ્રોજેક્ટ બનાવે છે અને પરિણામ ઇન્સ્ટોલ કરે છે.
- `files_panel`, `todo_write`: ફાઇલ બ્રાઉઝર અને ટાસ્ક બોર્ડ.

## ગુણવત્તાના નિયમો એજન્ટ અનુસરે છે
સંપૂર્ણ લેઆઉટ, રિસ્પોન્સિવ ડિઝાઇન, વર્કિંગ JavaScript, એનિમેશન, સુસંગત રંગો અને ફોન્ટ્સ (જ્યાં તે બંધબેસે છે ત્યાં ડાર્ક અને લાઇટ), સામાન્ય ટેમ્પલેટ નહીં. લેન્ડિંગ પેજ સામાન્ય રીતે 300-900 લીટીઓનું હોય છે; મોટી વસ્તુઓ વધુ.

## જો કંઈક તૂટેલું દેખાય છે
પ્રીવ્યૂમાં ફિક્સ દબાવો અથવા એજન્ટને કહો. તે કન્સોલ વાંચે છે, કારણ સુધારે છે, પૃષ્ઠ ફરીથી ખોલે છે અને ફરીથી તપાસે છે.
