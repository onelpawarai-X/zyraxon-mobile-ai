Ξεκινώντας
Ο ZYRAXON είναι ένας βοηθός που ζει μέσα στο τηλέφωνο Android σας. Μιλάει μαζί σας, σας ακούει και μπορεί να κάνει πραγματική δουλειά: ανοίγει εφαρμογές, αγγίζει και πληκτρολογεί στην οθόνη, καλεί άτομα, γράφει αρχεία, δημιουργεί ιστοτόπους και εφαρμογές, εκτελεί ένα σύστημα ZYRAXON OS, δημιουργεί εικόνες, ήχο, βίντεο και έγγραφα γραφείου και σε θυμάται για μήνες. Λειτουργεί σε οποιαδήποτε γλώσσα μιλάτε.

## Τα πρώτα λεπτά
- Κατά την πρώτη εκκίνηση ZYRAXON δείχνει μια σύντομη ειδοποίηση ότι ο πράκτορας μπορεί να ενεργήσει στο τηλέφωνό σας μόνος του. Πατήστε "Το κατάλαβα, ξεκινήστε" για να συνεχίσετε.
- Προσθέστε ένα κλειδί AI (Ρυθμίσεις → Πάροχοι & API → πάροχοι τεχνητής νοημοσύνης). Επικολλήστε ένα κλειδί για κάθε πάροχο που σας αρέσει (ZYRAXON, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode). Όταν αποθηκεύετε ένα κλειδί, η εφαρμογή διαβάζει τον κατάλογο αυτού του παρόχου και τον ελέγχει για πραγματικό, ώστε να βλέπετε ένα πραγματικό "συνδεδεμένο" και τον αριθμό των μοντέλων.
- Δεν υπάρχει κλειδί; Μπορείτε ακόμα να χρησιμοποιήσετε τα μοντέλα της συσκευής (Ρυθμίσεις → Μοντέλο και ταυτότητα → Στη συσκευή). Τρέχουν στο τηλέφωνο χωρίς internet.
- Επιλέξτε ένα μοντέλο με το κουμπί μοντέλου στη γραμμή μηνυμάτων και έναν χαρακτήρα (Ρυθμίσεις → Μοντέλο και ταυτότητα → Ταυτότητα).
- Εκχωρήστε δικαιώματα όταν ένα χαρακτηριστικό χρειάζεται (δείτε το κεφάλαιο Δικαιώματα). Ο πράκτορας μπορεί επίσης να ανοίξει το παράθυρο διαλόγου άδειας για εσάς με ένα πάτημα.
- Απλώς μιλήστε ή πληκτρολογήστε. "Φτιάξε μου μια σελίδα προορισμού για το αρτοποιείο μου", "άνοιξε YouTube και παίξε ένα τραγούδι", "τι είναι η μπαταρία μου;", "καλέστε τη μαμά".

## Οι δύο τρόποι εργασίας
Δίπλα στο πλαίσιο μηνύματος υπάρχει ένα κουμπί λειτουργίας με δύο λειτουργίες: Agent και Build. Δείτε το κεφάλαιο Λειτουργίες.

## Εκεί που είναι τα πράγματα
- Αριστερό μενού: οι συνομιλίες σας, νέα συνομιλία, μετονομασία, διαγραφή και ο διακόπτης θέματος.
- Οθόνη συνομιλίας: μηνύματα, πίνακας εργασιών, λίστα εργαλείων, αρχεία, τερματικό.
- Πίνακες προεπισκόπησης και κώδικα: δείτε και επεξεργαστείτε τι δημιουργεί ο πράκτορας.
- Ρυθμίσεις: οκτώ ενότητες, που καλύπτονται μία προς μία σε αυτήν την τεκμηρίωση.
- Αυτή η τεκμηρίωση: Ρυθμίσεις → Τεκμηρίωση (βρίσκεστε εδώ).
