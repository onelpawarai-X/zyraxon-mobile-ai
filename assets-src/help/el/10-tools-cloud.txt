Cloud, δίκτυο, μοντέλα και βοηθοί
## Σύννεφο και Διαδίκτυο
- `web_search` (δίκτυο): αναζήτηση στον πραγματικό ιστό. `read_url` (δίκτυο): λήψη μιας σελίδας ως κείμενο. `http_request` (δίκτυο): οποιαδήποτε κλήση HTTP (GET, POST, PUT, PATCH, DELETE) με κεφαλίδες και σώμα. `verify_url` (δίκτυο): ελέγξτε ότι ένας σύνδεσμος υπάρχει πραγματικά και λάβετε την πραγματική κατάσταση. `download_file` (Προσωπικό, δίκτυο): λήψη μιας διεύθυνσης URL σε ένα αρχείο.
- Ο πράκτορας ανοίγει συνδέσμους μόνο όταν του το ζητήσετε.
- Τα μοντέλα τεχνητής νοημοσύνης εκτελούνται στο cloud μέσω των παρόχων που προσθέσατε (ZYRAXON, ZYRAXON Apex cloud agent, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode. Η λίστα μοντέλων φορτώνεται ζωντανά και συμπληρώνεται καθώς απαντά κάθε πάροχος.
- Τα αιτήματα δημιουργίας, δημοσίευσης και έλξης εκτελούνται μέσω GitHub και Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git`).
- Ενεργοποιήστε το "μόνο στη συσκευή" (Ρυθμίσεις αυτοματισμού) και δεν πραγματοποιείται καθόλου κλήση στο cloud: χωρίς πάροχο, χωρίς web, χωρίς μεταφόρτωση.

## MCP διακομιστές
Το MCP επιτρέπει σε εξωτερικές υπηρεσίες να παρέχουν στον πράκτορα επιπλέον εργαλεία. Συνδέστε τα Canva, Cloudflare, Supabase, GitHub ή τον δικό σας διακομιστή μέσω της διεύθυνσής του (προαιρετικό διακριτικό). Τα εργαλεία συνδεδεμένων διακομιστών εντάσσονται στη λίστα εργαλείων του πράκτορα ως `server__tool`.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (δείτε τι είναι συνδεδεμένο και ποια εργαλεία υπάρχουν), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (παρακολουθήστε έναν πόρο για αλλαγές), `mcp_complete` (αυτόματη συμπλήρωση ορισμάτων), `mcp_ping`, `mcp_log_level`. Οι κλήσεις τους είναι κλήσεις δικτύου και τα άγνωστα MCP εργαλεία ζητούν άδεια από προεπιλογή.
- Η οθόνη MCP παραθέτει κάθε διακομιστή με κατάσταση Συνδεδεμένος, τα εργαλεία, τους πόρους και τα πρότυπα προτροπής και τα κουμπιά Προσθήκη, Αποσύνδεση, Κατάργηση, Αποδοχή.

## Υποπράκτορες
`sub_agent` (Σύστημα): παραδώστε μέρη μιας μεγάλης δουλειάς σε βοηθούς πράκτορες που τρέχουν στο παρασκήνιο. Ενέργειες: αναπαραγωγή, κατάσταση, λίστα, αποτέλεσμα, μήνυμα, διακοπή, αναμονή. Το καθένα μπορεί να χρησιμοποιήσει το δικό του μοντέλο. Ο πράκτορας συνδυάζει και ελέγχει τα αποτελέσματά τους πριν πει "έγινε".

## Μοντέλο στη συσκευή
`on_device_model` (Σύστημα): λίστα, φόρτωση και εκτέλεση ενός μοντέλου γλώσσας που λειτουργεί στο τηλέφωνο, χωρίς internet. Στις Ρυθμίσεις → Μοντέλο και ταυτότητα → Στη συσκευή πραγματοποιείτε λήψη μοντέλων (μικρό έως μεγάλο: FunctionGemma 270M, Qwen3 0,6B, Gemma 4 E2B…); ένα διακριτικό Hugging Face είναι προαιρετικό και απαιτείται μόνο για αρχεία με κλειστό χώρο. Ένα φορτωμένο μοντέλο απομνημονεύεται και επαναφορτώνεται κατά την εκκίνηση.

## Κανάλια ανταλλαγής μηνυμάτων
Το `channel_post` (Σύστημα) ανοίγει τα Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail ή SMS με το κείμενό σας έτοιμο. Πατάς αποστολή μόνος σου.
