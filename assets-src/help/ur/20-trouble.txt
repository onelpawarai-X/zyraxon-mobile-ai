خرابی کا سراغ لگانا
- کوئی جواب نہیں: اپنا انٹرنیٹ اور API کلید چیک کریں (ترتیبات → فراہم کنندگان اور API اصل غلطی کو ظاہر کرتا ہے)۔ کوئی دوسرا ماڈل یا آن ڈیوائس ماڈل آزمائیں۔
- مائیکروفون کچھ نہیں کرتا: مائیکروفون کی اجازت دیں؛ چیک کریں "مائیک آن رکھیں"؛ شناختی زبان چیک کریں۔
- ZYRAXON خود سنتا ہے: یہ متن کے ذریعہ فلٹر کیا جاتا ہے۔ اگر یہ اب بھی ہوتا ہے، تو والیوم کم کریں یا ہیڈ فون استعمال کریں۔
- ایک جملہ دو بار ظاہر ہوتا ہے: موجودہ ورژن میں طے شدہ؛ ایپ کو اپ ڈیٹ کریں۔
- یہ اسکرین کو ٹیپ نہیں کرے گا اور نہ ہی پڑھے گا: ایکسیسبیلٹی سروس پر سوئچ کریں (ترتیبات → اجازتیں)۔
- یہ پس منظر میں رک جاتا ہے: اطلاعات اور بیٹری آپٹیمائزیشن کی چھوٹ کی اجازت دیں؛ تیرتی آنکھ کے لیے اوورلے
- ایک ٹول اجازت مانگتا رہتا ہے: سیٹنگز → آٹومیشن میں لیول تبدیل کریں، یا کارڈ کا جواب دیں۔
- Play Protect کسی چیز کو روکتا ہے: اجازتوں کا باب دیکھیں، یا ایجنٹ کو اقدامات کی رہنمائی کرنے دیں۔
- ٹرمینل یا ZYRAXON OS شروع نہیں ہوتا ہے: ایپ شروع ہونے پر پہلی بار پیک کھولنے کا انتظار کریں۔ مفت اسٹوریج چیک کریں۔
- اپ ڈیٹ انسٹال نہیں ہوگا: اجازت دیں ZYRAXON کو بطور انسٹال ماخذ۔
- شائع نہیں کیا جا سکتا: GitHub کے لیے GitHub ٹوکن شامل کریں؛ عوامی لنک کے لیے ایجنٹ ایک سرنگ استعمال کر سکتا ہے۔
- ایک باب انگریزی کو ظاہر کرتا ہے: اس باب میں اس تعمیر میں آپ کی زبان میں کوئی متن نہیں ہے۔ ایپ کو اپ ڈیٹ کریں۔
- کچھ عجیب: کلین شروع کرنے کے لیے سیٹنگز → نیویگیشن → نیا سیشن استعمال کریں (یہ صرف چیٹ کی سرگزشت کو صاف کرتا ہے؛ میموری برقرار رہتی ہے)۔
