每個設定畫面一一對應
設置有八個部分。每個部分的子螢幕都有藥丸。您上次使用的部分下次將重新開啟。

## 1. 語言和翻譯 → 應用程式和工具語言
選擇整個應用程式和代理工具訊息的語言。搜尋列表並點擊其中一項。螢幕顯示目前語言以及 UI 翻譯和工具訊息翻譯是否開啟。有 60 種語言可供選擇。請參閱語言章節。

## 2. 語音和麥克風
- 語音設定檔：選擇女聲或男聲、速度、音調、「大聲朗讀答案」、測試語音、孟加拉語語音下載提示。
- 麥克風和語言：辨識語言，保持麥克風打開，停止說話時自動發送。
- 即時語音：語音到語音開/關、狀態、即時模型清單。

## 3. 提供者和 API
- AI 供應商：您自己的 API 金鑰（ZYRAXON、OpenCode 免費配額、Groq、Gemini、OpenAI、Grok、Claude、DeepSeek、OpenRouter）和 ZYRAXON Apex 雲端代理。保存的密鑰透過讀取提供者的真實目錄進行驗證，並顯示模型計數或確切的錯誤。按鈕可開啟您在其中建立金鑰的 ZYRAXON 網站。
- GitHub：您的 GitHub 存取權杖（需要儲存庫範圍）用於發布、Git 推送和拉取請求。儲存或刪除token；狀態顯示是否已設定。

## 4.更新→應用程式更新
顯示目前版本，檢查是否有較新版本，使用進度條下載並安裝。您的聊天記錄、記憶體和設定都會保留。如果 Android 需要安裝權限，則會有一個按鈕開啟該設定。

## 5. 型號及標識
- 身份：選擇角色（參見角色章節）。
- 模型：帶有搜尋框、「所有模型」和「自訂」過濾器的即時模型目錄；首先是快速模型。
- 設備端：下載、載入和卸載離線運行的模型；從小到大排序；可選的 Hugging Face 標記；顯示已載入、正在載入和失敗狀態。

## 6. 氣場與主題
- 主題：恐怖、黑暗或光明。
- 光環&背景：光環風格和顏色（血、粉、紫、天、綠、火），具有精細的色調控制；光環大小、發光強度、旋轉速度、面板透明度；浮動眼睛（開/關、設計、屏幕邊緣、語音命令/喚醒詞，添加您自己的）；著色器模式；自定義背景 URL（mp4、gif 或圖像）；動畫速度。

## 7. 安全與隱私
- 應用鎖：密碼（4-8位）或3×3點陣圖案；輸入兩次確認；移除鎖。
- 權限：權限章節中的列表，有 Play Protect 幫助。
- 隱私和資料：所有資料都保留在手機上。按鈕：刪除所有記憶體、刪除聊天記錄、刪除GitHub令牌。

## 8. 系統
該部分有自己的一排按鈕，可以橫向滾動，因此不會擠壓任何東西。
- 自動化：核准等級且僅限裝置上（請參閱核准等級）。
- 導航：要跳到的區域列表 - “頂部沒有按鈕，一切都在這裡” - 包括 ⌘ ZX 系統 shell、“新會話”按鈕（刪除聊天記錄以重新開始）、訊息計數和麥克風切換。
- 內存：本地SQL內存，​​包含事實ZYRAXON記憶；添加鍵和值；全部刪除。
- 技能指南：範例能力的快速清單（訊息應用程式、網站建立、螢幕閱讀器、手電筒、相機、Wi-Fi 和設定）以及範例短語。
- 自動化中心：技能、自動駕駛儀、金錢、時間軸、大腦和呼叫代理集中在一個地方（請參閱自動化中心）。

## 9. 文件
「設定」中有自己的部分，與系統分開。本指南：二十一章、一個搜尋框和一個語言晶片行。應用程式中的每種語言都已在應用程式內完整編寫 - 您的手機上不會翻譯任何內容，也不需要網路即可閱讀。
