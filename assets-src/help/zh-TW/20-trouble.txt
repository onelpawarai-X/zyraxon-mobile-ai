故障排除
- 沒有答案：檢查您的網際網路和 API 金鑰（設定 → 提供者和 API 顯示真正的錯誤）。嘗試其他模型或設備上的模型。
- 麥克風不執行任何操作：允許麥克風權限；選取「保持麥克風開啟」；檢查辨識語言。
- ZYRAXON 聽到自己的聲音：這是透過文字過濾的；如果仍然出現這種情況，請降低音量或使用耳機。
- 一句話出現兩次：當前版本已修復；更新應用程式。
- 它不會點擊或閱讀螢幕：開啟輔助功能服務（設定 → 權限）。
- 它在後台停止：允許通知和電池優化豁免；浮動眼睛的覆蓋層。
- 工具不斷請求許可：更改設定 → 自動化中的級別，或應答卡。
- Play Protect 阻止某些內容：請參閱「權限」一章，或讓代理人指導步驟。
- 終端或Linux未啟動：等待應用程式啟動時首次解壓縮；檢查免費儲存空間。
- 更新將無法安裝：允許 ZYRAXON 作為安裝來源。
- 無法發布：為GitHub添加GitHub令牌；對於公共鏈路，代理可以使用隧道。
- 某個章節顯示英文：該章節在此版本中沒有您的語言的文字；更新應用程式。
- 奇怪的是：使用設定 → 導航 → 新會話開始清理（它只清除聊天歷史記錄；記憶體保留）。
