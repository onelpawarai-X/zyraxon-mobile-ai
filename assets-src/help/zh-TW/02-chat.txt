聊天螢幕和每個按鈕
## 螢幕頂部
- 選單：打開左側抽屜，其中包含您的聊天內容。
- 聊天/終端/程式碼/預覽：切換主視圖。聊天就是對話； Terminal是真正的終端機；程式碼是帶有Git的文件工作區；預覽是內建瀏覽器。
- Aura：顯示動畫角色畫面。它的側邊按鈕是麥克風、聊天（返回對話）和刷新（重新連接雲端並重新載入模型清單）。
- 設定：打開八個設定部分。
- 橫幅顯示麥克風狀態：「正在收聽...」、「麥克風關閉 — 點擊」或「正在講話...點擊停止」。
- 當新版本準備好時，會出現更新橫幅，其中包含「下載」、「安裝」和「允許」按鈕（請參閱更新）。

## 左側選單（聊天）
- “+新聊天”：開始新對話。
- 當客服人員忙碌時，清單中的每個聊天都會顯示一個正在運行的標記。鉛筆重新命名它；十字將其刪除（確認後：其中的所有訊息都將被刪除）。
- 主題：選擇恐怖（血、火和陰影）、黑暗（乾淨的深色玻璃）或光明（明亮的玻璃）。

## 訊息欄
- 附加（回形針）：圖庫照片、相機照片、文件掃描（將照片中的文字轉換為可編輯的 .docx）、共享螢幕以便代理可以看到它（打開或關閉「螢幕觀看」）以及音訊或視訊檔案。附件顯示為碎片；十字刪除一個，「全部清除」刪除所有。
- 模式按鈕：代理或建置。
- 麥克風按鈕：開啟或關閉始終監聽的麥克風。
- 型號按鈕：使用搜尋框開啟型號清單。標記為“Live”的模型可以用自己的聲音說話。
- 發送：發送訊息。當代理正在工作時，這將變為停止。
- 輸入內容為“我應該做什麼？”在代理模式下和在構建模式下“我應該構建什麼？簡短地說”。

## 留言
- 每個訊息下方都有複製、分享和聆聽（大聲朗讀訊息；再次按下即可停止）。
- 當模型提供推理時，「思考」顯示模型的推理。
- 代理程式編寫的程式碼逐行顯示在一個方塊中，可以複製、下載和開啟。
- 代理製作的檔案透過「開啟」（在手機的真實應用程式中）、「播放」、「分享」和「其他應用程式...」顯示為卡片。
- 圖片、音訊和影片在製作時會顯示即時進度百分比。
- 工具卡顯示代理正在執行的操作：正在運行、已完成、成功或失敗。

## 面板（待辦事項、工具、文件、子代理程式）
- 待辦事項板：代理為一項大工作及其進度編寫的計劃（n/已完成的總數）。您可以新增自己的任務和刪除任務。
- 工具：每個工具呼叫的列表，以及即時狀態。
- 文件：代理程式建立的每個文件，包括開啟、分享、發布和刪除（需要確認）以及搜尋框。
- 子代理：在背景運行的輔助代理，帶有“停止”按鈕。
- 終端選項卡：真正的終端（請參閱文件和終端章節）。

## 預覽面板
- 後退、前進、停止、重新載入和網址列（鍵入網址或搜尋 Google）。
- 開啟檔案：在應用程式內顯示 Word、Excel、PowerPoint、PDF、圖像、Markdown、CSV、程式碼和網站。
- 尺寸：縮小或放大面板。
- 修復：將頁面的問題（控制台錯誤、載入失敗）傳送給代理，代理在後台修復這些問題。
- 選擇部分：點擊頁面的一部分，然後告訴客服人員如何處理該部分。
- 代理按鈕：詢問有關頁面的資訊；代理收到它的照片。
- 快速開啟：最近頁面的捷徑。

## 代碼工作區
- 左側：您的文件（新文件、開啟、儲存）。
- 編輯器：顯示線條和字元；代理程式所做的變更會立即顯示。
- Git：新儲存庫、從 GitHub 複製、掃描、狀態、提交訊息、推播、拉取、分支、令牌。
- 拉取要求：建立、合併、關閉。工作流程：列出運作、運作工作流程。日誌顯示命令輸出。
