安全和隱私
- ZYRAXON 的所有資料都儲存在您的手機上：聊天、記憶體、帳本、技能、時間軸、大腦索引。 ZYRAXON 伺服器上不會儲存任何內容。
- 雲端模型僅接收您發送的回合所需的內容。對於“僅限設備上”，根本不會發送任何內容。
- 應用程式中附帶的提示和語言檔案在 APK 內加密。
- 應用程式鎖定：在設定 → 安全性和隱私 → 應用程式鎖定中設定密碼或圖案。 ZYRAXON 然後在您打開它或從背景返回時鎖定。 「解除鎖定」會刪除已儲存的密碼或圖案。
- 批准等級保護程式碼中的每個工具呼叫（請參閱批准等級）。未知的工具總是會詢問。
- 您可以擦除：所有記憶體、聊天歷史記錄和您的 GitHub 令牌，每一項都可以透過「隱私和資料」中的一個按鈕來擦除。
- 安全：如果您說有人威脅或跟踪您，或者想要您的手機或數據，代理會先鎖定手機（如果設備管理員權限已打開），然後平靜地與您交談。
- 付款：在任何付款或轉帳之前，代理商會說明將支付的金額並要求您確認。
- 誠實：代理商看到結果後才說某件事有效。它從不發明連結、文件或結果。
- 內容屏蔽：代理從外部讀取的任何內容（另一個應用程式的螢幕、網頁、訊息、檔案、連接的伺服器）都會在程式碼中檢查試圖向代理程式發出命令的文字（在許多語言中，包括用不可見字元隱藏的文字）。可疑文字被隔離，因此模型僅將其視為資料。其嚴格程度取決於您的批准等級：鎖定將任何可疑的行為視為敵對；受監督的圍欄會屏蔽可疑文本，並且當文本明顯具有敵意時，會鎖定將任何可疑的行為視為敵對；受監督的圍欄會屏蔽可疑文本，並且當文本明顯具有敵意時，會鎖定該回合的其餘部分，因此每個更改工具都會首先詢問您（卡片上會說明原因）；平衡僅對明顯敵對的文本起作用，並且只有系統級工具停止詢問；您發送的新訊息會將其清除。
