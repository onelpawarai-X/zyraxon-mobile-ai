入門
ZYRAXON 是位於您 Android 手機內的助手。它會與你交談，傾聽你的聲音，並且可以做真正的工作：打開應用程式、在螢幕上點擊和打字、打電話給別人、編寫文件、建立網站和應用程式、運行 ZYRAXON OS 系統、製作圖片、音訊、視訊和辦公文檔，並在幾個月內記住你。它適用於您所說的任何語言。

## 最初幾分鐘
- 首次啟動時 ZYRAXON 會顯示一條簡短通知，表示代理可以自行對您的手機進行操作。按「知道了，開始」繼續。
- 新增 AI 金鑰（設定 → 提供者和 API → AI 提供者）。貼上您喜歡的任何提供者的金鑰（ZYRAXON、Groq、Gemini、OpenAI、Grok、Claude、DeepSeek、OpenRouter、OpenCode）。當您儲存密鑰時，應用程式會讀取該提供者的目錄並檢查其是否真實，以便您可以看到真正的「已連接」和模型數量。
- 沒有鑰匙？您仍然可以使用裝置上的模型（設定 → 模型和身分 → 裝置上）。他們在沒有網路的情況下透過手機運作。
- 使用訊息欄中的模型按鈕選擇模型和角色（設定 → 模型和身分 → 身分）。
- 當某項功能需要權限時授予權限（請參閱「權限」章節）。客服人員也可以一鍵為您開啟權限對話框。
- 只需說話或打字即可。 「為我的麵包店製作一個登陸頁面」、「打開 YouTube 並播放歌曲」、「我的電池是什麼？」、「打電話給媽媽」。

## 兩種工作方式
訊息框旁邊有一個模式按鈕，有兩種模式：代理和建置。請參閱模式章節。

## 東西在哪裡
- 左側選單：您的聊天記錄、新聊天記錄、重新命名、刪除和主題切換。
- 聊天螢幕：訊息、待辦事項板、工具清單、文件、終端機。
- 預覽和程式碼面板：檢視和編輯代理程式建置的內容。
- 設定：八個部分，本文檔一一介紹。
- 本文檔：設定 → 文件（您在此）。
