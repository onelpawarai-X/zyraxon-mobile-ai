ಪೂರೈಕೆದಾರರು, ಮಾದರಿಗಳು ಮತ್ತು ಕೀಲಿಗಳು
## ಪೂರೈಕೆದಾರರು
ZYRAXON (ಸ್ವಂತ ಲೈನ್ ಮತ್ತು Apex ಕ್ಲೌಡ್ ಏಜೆಂಟ್, ಯಾವಾಗಲೂ ಸಂಪರ್ಕಿತವಾಗಿದೆ), OpenCode (ಉಚಿತ ಕೋಟಾ), Groq (ಅತ್ಯಂತ ವೇಗದ ಲಾಮಾ), Gemini, OpenAI, Grok (xAI), Claude, DeepSeek ಮತ್ತು OpenRouter. ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಪೂರೈಕೆದಾರರು ಮತ್ತು API ನಲ್ಲಿ ಯಾವುದೇ ಕೀಲಿಯನ್ನು ಸೇರಿಸಿ. ಕೀಲಿಯನ್ನು ನಿಮ್ಮ ಫೋನ್‌ನಲ್ಲಿ ಉಳಿಸಲಾಗಿದೆ, ಒದಗಿಸುವವರ ಕ್ಯಾಟಲಾಗ್‌ಗೆ ವಿರುದ್ಧವಾಗಿ ಪರಿಶೀಲಿಸಲಾಗಿದೆ ಮತ್ತು ಪ್ರತಿ ಪೂರೈಕೆದಾರರು ಉತ್ತರಿಸಿದಂತೆ ಮಾದರಿಗಳು ಸೆಲೆಕ್ಟರ್‌ಗೆ ಸ್ಟ್ರೀಮ್ ಆಗುತ್ತವೆ.

## ಮಾದರಿಯನ್ನು ಆರಿಸುವುದು
ಸಂದೇಶ ಪಟ್ಟಿಯಲ್ಲಿರುವ ಮಾದರಿ ಬಟನ್ ಅಥವಾ ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಮಾದರಿ ಮತ್ತು ಗುರುತು → ಮಾದರಿಯನ್ನು ಬಳಸಿ. ಹೆಸರಿನ ಮೂಲಕ ಹುಡುಕಿ, ಎಲ್ಲವನ್ನೂ ಫಿಲ್ಟರ್ ಮಾಡಿ ಅಥವಾ ಕಸ್ಟಮ್ ಮಾಡಿ. ನಿಮ್ಮ ಆಯ್ಕೆಯನ್ನು ಉಳಿಸಲಾಗಿದೆ ಮತ್ತು ಪ್ರಾರಂಭದಲ್ಲಿ ಮರುಸ್ಥಾಪಿಸಲಾಗಿದೆ; ರಿಫ್ರೆಶ್ ನಿಮ್ಮ ಉಳಿಸಿದ ಮಾದರಿಯನ್ನು ಎಂದಿಗೂ ಬದಲಿಸುವುದಿಲ್ಲ. ಲೈವ್ ಎಂದು ಗುರುತಿಸಲಾದ ಮಾದರಿಗಳು ತಮ್ಮದೇ ಆದ ಧ್ವನಿಯಲ್ಲಿ ಮಾತನಾಡಬಹುದು (ಲೈವ್ ಧ್ವನಿಯನ್ನು ನೋಡಿ).

## ಸಾಧನದ ಮಾದರಿಗಳು
ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಮಾದರಿ ಮತ್ತು ಗುರುತು → ಸಾಧನದಲ್ಲಿ. ಯಾವುದೇ ಡೇಟಾವನ್ನು ಬಿಟ್ಟು ಫೋನ್‌ನಲ್ಲಿ ಮಾಡೆಲ್ ರನ್ ಆಗುತ್ತದೆ. ಫೈಲ್‌ಗಳು ದೊಡ್ಡದಾಗಿದೆ (ನೂರಾರು MB ಯಿಂದ ಕೆಲವು GB), ಆದ್ದರಿಂದ Wi-Fi ನಲ್ಲಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. ಅವುಗಳನ್ನು ಚಿಕ್ಕದಾಗಿ ದೊಡ್ಡದಾಗಿ ಪಟ್ಟಿಮಾಡಲಾಗಿದೆ; ಕಡಿಮೆ RAM ಹೊಂದಿರುವ ಫೋನ್‌ನಲ್ಲಿ ಹಗುರವಾದದನ್ನು ಆಯ್ಕೆಮಾಡಿ. ಟೂಲ್ ಕರೆ ಮಾಡುವಿಕೆಯನ್ನು Gemma ಮತ್ತು FunctionGemma ಬಂಡಲ್‌ಗಳು ಬೆಂಬಲಿಸುತ್ತವೆ. Hugging Face ಟೋಕನ್ ಗೇಟೆಡ್ ಫೈಲ್‌ಗಳಿಗೆ ಮಾತ್ರ. ಲೋಡ್ ಮಾಡಲಾದ ಮಾದರಿಗಳನ್ನು ನೆನಪಿಸಿಕೊಳ್ಳಲಾಗುತ್ತದೆ.

## ZYRAXON ವೆಬ್‌ಸೈಟ್
zyraxonai.lovable.app: ಖಾತೆಯನ್ನು ರಚಿಸಿ (ಇಮೇಲ್ ಅಥವಾ Google), ಸೆಟ್ಟಿಂಗ್‌ಗಳು, API ಕೀ / ಪ್ರವೇಶ ಟೋಕನ್ ತೆರೆಯಿರಿ, ಕೀಲಿಯನ್ನು ರಚಿಸಿ ಮತ್ತು ಅದನ್ನು ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಅಂಟಿಸಿ. ಕೀ ಇಲ್ಲದೆಯೇ ನೀವು ಇನ್ನೂ ಸಾಧನದ ಮಾದರಿಗಳು ಮತ್ತು ಸ್ಥಳೀಯ ಪರಿಕರಗಳೊಂದಿಗೆ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಬಳಸಬಹುದು.

## ವೆಚ್ಚಗಳು ಮತ್ತು ಡೇಟಾ
ಮೇಘ ಪೂರೈಕೆದಾರರು ತಮ್ಮದೇ ನಿಯಮಗಳ ಪ್ರಕಾರ ನಿಮಗೆ ಬಿಲ್ ಮಾಡುತ್ತಾರೆ. "ಸಾಧನದಲ್ಲಿ ಮಾತ್ರ" ಆನ್ ಮಾಡಿದಾಗ ಯಾವುದನ್ನೂ ಯಾವುದೇ ಪೂರೈಕೆದಾರರಿಗೆ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.
