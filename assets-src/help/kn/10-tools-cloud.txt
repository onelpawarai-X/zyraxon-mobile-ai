ಮೇಘ, ನೆಟ್‌ವರ್ಕ್, ಮಾದರಿಗಳು ಮತ್ತು ಸಹಾಯಕರು
## ಮೇಘ ಮತ್ತು ಇಂಟರ್ನೆಟ್
- `web_search` (ನೆಟ್‌ವರ್ಕ್): ನೈಜ ವೆಬ್ ಅನ್ನು ಹುಡುಕಿ. `read_url` (ನೆಟ್‌ವರ್ಕ್): ಪಠ್ಯದಂತೆ ಪುಟವನ್ನು ಪಡೆದುಕೊಳ್ಳಿ. `http_request` (ನೆಟ್‌ವರ್ಕ್): ಹೆಡರ್‌ಗಳು ಮತ್ತು ದೇಹದೊಂದಿಗೆ ಯಾವುದೇ HTTP ಕರೆ (GET, POST, PUT, PATCH, DELETE). `verify_url` (ನೆಟ್‌ವರ್ಕ್): ಲಿಂಕ್ ನಿಜವಾಗಿಯೂ ಅಸ್ತಿತ್ವದಲ್ಲಿದೆ ಎಂಬುದನ್ನು ಪರಿಶೀಲಿಸಿ ಮತ್ತು ನಿಜವಾದ ಸ್ಥಿತಿಯನ್ನು ಪಡೆಯಿರಿ. `download_file` (ವೈಯಕ್ತಿಕ, ನೆಟ್‌ವರ್ಕ್): ಫೈಲ್‌ಗೆ URL ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ.
- ನೀವು ಕೇಳಿದಾಗ ಮಾತ್ರ ಏಜೆಂಟ್ ಲಿಂಕ್‌ಗಳನ್ನು ತೆರೆಯುತ್ತದೆ.
- ನೀವು ಸೇರಿಸಿದ ಪೂರೈಕೆದಾರರ ಮೂಲಕ AI ಮಾದರಿಗಳು ಕ್ಲೌಡ್‌ನಲ್ಲಿ ಚಲಿಸುತ್ತವೆ (ZYRAXON, ZYRAXON Apex ಕ್ಲೌಡ್ ಏಜೆಂಟ್, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode). ಮಾದರಿ ಪಟ್ಟಿಯು ಲೈವ್ ಆಗಿ ಲೋಡ್ ಆಗುತ್ತದೆ ಮತ್ತು ಪ್ರತಿ ಪೂರೈಕೆದಾರರು ಉತ್ತರಿಸಿದಂತೆ ತುಂಬುತ್ತದೆ.
- ಬಿಲ್ಡ್‌ಗಳು, ಪಬ್ಲಿಷಿಂಗ್ ಮತ್ತು ಪುಲ್ ವಿನಂತಿಗಳು GitHub ಮತ್ತು Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git` ಮೂಲಕ ಸಾಗುತ್ತವೆ.
- "ಸಾಧನದಲ್ಲಿ ಮಾತ್ರ" (ಸ್ವಯಂಚಾಲಿತ ಸೆಟ್ಟಿಂಗ್‌ಗಳು) ಆನ್ ಮಾಡಿ ಮತ್ತು ಯಾವುದೇ ಕ್ಲೌಡ್ ಕರೆ ಮಾಡಲಾಗುವುದಿಲ್ಲ: ಯಾವುದೇ ಪೂರೈಕೆದಾರರಿಲ್ಲ, ವೆಬ್ ಇಲ್ಲ, ಅಪ್‌ಲೋಡ್ ಇಲ್ಲ.

## MCP ಸರ್ವರ್‌ಗಳು
MCP ಹೊರಗಿನ ಸೇವೆಗಳು ಏಜೆಂಟ್‌ಗೆ ಹೆಚ್ಚುವರಿ ಪರಿಕರಗಳನ್ನು ನೀಡಲು ಅನುಮತಿಸುತ್ತದೆ. Canva, Cloudflare, Supabase, GitHub ಅಥವಾ ನಿಮ್ಮ ಸ್ವಂತ ಸರ್ವರ್ ಅನ್ನು ಅದರ ವಿಳಾಸದ ಮೂಲಕ ಸಂಪರ್ಕಿಸಿ (ಐಚ್ಛಿಕ ಟೋಕನ್). ಸಂಪರ್ಕಿತ ಸರ್ವರ್‌ಗಳ ಪರಿಕರಗಳು ಏಜೆಂಟ್‌ನ ಟೂಲ್ ಪಟ್ಟಿಗೆ `server__tool` ಸೇರುತ್ತವೆ.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (ಯಾವುದನ್ನು ಸಂಪರ್ಕಿಸಲಾಗಿದೆ ಮತ್ತು ಯಾವ ಸಾಧನಗಳು ಅಸ್ತಿತ್ವದಲ್ಲಿವೆ ಎಂಬುದನ್ನು ನೋಡಿ), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (ಬದಲಾವಣೆಗಳಿಗಾಗಿ ಸಂಪನ್ಮೂಲವನ್ನು ವೀಕ್ಷಿಸಿ), `mcp_complete` (ಸ್ವಯಂಪೂರ್ಣ ವಾದಗಳು), `mcp_ping`, `mcp_log_level`. ಅವರ ಕರೆಗಳು ನೆಟ್‌ವರ್ಕ್ ಕರೆಗಳಾಗಿವೆ ಮತ್ತು ಅಜ್ಞಾತ MCP ಉಪಕರಣಗಳು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಅನುಮತಿಯನ್ನು ಕೇಳುತ್ತವೆ.
- MCP ಪರದೆಯು ಪ್ರತಿ ಸರ್ವರ್ ಅನ್ನು ಸಂಪರ್ಕಿತ ಸ್ಥಿತಿ, ಅದರ ಪರಿಕರಗಳು, ಸಂಪನ್ಮೂಲಗಳು ಮತ್ತು ಪ್ರಾಂಪ್ಟ್ ಟೆಂಪ್ಲೇಟ್‌ಗಳು ಮತ್ತು ಸೇರಿಸಿ, ಸಂಪರ್ಕ ಕಡಿತಗೊಳಿಸಿ, ತೆಗೆದುಹಾಕಿ, ಅನುಮತಿಸುವ ಬಟನ್‌ಗಳೊಂದಿಗೆ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ.

## ಉಪ ಏಜೆಂಟ್
`sub_agent` (ಸಿಸ್ಟಮ್): ಹಿನ್ನಲೆಯಲ್ಲಿ ಚಾಲನೆಯಲ್ಲಿರುವ ಸಹಾಯಕ ಏಜೆಂಟ್‌ಗಳಿಗೆ ದೊಡ್ಡ ಕೆಲಸದ ಭಾಗಗಳನ್ನು ಹಸ್ತಾಂತರಿಸುವುದು. ಕ್ರಿಯೆಗಳು: ಸ್ಪಾನ್, ಸ್ಥಿತಿ, ಪಟ್ಟಿ, ಫಲಿತಾಂಶ, ಸಂದೇಶ, ನಿಲ್ಲಿಸಿ, ನಿರೀಕ್ಷಿಸಿ. ಪ್ರತಿಯೊಂದೂ ತನ್ನದೇ ಆದ ಮಾದರಿಯನ್ನು ಬಳಸಬಹುದು. "ಮುಗಿದಿದೆ" ಎಂದು ಹೇಳುವ ಮೊದಲು ಏಜೆಂಟ್ ಅವರ ಫಲಿತಾಂಶಗಳನ್ನು ಸಂಯೋಜಿಸುತ್ತದೆ ಮತ್ತು ಪರಿಶೀಲಿಸುತ್ತದೆ.

## ಸಾಧನದ ಮಾದರಿ
`on_device_model` (ಸಿಸ್ಟಮ್): ಇಂಟರ್ನೆಟ್ ಇಲ್ಲದೆ ಫೋನ್‌ನಲ್ಲಿ ವಾಸಿಸುವ ಭಾಷಾ ಮಾದರಿಯನ್ನು ಪಟ್ಟಿ ಮಾಡಿ, ಲೋಡ್ ಮಾಡಿ ಮತ್ತು ರನ್ ಮಾಡಿ. ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ → ಮಾದರಿ ಮತ್ತು ಗುರುತು → ಸಾಧನದಲ್ಲಿ ನೀವು ಮಾದರಿಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತೀರಿ (ಸಣ್ಣದಿಂದ ದೊಡ್ಡದಕ್ಕೆ: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B...); ಒಂದು Hugging Face ಟೋಕನ್ ಐಚ್ಛಿಕವಾಗಿರುತ್ತದೆ ಮತ್ತು ಗೇಟೆಡ್ ಫೈಲ್‌ಗಳಿಗೆ ಮಾತ್ರ ಅಗತ್ಯವಿದೆ. ಲೋಡ್ ಮಾಡಲಾದ ಮಾದರಿಯನ್ನು ನೆನಪಿಸಿಕೊಳ್ಳಲಾಗುತ್ತದೆ ಮತ್ತು ಉಡಾವಣೆಯಲ್ಲಿ ಮರುಲೋಡ್ ಮಾಡಲಾಗುತ್ತದೆ.

## ಸಂದೇಶ ಕಳುಹಿಸುವ ಚಾನಲ್‌ಗಳು
`channel_post` (ಸಿಸ್ಟಮ್) Telegram, WhatsApp, ಫೇಸ್‌ಬುಕ್, Messenger, YouTube, X, Instagram, Gmail ಅಥವಾ ನಿಮ್ಮ ಪಠ್ಯವನ್ನು ಸಿದ್ಧಗೊಳಿಸಿದ SMS ತೆರೆಯುತ್ತದೆ. ನೀವೇ ಕಳುಹಿಸು ಒತ್ತಿರಿ.
