ಪ್ರತಿ ಸೆಟ್ಟಿಂಗ್‌ಗಳ ಪರದೆ, ಒಂದೊಂದಾಗಿ
ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಎಂಟು ವಿಭಾಗಗಳನ್ನು ಹೊಂದಿದೆ. ಪ್ರತಿಯೊಂದು ವಿಭಾಗವು ಅದರ ಉಪ-ಪರದೆಗಳಿಗೆ ಮಾತ್ರೆಗಳನ್ನು ಹೊಂದಿದೆ. ನೀವು ಬಳಸಿದ ಕೊನೆಯ ವಿಭಾಗವನ್ನು ಮುಂದಿನ ಬಾರಿ ಪುನಃ ತೆರೆಯಲಾಗುತ್ತದೆ.

## 1. ಭಾಷೆ ಮತ್ತು ಅನುವಾದ → ಅಪ್ಲಿಕೇಶನ್ ಮತ್ತು ಟೂಲ್ ಭಾಷೆ
ಇಡೀ ಅಪ್ಲಿಕೇಶನ್‌ನ ಭಾಷೆಯನ್ನು ಮತ್ತು ಏಜೆಂಟ್‌ನ ಟೂಲ್ ಸಂದೇಶಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ. ಪಟ್ಟಿಯನ್ನು ಹುಡುಕಿ ಮತ್ತು ಒಂದನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿ. ಪರದೆಯು ಪ್ರಸ್ತುತ ಭಾಷೆ ಮತ್ತು UI ಅನುವಾದ ಮತ್ತು ಟೂಲ್-ಸಂದೇಶ ಅನುವಾದ ಆನ್ ಆಗಿದೆಯೇ ಎಂಬುದನ್ನು ತೋರಿಸುತ್ತದೆ. 60 ಭಾಷೆಗಳು ಲಭ್ಯವಿದೆ. ಭಾಷಾ ಅಧ್ಯಾಯವನ್ನು ನೋಡಿ.

## 2. ಧ್ವನಿ ಮತ್ತು ಮೈಕ್
- ಧ್ವನಿ ಪ್ರೊಫೈಲ್: ಸ್ತ್ರೀ ಅಥವಾ ಪುರುಷ ಧ್ವನಿ, ವೇಗ, ಪಿಚ್, "ಉತ್ತರಗಳನ್ನು ಗಟ್ಟಿಯಾಗಿ ಓದಿ", ಪರೀಕ್ಷಾ ಧ್ವನಿ, ಬಂಗಾಳಿ ಧ್ವನಿ ಡೌನ್‌ಲೋಡ್ ಸುಳಿವು ಆಯ್ಕೆಮಾಡಿ.
- ಮೈಕ್ ಮತ್ತು ಭಾಷೆ: ಗುರುತಿಸುವಿಕೆ ಭಾಷೆ, ಮೈಕ್ ಅನ್ನು ಆನ್ ಮಾಡಿ, ನೀವು ಮಾತನಾಡುವುದನ್ನು ನಿಲ್ಲಿಸಿದಾಗ ಸ್ವಯಂ-ಕಳುಹಿಸಿ.
- ಲೈವ್ ಧ್ವನಿ: ಸ್ಪೀಚ್-ಟು-ಸ್ಪೀಚ್ ಆನ್/ಆಫ್, ಸ್ಥಿತಿ, ನೈಜ ಸಮಯದ ಮಾದರಿಗಳ ಪಟ್ಟಿ.

## 3. ಪೂರೈಕೆದಾರರು ಮತ್ತು API
- AI ಪೂರೈಕೆದಾರರು: ನಿಮ್ಮ ಸ್ವಂತ API ಕೀಗಳು (ZYRAXON, OpenCode ಉಚಿತ ಕೋಟಾ, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter) ಮತ್ತು ZYRAXON Apex ಕ್ಲೌಡ್ ಏಜೆಂಟ್. ಒದಗಿಸುವವರ ನೈಜ ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು ಓದುವ ಮೂಲಕ ಉಳಿಸಿದ ಕೀಲಿಯನ್ನು ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಮಾದರಿ ಎಣಿಕೆ ಅಥವಾ ನಿಖರವಾದ ದೋಷವನ್ನು ತೋರಿಸುತ್ತದೆ. ನೀವು ಕೀಲಿಯನ್ನು ರಚಿಸುವ ZYRAXON ವೆಬ್‌ಸೈಟ್ ಅನ್ನು ಬಟನ್ ತೆರೆಯುತ್ತದೆ.
- GitHub: ನಿಮ್ಮ GitHub ಪ್ರವೇಶ ಟೋಕನ್ (ರೆಪೋ ಸ್ಕೋಪ್ ಅಗತ್ಯವಿದೆ) ಪ್ರಕಟಣೆಗಾಗಿ, Git ವಿನಂತಿಗಳನ್ನು ಒತ್ತಿ ಮತ್ತು ಎಳೆಯಿರಿ. ಟೋಕನ್ ಉಳಿಸಿ ಅಥವಾ ಅಳಿಸಿ; ಅದನ್ನು ಹೊಂದಿಸಿದ್ದರೆ ಸ್ಥಿತಿ ತೋರಿಸುತ್ತದೆ.

## 4. ನವೀಕರಣಗಳು → ಅಪ್ಲಿಕೇಶನ್ ನವೀಕರಣ
ಪ್ರಸ್ತುತ ಆವೃತ್ತಿಯನ್ನು ತೋರಿಸುತ್ತದೆ, ಹೊಸ ಬಿಡುಗಡೆಗಾಗಿ ಪರಿಶೀಲಿಸುತ್ತದೆ, ಪ್ರಗತಿ ಪಟ್ಟಿಯೊಂದಿಗೆ ಅದನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆ ಮತ್ತು ಅದನ್ನು ಸ್ಥಾಪಿಸುತ್ತದೆ. ನಿಮ್ಮ ಚಾಟ್‌ಗಳು, ಮೆಮೊರಿ ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಉಳಿಯುತ್ತವೆ. Android ಅನುಸ್ಥಾಪಿಸಲು ಅನುಮತಿ ಅಗತ್ಯವಿದ್ದರೆ, ಒಂದು ಬಟನ್ ಆ ಸೆಟ್ಟಿಂಗ್ ಅನ್ನು ತೆರೆಯುತ್ತದೆ.

## 5. ಮಾದರಿ ಮತ್ತು ಗುರುತು
- ಗುರುತು: ಪಾತ್ರವನ್ನು ಆಯ್ಕೆ ಮಾಡಿ (ಪಾತ್ರಗಳ ಅಧ್ಯಾಯವನ್ನು ನೋಡಿ).
- ಮಾದರಿ: ಹುಡುಕಾಟ ಬಾಕ್ಸ್‌ನೊಂದಿಗೆ ಲೈವ್ ಮಾಡೆಲ್ ಕ್ಯಾಟಲಾಗ್, "ಎಲ್ಲಾ ಮಾದರಿಗಳು" ಮತ್ತು "ಕಸ್ಟಮ್" ಫಿಲ್ಟರ್‌ಗಳು; ಮೊದಲ ವೇಗದ ಮಾದರಿಗಳು.
- ಸಾಧನದಲ್ಲಿ: ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಚಾಲನೆಯಲ್ಲಿರುವ ಮಾದರಿಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ, ಲೋಡ್ ಮಾಡಿ ಮತ್ತು ಇಳಿಸಿ; ಚಿಕ್ಕದಾಗಿ ದೊಡ್ಡದಾಗಿ ವಿಂಗಡಿಸಲಾಗಿದೆ; ಐಚ್ಛಿಕ Hugging Face ಟೋಕನ್; ಲೋಡ್ ಮಾಡಲಾದ, ಲೋಡ್ ಆಗುತ್ತಿರುವ ಮತ್ತು ವಿಫಲವಾದ ಸ್ಥಿತಿಗಳನ್ನು ತೋರಿಸುತ್ತದೆ.

## 6. ಸೆಳವು ಮತ್ತು ಥೀಮ್
- ಥೀಮ್: ಭಯಾನಕ, ಕತ್ತಲೆ ಅಥವಾ ಬೆಳಕು.
- ಸೆಳವು ಮತ್ತು ಹಿನ್ನೆಲೆ: ಉತ್ತಮ ವರ್ಣ ನಿಯಂತ್ರಣದೊಂದಿಗೆ ಸೆಳವು ಶೈಲಿ ಮತ್ತು ಬಣ್ಣ (ರಕ್ತ, ಗುಲಾಬಿ, ನೇರಳೆ, ಆಕಾಶ, ಹಸಿರು, ಬೆಂಕಿ); ಸೆಳವು ಗಾತ್ರ, ಹೊಳಪಿನ ಶಕ್ತಿ, ತಿರುಗುವಿಕೆಯ ವೇಗ, ಫಲಕ ಪಾರದರ್ಶಕತೆ; ತೇಲುವ ಕಣ್ಣು (ಆನ್/ಆಫ್, ಡಿಸೈನ್, ಸ್ಕ್ರೀನ್ ಎಡ್ಜ್, ವಾಯ್ಸ್ ಕಮಾಂಡ್‌ಗಳು/ವೇಕ್ ವರ್ಡ್ಸ್, ನಿಮ್ಮದೇ ಆದ ಸೇರಿಸಿ); ಶೇಡರ್ ಮೋಡ್; ಕಸ್ಟಮ್ ಹಿನ್ನೆಲೆ URL (mp4, gif ಅಥವಾ ಚಿತ್ರ); ಅನಿಮೇಷನ್ ವೇಗ.

## 7. ಭದ್ರತೆ ಮತ್ತು ಗೌಪ್ಯತೆ
- ಅಪ್ಲಿಕೇಶನ್ ಲಾಕ್: ಪಾಸ್‌ವರ್ಡ್ (4–8 ಅಂಕೆಗಳು) ಅಥವಾ 3×3 ಡಾಟ್ ಮಾದರಿ; ಅದನ್ನು ಎರಡು ಬಾರಿ ನಮೂದಿಸುವ ಮೂಲಕ ದೃಢೀಕರಿಸಿ; ಲಾಕ್ ತೆಗೆದುಹಾಕಿ.
- ಅನುಮತಿಗಳು: Play Protect ಸಹಾಯದಿಂದ ಅನುಮತಿಗಳ ಅಧ್ಯಾಯದಲ್ಲಿರುವ ಪಟ್ಟಿ.
- ಗೌಪ್ಯತೆ ಮತ್ತು ಡೇಟಾ: ಎಲ್ಲಾ ಡೇಟಾ ಫೋನ್‌ನಲ್ಲಿ ಉಳಿಯುತ್ತದೆ. ಬಟನ್‌ಗಳು: ಎಲ್ಲಾ ಮೆಮೊರಿಯನ್ನು ಅಳಿಸಿ, ಚಾಟ್ ಇತಿಹಾಸವನ್ನು ಅಳಿಸಿ, GitHub ಟೋಕನ್ ಅಳಿಸಿ.

## 8. ವ್ಯವಸ್ಥೆ
ಈ ವಿಭಾಗವು ತನ್ನದೇ ಆದ ಗುಂಡಿಗಳನ್ನು ಹೊಂದಿದ್ದು ಅದು ಪಕ್ಕಕ್ಕೆ ಸ್ಕ್ರಾಲ್ ಮಾಡುತ್ತದೆ, ಆದ್ದರಿಂದ ಯಾವುದನ್ನೂ ಹಿಂಡಿದಿಲ್ಲ.
- ಆಟೊಮೇಷನ್: ಅನುಮೋದನೆ ಮಟ್ಟ ಮತ್ತು ಸಾಧನದಲ್ಲಿ ಮಾತ್ರ (ಅನುಮೋದನೆಯ ಹಂತಗಳನ್ನು ನೋಡಿ).
- ನ್ಯಾವಿಗೇಶನ್: ⌘ ZX ಸಿಸ್ಟಮ್ ಶೆಲ್, "ಹೊಸ ಸೆಷನ್" ಬಟನ್ (ಕ್ಲೀನ್ ಸ್ಟಾರ್ಟ್‌ಗಾಗಿ ಚಾಟ್ ಇತಿಹಾಸವನ್ನು ಅಳಿಸುತ್ತದೆ), ಸಂದೇಶ ಎಣಿಕೆ ಮತ್ತು ಮೈಕ್ ಟಾಗಲ್ ಸೇರಿದಂತೆ "ಮೇಲ್ಭಾಗದಲ್ಲಿ ಯಾವುದೇ ಬಟನ್‌ಗಳಿಲ್ಲ, ಎಲ್ಲವೂ ಇಲ್ಲಿದೆ" - ಗೆ ಹೋಗಲು ಪ್ರದೇಶಗಳ ಪಟ್ಟಿ.
- ಸ್ಮರಣೆ: ಸ್ಥಳೀಯ SQL ನೆನಪುಗಳು ZYRAXON ನೆನಪಿಸುತ್ತದೆ; ಕೀ ಮತ್ತು ಮೌಲ್ಯವನ್ನು ಸೇರಿಸಿ; ಎಲ್ಲವನ್ನೂ ಅಳಿಸಿ.
- ಕೌಶಲ್ಯ ಮಾರ್ಗದರ್ಶಿ: ಉದಾಹರಣೆ ಸಾಮರ್ಥ್ಯಗಳ ತ್ವರಿತ ಪಟ್ಟಿ (ಮೆಸೇಜಿಂಗ್ ಅಪ್ಲಿಕೇಶನ್‌ಗಳು, ವೆಬ್‌ಸೈಟ್ ನಿರ್ಮಾಣ, ಸ್ಕ್ರೀನ್ ರೀಡರ್, ಟಾರ್ಚ್, ಕ್ಯಾಮೆರಾ, Wi-Fi ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳು) ಉದಾಹರಣೆಗೆ ನುಡಿಗಟ್ಟುಗಳೊಂದಿಗೆ.
- ಆಟೊಮೇಷನ್ ಹಬ್: ಕೌಶಲ್ಯಗಳು, ಆಟೋಪೈಲಟ್, ಹಣ, ಟೈಮ್‌ಲೈನ್, ಮೆದುಳು ಮತ್ತು ಒಂದೇ ಸ್ಥಳದಲ್ಲಿ ಕರೆ ಏಜೆಂಟ್ (ಆಟೋಮೇಷನ್ ಹಬ್ ನೋಡಿ).

## 9. ದಾಖಲೆ
ಸಿಸ್ಟಮ್‌ನಿಂದ ಪ್ರತ್ಯೇಕವಾದ ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ತನ್ನದೇ ಆದ ವಿಭಾಗ. ಈ ಮಾರ್ಗದರ್ಶಿ: ಇಪ್ಪತ್ತೊಂದು ಅಧ್ಯಾಯಗಳು, ಹುಡುಕಾಟ ಬಾಕ್ಸ್ ಮತ್ತು ಭಾಷಾ ಚಿಪ್ ಸಾಲು. ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿರುವ ಪ್ರತಿಯೊಂದು ಭಾಷೆಯನ್ನು ಈಗಾಗಲೇ ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಸಂಪೂರ್ಣವಾಗಿ ಬರೆಯಲಾಗಿದೆ - ನಿಮ್ಮ ಫೋನ್‌ನಲ್ಲಿ ಏನನ್ನೂ ಅನುವಾದಿಸಲಾಗಿಲ್ಲ ಮತ್ತು ಅದನ್ನು ಓದಲು ಯಾವುದೇ ಇಂಟರ್ನೆಟ್ ಅಗತ್ಯವಿಲ್ಲ.
