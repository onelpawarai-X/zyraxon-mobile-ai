ದೋಷನಿವಾರಣೆ
- ಉತ್ತರವಿಲ್ಲ: ನಿಮ್ಮ ಇಂಟರ್ನೆಟ್ ಮತ್ತು API ಕೀಯನ್ನು ಪರಿಶೀಲಿಸಿ (ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಪೂರೈಕೆದಾರರು ಮತ್ತು API ನಿಜವಾದ ದೋಷವನ್ನು ತೋರಿಸುತ್ತದೆ). ಇನ್ನೊಂದು ಮಾದರಿ ಅಥವಾ ಸಾಧನದ ಮಾದರಿಯನ್ನು ಪ್ರಯತ್ನಿಸಿ.
- ಮೈಕ್ರೊಫೋನ್ ಏನನ್ನೂ ಮಾಡುವುದಿಲ್ಲ: ಮೈಕ್ರೊಫೋನ್ ಅನುಮತಿಯನ್ನು ಅನುಮತಿಸಿ; "ಮೈಕ್ ಅನ್ನು ಆನ್ ಮಾಡಿ" ಪರಿಶೀಲಿಸಿ; ಗುರುತಿಸುವಿಕೆ ಭಾಷೆಯನ್ನು ಪರಿಶೀಲಿಸಿ.
- ZYRAXON ಸ್ವತಃ ಕೇಳುತ್ತದೆ: ಇದನ್ನು ಪಠ್ಯದಿಂದ ಫಿಲ್ಟರ್ ಮಾಡಲಾಗಿದೆ; ಇದು ಇನ್ನೂ ಸಂಭವಿಸಿದಲ್ಲಿ, ವಾಲ್ಯೂಮ್ ಅನ್ನು ಕಡಿಮೆ ಮಾಡಿ ಅಥವಾ ಹೆಡ್‌ಫೋನ್‌ಗಳನ್ನು ಬಳಸಿ.
- ಒಂದು ವಾಕ್ಯವು ಎರಡು ಬಾರಿ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ: ಪ್ರಸ್ತುತ ಆವೃತ್ತಿಗಳಲ್ಲಿ ಸ್ಥಿರವಾಗಿದೆ; ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ನವೀಕರಿಸಿ.
- ಇದು ಪರದೆಯನ್ನು ಟ್ಯಾಪ್ ಮಾಡುವುದಿಲ್ಲ ಅಥವಾ ಓದುವುದಿಲ್ಲ: ಪ್ರವೇಶಿಸುವಿಕೆ ಸೇವೆಯನ್ನು ಆನ್ ಮಾಡಿ (ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಅನುಮತಿಗಳು).
- ಇದು ಹಿನ್ನೆಲೆಯಲ್ಲಿ ನಿಲ್ಲುತ್ತದೆ: ಅಧಿಸೂಚನೆಗಳು ಮತ್ತು ಬ್ಯಾಟರಿ ಆಪ್ಟಿಮೈಸೇಶನ್ ವಿನಾಯಿತಿಯನ್ನು ಅನುಮತಿಸಿ; ತೇಲುವ ಕಣ್ಣಿಗೆ ಮೇಲ್ಪದರ.
- ಒಂದು ಉಪಕರಣವು ಅನುಮತಿಯನ್ನು ಕೇಳುತ್ತಲೇ ಇರುತ್ತದೆ: ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ → ಆಟೊಮೇಷನ್‌ನಲ್ಲಿ ಮಟ್ಟವನ್ನು ಬದಲಾಯಿಸಿ ಅಥವಾ ಕಾರ್ಡ್‌ಗೆ ಉತ್ತರಿಸಿ.
- Play Protect ಯಾವುದನ್ನಾದರೂ ನಿರ್ಬಂಧಿಸುತ್ತದೆ: ಅನುಮತಿಗಳ ಅಧ್ಯಾಯವನ್ನು ನೋಡಿ, ಅಥವಾ ಏಜೆಂಟ್ ಹಂತಗಳನ್ನು ಮಾರ್ಗದರ್ಶನ ಮಾಡಲು ಅವಕಾಶ ಮಾಡಿಕೊಡಿ.
- ಟರ್ಮಿನಲ್ ಅಥವಾ Linux ಪ್ರಾರಂಭವಾಗುವುದಿಲ್ಲ: ಅಪ್ಲಿಕೇಶನ್ ಪ್ರಾರಂಭದಲ್ಲಿ ಮೊದಲ ಬಾರಿ ಅನ್ಪ್ಯಾಕ್ ಮಾಡಲು ನಿರೀಕ್ಷಿಸಿ; ಉಚಿತ ಸಂಗ್ರಹಣೆಯನ್ನು ಪರಿಶೀಲಿಸಿ.
- ನವೀಕರಣವನ್ನು ಸ್ಥಾಪಿಸಲಾಗುವುದಿಲ್ಲ: ZYRAXON ಅನ್ನು ಸ್ಥಾಪಿಸುವ ಮೂಲವಾಗಿ ಅನುಮತಿಸಿ.
- ಪ್ರಕಟಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ: GitHub ಗೆ GitHub ಟೋಕನ್ ಸೇರಿಸಿ; ಸಾರ್ವಜನಿಕ ಲಿಂಕ್‌ಗಾಗಿ ಏಜೆಂಟ್ ಸುರಂಗವನ್ನು ಬಳಸಬಹುದು.
- ಒಂದು ಅಧ್ಯಾಯವು ಇಂಗ್ಲಿಷ್ ಅನ್ನು ತೋರಿಸುತ್ತದೆ: ಆ ಅಧ್ಯಾಯವು ಈ ರಚನೆಯಲ್ಲಿ ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ ಯಾವುದೇ ಪಠ್ಯವನ್ನು ಹೊಂದಿಲ್ಲ; ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ನವೀಕರಿಸಿ.
- ಏನೋ ವಿಚಿತ್ರ: ಕ್ಲೀನ್ ಪ್ರಾರಂಭಿಸಲು ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ನ್ಯಾವಿಗೇಶನ್ → ಹೊಸ ಸೆಶನ್ ಅನ್ನು ಬಳಸಿ (ಇದು ಚಾಟ್ ಇತಿಹಾಸವನ್ನು ಮಾತ್ರ ತೆರವುಗೊಳಿಸುತ್ತದೆ; ಮೆಮೊರಿ ಉಳಿಯುತ್ತದೆ).
