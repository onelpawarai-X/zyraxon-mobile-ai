ਸਮੱਸਿਆ ਨਿਪਟਾਰਾ
- ਕੋਈ ਜਵਾਬ ਨਹੀਂ: ਆਪਣੀ ਇੰਟਰਨੈਟ ਅਤੇ API ਕੁੰਜੀ ਦੀ ਜਾਂਚ ਕਰੋ (ਸੈਟਿੰਗਾਂ → ਪ੍ਰਦਾਤਾ ਅਤੇ API ਅਸਲ ਗਲਤੀ ਦਿਖਾਉਂਦਾ ਹੈ)। ਕੋਈ ਹੋਰ ਮਾਡਲ ਜਾਂ ਆਨ-ਡਿਵਾਈਸ ਮਾਡਲ ਅਜ਼ਮਾਓ।
- ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਕੁਝ ਨਹੀਂ ਕਰਦਾ: ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਦੀ ਇਜਾਜ਼ਤ ਦਿਓ; "ਮਾਈਕ ਨੂੰ ਚਾਲੂ ਰੱਖੋ" ਦੀ ਜਾਂਚ ਕਰੋ; ਪਛਾਣ ਭਾਸ਼ਾ ਦੀ ਜਾਂਚ ਕਰੋ।
- ZYRAXON ਖੁਦ ਸੁਣਦਾ ਹੈ: ਇਹ ਟੈਕਸਟ ਦੁਆਰਾ ਫਿਲਟਰ ਕੀਤਾ ਜਾਂਦਾ ਹੈ; ਜੇਕਰ ਅਜੇ ਵੀ ਅਜਿਹਾ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਵਾਲੀਅਮ ਘੱਟ ਕਰੋ ਜਾਂ ਹੈੱਡਫੋਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।
- ਇੱਕ ਵਾਕ ਦੋ ਵਾਰ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ: ਮੌਜੂਦਾ ਸੰਸਕਰਣਾਂ ਵਿੱਚ ਸਥਿਰ; ਐਪ ਨੂੰ ਅਪਡੇਟ ਕਰੋ।
- ਇਹ ਸਕ੍ਰੀਨ ਨੂੰ ਟੈਪ ਜਾਂ ਪੜ੍ਹ ਨਹੀਂ ਸਕੇਗਾ: ਪਹੁੰਚਯੋਗਤਾ ਸੇਵਾ (ਸੈਟਿੰਗਾਂ → ਅਨੁਮਤੀਆਂ) ਨੂੰ ਚਾਲੂ ਕਰੋ।
- ਇਹ ਬੈਕਗ੍ਰਾਉਂਡ ਵਿੱਚ ਰੁਕ ਜਾਂਦਾ ਹੈ: ਸੂਚਨਾਵਾਂ ਅਤੇ ਬੈਟਰੀ ਅਨੁਕੂਲਨ ਛੋਟ ਦੀ ਆਗਿਆ ਦਿਓ; ਫਲੋਟਿੰਗ ਅੱਖ ਲਈ ਓਵਰਲੇਅ.
- ਇੱਕ ਟੂਲ ਇਜਾਜ਼ਤ ਮੰਗਦਾ ਰਹਿੰਦਾ ਹੈ: ਸੈਟਿੰਗਾਂ → ਆਟੋਮੇਸ਼ਨ ਵਿੱਚ ਪੱਧਰ ਬਦਲੋ, ਜਾਂ ਕਾਰਡ ਦਾ ਜਵਾਬ ਦਿਓ।
- Play Protect ਕਿਸੇ ਚੀਜ਼ ਨੂੰ ਰੋਕਦਾ ਹੈ: ਅਨੁਮਤੀਆਂ ਅਧਿਆਇ ਦੇਖੋ, ਜਾਂ ਏਜੰਟ ਨੂੰ ਕਦਮਾਂ ਦੀ ਅਗਵਾਈ ਕਰਨ ਦਿਓ।
- ਟਰਮੀਨਲ ਜਾਂ Linux ਸ਼ੁਰੂ ਨਹੀਂ ਹੁੰਦਾ: ਐਪ ਸ਼ੁਰੂ ਹੋਣ 'ਤੇ ਪਹਿਲੀ ਵਾਰ ਅਨਪੈਕ ਕਰਨ ਦੀ ਉਡੀਕ ਕਰੋ; ਮੁਫਤ ਸਟੋਰੇਜ ਦੀ ਜਾਂਚ ਕਰੋ।
- ਅੱਪਡੇਟ ਇੰਸਟੌਲ ਨਹੀਂ ਹੋਵੇਗਾ: ZYRAXON ਨੂੰ ਇੱਕ ਸਥਾਪਨਾ ਸਰੋਤ ਵਜੋਂ ਆਗਿਆ ਦਿਓ।
- ਪ੍ਰਕਾਸ਼ਿਤ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ: GitHub ਲਈ GitHub ਟੋਕਨ ਸ਼ਾਮਲ ਕਰੋ; ਜਨਤਕ ਲਿੰਕ ਲਈ ਏਜੰਟ ਇੱਕ ਸੁਰੰਗ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦਾ ਹੈ।
- ਇੱਕ ਅਧਿਆਇ ਅੰਗਰੇਜ਼ੀ ਦਿਖਾਉਂਦਾ ਹੈ: ਇਸ ਬਿਲਡ ਵਿੱਚ ਉਸ ਚੈਪਟਰ ਵਿੱਚ ਤੁਹਾਡੀ ਭਾਸ਼ਾ ਵਿੱਚ ਕੋਈ ਟੈਕਸਟ ਨਹੀਂ ਹੈ; ਐਪ ਨੂੰ ਅਪਡੇਟ ਕਰੋ।
- ਕੁਝ ਅਜੀਬ: ਸਾਫ਼ ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਸੈਟਿੰਗਾਂ → ਨੈਵੀਗੇਸ਼ਨ → ਦੀ ਵਰਤੋਂ ਕਰੋ (ਇਹ ਸਿਰਫ਼ ਚੈਟ ਇਤਿਹਾਸ ਨੂੰ ਸਾਫ਼ ਕਰਦਾ ਹੈ; ਮੈਮੋਰੀ ਰਹਿੰਦੀ ਹੈ)।
