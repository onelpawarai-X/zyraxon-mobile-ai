ਚੈਟ ਸਕ੍ਰੀਨ ਅਤੇ ਹਰ ਬਟਨ
## ਸਕ੍ਰੀਨ ਦੇ ਸਿਖਰ 'ਤੇ
- Menu: ਤੁਹਾਡੀਆਂ ਚੈਟਾਂ ਵਾਲੀ ਖੱਬੀ ਦਰਾਜ਼ ਖੋਲ੍ਹਦਾ ਹੈ।
- Chat / Terminal / Code / Preview: ਮੁੱਖ ਦ੍ਰਿਸ਼ ਬਦਲਦੇ ਹਨ। Chat ਗੱਲਬਾਤ ਹੈ; Terminal ਅਸਲੀ ਟਰਮੀਨਲ ਹੈ; Code Git ਸਮੇਤ ਫਾਈਲ ਵਰਕਸਪੇਸ ਹੈ; Preview ਬਿਲਟ-ਇਨ ਬ੍ਰਾਊਜ਼ਰ ਹੈ।
- Aura: ਐਨੀਮੇਟਡ ਕਿਰਦਾਰ ਵਾਲੀ ਸਕ੍ਰੀਨ ਦਿਖਾਉਂਦਾ ਹੈ। ਇਸ ਦੇ ਪਾਸੇ ਦੇ ਬਟਨ Mic, Chat (ਗੱਲਬਾਤ ਤੇ ਵਾਪਸ) ਅਤੇ Refresh (ਕਲਾਊਡ ਨੂੰ ਦੁਬਾਰਾ ਜੋੜਦਾ ਅਤੇ ਮਾਡਲ ਸੂਚੀ ਮੁੜ ਲੋਡ ਕਰਦਾ ਹੈ) ਹਨ।
- Settings: ਅੱਠ ਸੈਟਿੰਗਾਂ ਭਾਗ ਖੋਲ੍ਹਦਾ ਹੈ।
- ਇੱਕ ਬੈਨਰ ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਦੀ ਸਥਿਤੀ ਦਿਖਾਉਂਦਾ ਹੈ: "ਸੁਣ ਰਿਹਾ ਹਾਂ…", "ਮਾਈਕ ਬੰਦ — ਟੈਪ ਕਰੋ", ਜਾਂ "ਬੋਲ ਰਿਹਾ ਹਾਂ… ਰੋਕਣ ਲਈ ਟੈਪ ਕਰੋ"।
- ਜਦੋਂ ਨਵਾਂ ਸੰਸਕਰਣ ਤਿਆਰ ਹੁੰਦਾ ਹੈ ਤਾਂ Download, Install ਅਤੇ Allow ਬਟਨਾਂ ਵਾਲਾ ਅੱਪਡੇਟ ਬੈਨਰ ਦਿਸਦਾ ਹੈ (ਅੱਪਡੇਟ ਵੇਖੋ)।

## ਖੱਬਾ ਮੀਨੂ (ਚੈਟਾਂ)
- "+ ਨਵੀਂ ਚੈਟ": ਨਵੀਂ ਗੱਲਬਾਤ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- ਸੂਚੀ ਵਿੱਚ ਹਰ ਚੈਟ ਉੱਤੇ, ਜਦੋਂ ਏਜੰਟ ਉੱਥੇ ਰੁੱਝਾ ਹੋਵੇ, ਚੱਲਣ ਦਾ ਨਿਸ਼ਾਨ ਦਿਸਦਾ ਹੈ। ਪੈਨਸਿਲ ਨਾਂ ਬਦਲਦੀ ਹੈ; ਕਰਾਸ ਮਿਟਾਉਂਦਾ ਹੈ (ਪੁਸ਼ਟੀ ਤੋਂ ਬਾਅਦ: ਉਸ ਦੇ ਸਾਰੇ ਸੁਨੇਹੇ ਮਿਟ ਜਾਂਦੇ ਹਨ)।
- ਥੀਮ: Horror (ਖੂਨ, ਅੱਗ ਅਤੇ ਪਰਛਾਵਾਂ), Dark (ਸਾਫ਼ ਗੂੜ੍ਹਾ ਸ਼ੀਸ਼ਾ) ਜਾਂ Light (ਚਮਕਦਾਰ ਸ਼ੀਸ਼ਾ) ਚੁਣੋ।

## ਸੁਨੇਹਾ ਪੱਟੀ
- Attach (ਪੇਪਰਕਲਿੱਪ): ਗੈਲਰੀ ਦੀ ਫ਼ੋਟੋ, ਕੈਮਰੇ ਦੀ ਫ਼ੋਟੋ, ਦਸਤਾਵੇਜ਼ ਸਕੈਨ (ਫ਼ੋਟੋ ਦੇ ਪਾਠ ਨੂੰ ਸੰਪਾਦਨ ਯੋਗ .docx ਵਿੱਚ ਬਦਲਦਾ ਹੈ), ਸਕ੍ਰੀਨ ਸਾਂਝੀ ਕਰਨੀ ਤਾਂ ਜੋ ਏਜੰਟ ਉਸ ਨੂੰ ਵੇਖ ਸਕੇ ("Screen watching" ਚਾਲੂ ਜਾਂ ਬੰਦ), ਅਤੇ ਆਡੀਓ ਜਾਂ ਵੀਡੀਓ ਫਾਈਲਾਂ। ਜੁੜੀਆਂ ਚੀਜ਼ਾਂ ਚਿਪ ਵਜੋਂ ਦਿਸਦੀਆਂ ਹਨ; ਕਰਾਸ ਇੱਕ ਹਟਾਉਂਦਾ ਹੈ, "Clear all" ਸਾਰੀਆਂ ਹਟਾਉਂਦਾ ਹੈ।
- Mode ਬਟਨ: Agent ਜਾਂ Build।
- Mic ਬਟਨ: ਹਮੇਸ਼ਾ ਸੁਣਨ ਵਾਲੇ ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਨੂੰ ਚਾਲੂ ਜਾਂ ਬੰਦ ਕਰਦਾ ਹੈ।
- Model ਬਟਨ: ਖੋਜ ਬਾਕਸ ਸਮੇਤ ਮਾਡਲ ਸੂਚੀ ਖੋਲ੍ਹਦਾ ਹੈ। "Live" ਨਿਸ਼ਾਨ ਵਾਲੇ ਮਾਡਲ ਆਪਣੀ ਆਵਾਜ਼ ਵਿੱਚ ਬੋਲ ਸਕਦੇ ਹਨ।
- Send: ਸੁਨੇਹਾ ਭੇਜਦਾ ਹੈ। ਜਦੋਂ ਏਜੰਟ ਕੰਮ ਕਰ ਰਿਹਾ ਹੁੰਦਾ ਹੈ ਤਾਂ ਇਹ Stop ਬਣ ਜਾਂਦਾ ਹੈ।
- ਇਨਪੁੱਟ Agent ਮੋਡ ਵਿੱਚ "ਮੈਂ ਕੀ ਕਰਾਂ?" ਅਤੇ Build ਮੋਡ ਵਿੱਚ "ਮੈਂ ਕੀ ਬਣਾਵਾਂ? ਛੋਟਾ ਦੱਸੋ" ਕਹਿੰਦਾ ਹੈ।

## ਸੁਨੇਹੇ
- Copy, Share ਅਤੇ Listen (ਸੁਨੇਹਾ ਉੱਚੀ ਪੜ੍ਹਦਾ ਹੈ; ਰੋਕਣ ਲਈ ਮੁੜ ਦਬਾਓ) ਹਰ ਸੁਨੇਹੇ ਹੇਠਾਂ ਹਨ।
- "Thinking" ਮਾਡਲ ਦੀ ਸੋਚ ਦਿਖਾਉਂਦਾ ਹੈ ਜੇ ਮਾਡਲ ਉਹ ਦਿੰਦਾ ਹੈ।
- ਏਜੰਟ ਜੋ ਕੋਡ ਲਿਖਦਾ ਹੈ ਉਹ ਇੱਕ ਡੱਬੇ ਵਿੱਚ ਲਾਈਵ, ਲਾਈਨ ਦਰ ਲਾਈਨ ਦਿਸਦਾ ਹੈ, Copy, Download ਅਤੇ Open ਸਮੇਤ।
- ਏਜੰਟ ਦੀਆਂ ਬਣਾਈਆਂ ਫਾਈਲਾਂ ਕਾਰਡ ਵਜੋਂ ਦਿਸਦੀਆਂ ਹਨ, Open (ਫ਼ੋਨ ਦੀ ਅਸਲੀ ਐਪ ਵਿੱਚ), Play, Share ਅਤੇ "Other app…" ਸਮੇਤ।
- ਤਸਵੀਰਾਂ, ਆਡੀਓ ਅਤੇ ਵੀਡੀਓ ਬਣਦੇ ਸਮੇਂ ਲਾਈਵ ਪ੍ਰਗਤੀ ਪ੍ਰਤੀਸ਼ਤ ਦਿਖਾਉਂਦੇ ਹਨ।
- ਟੂਲ ਕਾਰਡ ਦਿਖਾਉਂਦੇ ਹਨ ਕਿ ਏਜੰਟ ਕੀ ਕਰ ਰਿਹਾ ਹੈ: ਦੌੜਨਾ, ਕੀਤਾ, ਸਫ਼ਲਤਾ ਜਾਂ ਅਸਫਲ।

## ਪੈਨਲ (ਟੂਡੋ, ਟੂਲ, ਫਾਈਲਾਂ, ਸਬ-ਏਜੰਟ)
- ਟੋਡੋ ਬੋਰਡ: ਏਜੰਟ ਇੱਕ ਵੱਡੀ ਨੌਕਰੀ ਅਤੇ ਇਸਦੀ ਪ੍ਰਗਤੀ ਲਈ ਜੋ ਯੋਜਨਾ ਲਿਖਦਾ ਹੈ (n/ਕੁੱਲ ਕੀਤਾ ਗਿਆ)। ਤੁਸੀਂ ਆਪਣਾ ਕੰਮ ਜੋੜ ਸਕਦੇ ਹੋ ਅਤੇ ਕਾਰਜਾਂ ਨੂੰ ਮਿਟਾ ਸਕਦੇ ਹੋ।
- Tools: ਹਰ ਟੂਲ ਕਾਲ ਦੀ ਸੂਚੀ, ਲਾਈਵ ਸਥਿਤੀ ਸਮੇਤ।
- Files: ਏਜੰਟ ਦੀ ਬਣਾਈ ਹਰ ਫਾਈਲ, Open, Share, Publish ਅਤੇ Delete (ਪੁਸ਼ਟੀ ਸਮੇਤ) ਅਤੇ ਖੋਜ ਬਾਕਸ ਸਮੇਤ।
- Sub-agents: ਪਿਛੋਕੜ ਵਿੱਚ ਚੱਲ ਰਹੇ ਸਹਾਇਕ ਏਜੰਟ, Stop ਬਟਨ ਸਮੇਤ।
- Terminal ਟੈਬ: ਅਸਲੀ ਟਰਮੀਨਲ (ਫਾਈਲਾਂ ਅਤੇ ਟਰਮੀਨਲ ਅਧਿਆਇ ਵੇਖੋ)।

## Preview ਪੈਨਲ
- Back, Forward, Stop, Reload ਅਤੇ ਇੱਕ ਪਤਾ ਪੱਟੀ (ਵੈੱਬ ਪਤਾ ਲਿਖੋ, ਜਾਂ Google ਤੇ ਖੋਜੋ)।
- Open file: Word, Excel, PowerPoint, PDF, ਤਸਵੀਰਾਂ, Markdown, CSV, ਕੋਡ ਅਤੇ ਸਾਈਟਾਂ ਸਿੱਧਾ ਐਪ ਦੇ ਅੰਦਰ ਦਿਖਾਉਂਦਾ ਹੈ।
- Size: ਪੈਨਲ ਨੂੰ ਛੋਟਾ ਜਾਂ ਵੱਡਾ ਕਰੋ।
- Fix: ਪੰਨੇ ਦੀਆਂ ਸਮੱਸਿਆਵਾਂ (ਕੰਸੋਲ ਗਲਤੀਆਂ, ਫੇਲ੍ਹ ਲੋਡ) ਏਜੰਟ ਨੂੰ ਭੇਜਦਾ ਹੈ, ਜੋ ਉਨ੍ਹਾਂ ਨੂੰ ਪਿਛੋਕੜ ਵਿੱਚ ਠੀਕ ਕਰਦਾ ਹੈ।
- Pick part: ਪੰਨੇ ਦੇ ਕਿਸੇ ਹਿੱਸੇ ਤੇ ਟੈਪ ਕਰੋ, ਫਿਰ ਏਜੰਟ ਨੂੰ ਦੱਸੋ ਕਿ ਉਸ ਹਿੱਸੇ ਦਾ ਕੀ ਕਰਨਾ ਹੈ।
- Agent ਬਟਨ: ਪੰਨੇ ਬਾਰੇ ਕੁਝ ਪੁੱਛੋ; ਏਜੰਟ ਨੂੰ ਉਸ ਦੀ ਤਸਵੀਰ ਮਿਲਦੀ ਹੈ।
- Quick open: ਹਾਲੀਆ ਪੰਨਿਆਂ ਦੇ ਸ਼ਾਰਟਕੱਟ।

## Code ਵਰਕਸਪੇਸ
- ਖੱਬਾ ਪਾਸਾ: ਤੁਹਾਡੀਆਂ ਫਾਈਲਾਂ (ਨਵੀਂ ਫਾਈਲ, ਖੋਲ੍ਹੋ, ਸੰਭਾਲੋ)।
- ਸੰਪਾਦਕ: ਲਾਈਨਾਂ ਅਤੇ ਅੱਖਰ ਦਿਖਾਉਂਦਾ ਹੈ; ਏਜੰਟ ਦੇ ਕੀਤੇ ਬਦਲਾਅ ਤੁਰੰਤ ਦਿਸਦੇ ਹਨ।
- Git: ਨਵਾਂ ਰਿਪੋ, GitHub ਤੋਂ ਕਲੋਨ, ਸਕੈਨ, ਸਥਿਤੀ, ਸੁਨੇਹੇ ਨਾਲ commit, push, pull, ਸ਼ਾਖਾਵਾਂ, ਟੋਕਨ।
- Pull requests: ਬਣਾਓ, ਮਰਜ ਕਰੋ, ਬੰਦ ਕਰੋ। Workflows: ਰਨ ਸੂਚੀ, ਵਰਕਫਲੋ ਚਲਾਓ। Log ਕਮਾਂਡ ਦਾ ਆਊਟਪੁੱਟ ਦਿਖਾਉਂਦਾ ਹੈ।
