בנייה: אתרים, אפליקציות, תצוגה מקדימה ופרסום
## איך לשאול
- "עשה לי דף נחיתה לבית הקפה שלי." הסוכן בונה אותו מיד, מפעיל אותו בטלפון שלך ופותח אותו בתצוגה מקדימה. אתה מקבל 2-3 שורות המתארות את זה. שום דבר לא מתפרסם אלא אם אתה שואל.
- "בנה אפליקציית מטלות." נבנה ישירות עם ערימה הגיונית, רץ ומוצג. אחורי, מסד נתונים או התחברות רק אם תבקשו.
- "בנה אפליקציית ערימה מלאה." הסוכן שואל תחילה שאלה קצרה אחת על שפת הקצה האחורי, מסד הנתונים, ההתחברות והיכן הוא פועל, עם ברירות מחדל מומלצות, ואז בונה את כל זה עם נתוני בסיס ובודק זרימה מלאה אחת.
- "צור תוכנית Windows/Linux/macOS/Android." נכתב המקור, מתווסף זרימת עבודה של בנייה, הוא נדחף ונבנה בענן עם GitHub פעולות, ומקבלים את קישור ההורדה האמיתי.

## כְּלֵי עֲבוֹדָה
- `edit_file` ו-`write_file`: כתוב את הקבצים האמיתיים (קוד מלא, אף פעם לא תולים). `code_box` מראה אותם בשידור חי.
- `preview` (בטוח): הדפדפן האמיתי המובנה. פעולות: פתיחה (קישור, `localhost:PORT` או קובץ), טען מחדש, אחורה, קדימה, צילום מסך, גלילה, לחיצה, הקלדה, קריאת טקסט עמוד, שגיאות מסוף, eval. הסוכן בוחן את העבודה שלו לפני שהוא אומר שזה נעשה.
- `serve_local` (מערכת): מפעיל שרת אינטרנט בטלפון עבור תיקיה ומחזיר את הכתובת LAN שמכשירים אחרים ב-Wi-Fi שלך יכולים לפתוח.
- `publish_website` (מערכת): משרת אתר ביציאה ציבורית מהטלפון. `publish_cloudflare` (מערכת): מעלה אתר באינטרנט ללא חשבון דרך מנהרה Cloudflare ומחזירה קישור https ציבורי. `publish_github` (מערכת): מפרסם פרויקט למאגר GitHub (דפים) עם האסימון שלך.
- `git` (מערכת): clone, init, status, add, commit, push, pull, branch, checkout, log, diff עם האסימון השמור שלך. `github_pr` (מערכת): צור, רשום, מיזוג והגיב לבקשות משיכה. `github_actions` (מערכת): רשום זרימות עבודה, הפעל אותן, ריצות סקר וקריאת יומנים, כך שבניינים פועלים בענן מהטלפון.
- `build_app` (מערכת): בונה את הפרויקט הזה עם Gradle בטלפון ומתקין את התוצאה.
- `files_panel`, `todo_write`: דפדפן קבצים ולוח משימות.

## כללי איכות לפי הסוכן
פריסה מלאה, עיצוב רספונסיבי, JavaScript עובד, אנימציה, צבעים וגופנים עקביים (כהה ובהיר איפה שזה מתאים), לא תבנית גנרית. דף נחיתה הוא בדרך כלל 300–900 שורות; דברים גדולים יותר.

## אם משהו נראה שבור
לחץ על תקן בתצוגה מקדימה, או ספר לסוכן. זה קורא את המסוף, מתקן את הסיבה, פותח מחדש את הדף ובודק שוב.
