פתרון בעיות
- אין תשובה: בדוק את מפתח האינטרנט ומפתח ה-API שלך (הגדרות → ספקים וממשק API מציגים את השגיאה האמיתית). נסה דגם אחר או דגם במכשיר.
- המיקרופון לא עושה כלום: אפשר את הרשאת המיקרופון; סמן "שמור את המיקרופון דלוק"; בדוק את שפת הזיהוי.
- ZYRAXON שומע את עצמו: זה מסונן לפי טקסט; אם זה עדיין קורה, הנמיך את עוצמת הקול או השתמש באוזניות.
- משפט מופיע פעמיים: קבוע בגרסאות עדכניות; לעדכן את האפליקציה.
- זה לא יקיש או יקרא את המסך: הפעל את שירות הנגישות (הגדרות → הרשאות).
- זה נעצר ברקע: אפשר הודעות ופטור מאופטימיזציה של סוללה; שכבת העל לעין המרחפת.
- כלי ממשיך לבקש רשות: שנה את הרמה בהגדרות → אוטומציה, או ענו לכרטיס.
- Play Protect חוסם משהו: עיין בפרק ההרשאות, או תן לסוכן להנחות את השלבים.
- הטרמינל או Linux לא מתחילים: המתן לפריקה בפעם הראשונה בהפעלת האפליקציה; בדוק אחסון בחינם.
- העדכון לא יתקין: אפשר ZYRAXON כמקור התקנה.
- לא ניתן לפרסם: הוסף את האסימון GitHub עבור GitHub; לקישור ציבורי הסוכן יכול להשתמש במנהרה.
- פרק מראה אנגלית: לפרק זה אין טקסט בשפה שלך במבנה הזה; לעדכן את האפליקציה.
- משהו מוזר: השתמש בהגדרות → ניווט → הפעלה חדשה כדי להתחיל נקי (הוא מנקה את היסטוריית הצ'אט בלבד; הזיכרון נשאר).
