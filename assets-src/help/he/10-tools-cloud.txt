ענן, רשת, דגמים ועוזרים
## ענן ואינטרנט
- `web_search` (רשת): חפש באינטרנט האמיתי. `read_url` (רשת): אחזר דף כטקסט. `http_request` (רשת): כל קריאת HTTP (GET, POST, PUT, PATCH, DELETE) עם כותרות וגוף. `verify_url` (רשת): בדוק שקישור באמת קיים וקבל את הסטטוס האמיתי. `download_file` (אישי, רשת): הורד כתובת URL לקובץ.
- הסוכן פותח קישורים רק כאשר אתה מבקש ממנו.
- מודלים של AI פועלים בענן דרך הספקים שהוספת (ZYRAXON, ZYRAXON Apex סוכן ענן, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode). רשימת הדגמים נטענת בשידור חי ומתמלאת כאשר כל ספק עונה.
- בקשות בנייה, פרסום ומשיכה עוברות דרך GitHub ו-Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git`).
- הפעל "במכשיר בלבד" (הגדרות אוטומציה) ולא מתבצעת שיחת ענן כלל: אין ספק, אין אינטרנט, אין העלאה.

## MCP שרתים
MCP מאפשר לשירותים חיצוניים לתת לסוכן כלים נוספים. חבר את Canva, Cloudflare, Supabase, GitHub או שרת משלך לפי הכתובת שלו (אסימון אופציונלי). הכלים של שרתים מחוברים מצטרפים לרשימת הכלים של הסוכן בתור `server__tool`.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (ראה מה קשור ואיזה כלים קיימים), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (צפו במשאב לשינויים), `mcp_complete` (ארגומנטים של השלמה אוטומטית), `mcp_ping`, `mcp_log_level`. השיחות שלהם הן שיחות רשת, וכלים לא ידועים MCP מבקשים רשות כברירת מחדל.
- המסך MCP מפרט כל שרת עם סטטוס מחובר, הכלים שלו, המשאבים ותבניות הבקשות שלו, ולחצני הוספה, ניתוק, הסר, אפשר.

## סוכני משנה
`sub_agent` (מערכת): העברת חלקים של עבודה גדולה לסוכנים עוזרים שרצים ברקע. פעולות: השרצים, סטטוס, רשימה, תוצאה, הודעה, עצירה, המתן. כל אחד יכול להשתמש במודל שלו. הסוכן משלב ובודק את התוצאות שלהם לפני שהוא אומר "בוצע".

## דגם במכשיר
`on_device_model` (מערכת): רשום, טען והפעל מודל שפה שחי בטלפון, ללא אינטרנט. בהגדרות → דגם וזהות → במכשיר אתה מוריד דגמים (קטן עד גדול: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B...); אסימון Hugging Face הוא אופציונלי ודרוש רק עבור קבצים מגודרים. דגם טעון נזכר ונטען מחדש בעת ההשקה.

## ערוצי העברת הודעות
`channel_post` (מערכת) פותחת Telegram, WhatsApp, פייסבוק, Messenger, YouTube, X, Instagram, Gmail או SMS כשהטקסט שלך מוכן. אתה לוחץ על שלח בעצמך.
