Хмара, мережа, моделі та помічники
## Хмара та Інтернет
- `web_search` (мережа): шукайте в реальній мережі. `read_url` (мережа): отримати сторінку як текст. `http_request` (мережа): будь-який виклик HTTP (GET, POST, PUT, PATCH, DELETE) із заголовками та тілом. `verify_url` (мережа): перевірте, чи посилання дійсно існує, і дізнайтеся справжній статус. `download_file` (Особистий, мережевий): завантажити URL-адресу файлу.
- Агент відкриває посилання лише тоді, коли ви його про це просите.
- Моделі ШІ працюють у хмарі через доданих вами постачальників (ZYRAXON, ZYRAXON Apex хмарний агент, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode). Список моделей завантажується в реальному часі та заповнюється, коли кожен постачальник відповідає.
- Запити на збирання, публікацію та вилучення проходять через GitHub і Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git`).
- Увімкніть «лише на пристрої» (налаштування автоматизації), і хмарний виклик не здійснюватиметься взагалі: ні провайдер, ні Інтернет, ні завантаження.

## MCP серверів
MCP дозволяє зовнішнім службам надавати агенту додаткові інструменти. Підключіть Canva, Cloudflare, Supabase, GitHub або свій власний сервер за його адресою (додатковий маркер). Інструменти підключених серверів приєднуються до списку інструментів агента як `server__tool`.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (перегляньте, що пов’язано та які існують інструменти), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (перегляньте ресурс на предмет змін), `mcp_complete` (автозаповнення аргументів), `mcp_ping`, `mcp_log_level`. Їхні виклики є мережевими, а невідомі MCP інструменти запитують дозвіл за умовчанням.
- Екран MCP містить список кожного сервера зі статусом «Підключено», його інструменти, ресурси та шаблони підказок, а також кнопки «Додати», «Відключити», «Видалити», «Дозволити».

## Субагенти
`sub_agent` (Система): передайте частини великої роботи допоміжним агентам, які працюють у фоновому режимі. Дії: spawn, status, list, result, message, stop, wait. Кожен може використовувати свою модель. Агент об’єднує та перевіряє їхні результати, перш ніж сказати «готово».

## Модель на пристрої
`on_device_model` (Система): список, завантаження та запуск мовної моделі, яка живе на телефоні, без Інтернету. У налаштуваннях → Модель та ідентифікація → На пристрій ви завантажуєте моделі (від малих до великих: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B…); маркер Hugging Face необов’язковий і потрібен лише для закритих файлів. Завантажена модель запам'ятовується та перезавантажується під час запуску.

## Канали обміну повідомленнями
`channel_post` (Система) відкриває Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail або SMS із готовим текстом. Ви натискаєте відправити себе.
