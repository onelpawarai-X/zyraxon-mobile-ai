Усунення несправностей
- Немає відповіді: перевірте свій Інтернет та ключ API (параметри → Providers & API показують справжню помилку). Спробуйте іншу модель або модель на пристрої.
- Мікрофон нічого не робить: надайте дозвіл мікрофону; поставте прапорець «Тримати мікрофон увімкненим»; перевірте мову розпізнавання.
- ZYRAXON чує себе: це фільтрується за текстом; якщо це все одно відбувається, зменшіть гучність або використовуйте навушники.
- Речення з'являється двічі: виправлено в поточних версіях; оновити програму.
- Він не буде торкатися або читати екран: увімкніть службу доступності (Налаштування → Дозволи).
- Він зупиняється у фоновому режимі: дозволити сповіщення та звільнення від оптимізації акумулятора; накладка для плаваючого ока.
- Інструмент постійно запитує дозвіл: змініть рівень у налаштуваннях → Автоматизація або дайте відповідь на картку.
- Play Protect щось блокує: перегляньте розділ «Дозволи» або дозвольте агенту керувати цими кроками.
- Термінал або ZYRAXON OS не запускається: зачекайте на перше розпакування під час запуску програми; перевірити вільне зберігання.
- Оновлення не встановлюється: дозвольте ZYRAXON як джерело встановлення.
- Неможливо опублікувати: додайте маркер GitHub для GitHub; для публічного посилання агент може використовувати тунель.
- Розділ показує англійську: цей розділ не містить тексту вашою мовою в цій збірці; оновити програму.
- Щось дивне: використовуйте Налаштування → Навігація → Новий сеанс, щоб розпочати чистий (це очищає лише історію чату; пам’ять залишається).
