عیب یابی
- بدون پاسخ: اینترنت و کلید API خود را بررسی کنید (تنظیمات → ارائه دهندگان و API خطای واقعی را نشان می دهد). مدل دیگری یا یک مدل روی دستگاه را امتحان کنید.
- میکروفون هیچ کاری نمی کند: اجازه میکروفون را بدهید. "روشن نگه داشتن میکروفون" را علامت بزنید؛ زبان تشخیص را بررسی کنید
- ZYRAXON خودش را می شنود: این توسط متن فیلتر می شود. اگر باز هم اتفاق افتاد، صدا را کم کنید یا از هدفون استفاده کنید.
- یک جمله دو بار ظاهر می شود: در نسخه های فعلی ثابت شده است. به روز رسانی برنامه
- روی صفحه ضربه زده یا نمی‌خواند: سرویس دسترس‌پذیری (تنظیمات → مجوزها) را روشن کنید.
- در پس‌زمینه متوقف می‌شود: اجازه اعلان‌ها و معافیت بهینه‌سازی باتری. روکش برای چشم شناور
- ابزاری مدام اجازه می‌خواهد: سطح را در تنظیمات → اتوماسیون تغییر دهید، یا به کارت پاسخ دهید.
- Play Protect چیزی را مسدود می‌کند: فصل مجوزها را ببینید یا اجازه دهید نماینده مراحل را راهنمایی کند.
- ترمینال یا Linux شروع نمی شود: برای اولین بار در شروع برنامه منتظر بمانید. فضای ذخیره سازی رایگان را بررسی کنید
- به‌روزرسانی نصب نمی‌شود: ZYRAXON را به عنوان منبع نصب مجاز کنید.
- نمی توان منتشر کرد: علامت GitHub را برای GitHub اضافه کنید. برای یک پیوند عمومی، نماینده می تواند از یک تونل استفاده کند.
- یک فصل انگلیسی را نشان می دهد: آن فصل هیچ متنی به زبان شما در این ساخت ندارد. به روز رسانی برنامه
- چیز عجیبی: از تنظیمات → پیمایش → جلسه جدید برای شروع پاکسازی استفاده کنید (فقط سابقه چت را پاک می‌کند، حافظه باقی می‌ماند).
