ట్రబుల్షూటింగ్
- సమాధానం లేదు: మీ ఇంటర్నెట్ మరియు API కీని తనిఖీ చేయండి (సెట్టింగ్‌లు → ప్రొవైడర్లు & API నిజమైన లోపాన్ని చూపుతుంది). మరొక మోడల్ లేదా ఆన్-డివైస్ మోడల్‌ని ప్రయత్నించండి.
- మైక్రోఫోన్ ఏమీ చేయదు: మైక్రోఫోన్ అనుమతిని అనుమతించండి; "మైక్ ఆన్‌లో ఉంచు"ని తనిఖీ చేయండి; గుర్తింపు భాషను తనిఖీ చేయండి.
- ZYRAXON స్వయంగా వింటుంది: ఇది టెక్స్ట్ ద్వారా ఫిల్టర్ చేయబడింది; ఇది ఇప్పటికీ జరిగితే, వాల్యూమ్ తగ్గించండి లేదా హెడ్‌ఫోన్‌లను ఉపయోగించండి.
- ఒక వాక్యం రెండుసార్లు కనిపిస్తుంది: ప్రస్తుత సంస్కరణల్లో పరిష్కరించబడింది; అనువర్తనాన్ని నవీకరించండి.
- ఇది స్క్రీన్‌ను నొక్కదు లేదా చదవదు: యాక్సెసిబిలిటీ సేవను ఆన్ చేయి (సెట్టింగ్‌లు → అనుమతులు).
- ఇది నేపథ్యంలో ఆగిపోతుంది: నోటిఫికేషన్‌లు మరియు బ్యాటరీ ఆప్టిమైజేషన్ మినహాయింపును అనుమతించండి; తేలియాడే కన్ను కోసం అతివ్యాప్తి.
- ఒక సాధనం అనుమతి అడుగుతూనే ఉంటుంది: సెట్టింగ్‌లు → ఆటోమేషన్‌లో స్థాయిని మార్చండి లేదా కార్డ్‌కి సమాధానం ఇవ్వండి.
- Play Protect ఏదైనా బ్లాక్ చేస్తుంది: అనుమతుల అధ్యాయాన్ని చూడండి లేదా ఏజెంట్‌ను దశలను గైడ్ చేయనివ్వండి.
- టెర్మినల్ లేదా Linux ప్రారంభం కాదు: యాప్ ప్రారంభంలో మొదటిసారి అన్‌ప్యాక్ కోసం వేచి ఉండండి; ఉచిత నిల్వను తనిఖీ చేయండి.
- నవీకరణ ఇన్‌స్టాల్ చేయబడదు: ZYRAXONని ఇన్‌స్టాల్ సోర్స్‌గా అనుమతించండి.
- ప్రచురించడం సాధ్యం కాదు: GitHub కోసం GitHub టోకెన్‌ను జోడించండి; పబ్లిక్ లింక్ కోసం ఏజెంట్ సొరంగం ఉపయోగించవచ్చు.
- ఒక అధ్యాయం ఆంగ్లాన్ని చూపుతుంది: ఈ బిల్డ్‌లో మీ భాషలో ఆ అధ్యాయానికి వచనం లేదు; అనువర్తనాన్ని నవీకరించండి.
- అసాధారణమైనది: క్లీన్‌గా ప్రారంభించడానికి సెట్టింగ్‌లు → నావిగేషన్ → కొత్త సెషన్‌ను ఉపయోగించండి (ఇది చాట్ చరిత్రను మాత్రమే క్లియర్ చేస్తుంది; మెమరీ అలాగే ఉంటుంది).
