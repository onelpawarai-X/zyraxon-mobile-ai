すべての設定画面を 1 つずつ
設定には 8 つのセクションがあります。各セクションにはサブ画面用の錠剤があります。最後に使用したセクションが次回再び開きます。

## 1. 言語と翻訳 → アプリとツールの言語
アプリ全体とエージェントのツールメッセージの言語を選択します。リストを検索していずれかをタップします。画面には、現在の言語と、UI 翻訳とツール メッセージ翻訳がオンになっているかどうかが表示されます。 60の言語が利用可能です。 「言語」の章を参照してください。

## 2.音声とマイク
- 音声プロファイル: 女性または男性の声、速度、ピッチ、「答えを読み上げる」、テスト音声、ベンガル語音声ダウンロードのヒントを選択します。
- マイクと言語: 認識言語、マイクをオンにしたまま、話すのをやめると自動送信。
- ライブ音声: 音声読み上げのオン/オフ、ステータス、リアルタイム モデルのリスト。

## 3. プロバイダーと API
- AI プロバイダー: 独自の API キー (ZYRAXON、OpenCode 無料割り当て、Groq、Gemini、OpenAI、Grok、Claude、DeepSeek、OpenRouter) および ZYRAXON Apex クラウド エージェント。保存されたキーは、プロバイダーの実際のカタログを読み取ることによって検証され、モデル数または正確なエラーが表示されます。ボタンをクリックすると、キーを作成する ZYRAXON Web サイトが開きます。
- GitHub: パブリッシュ、Git プッシュおよびプル リクエスト用の GitHub アクセス トークン (リポジトリ スコープが必要)。トークンを保存するか削除します。設定されているかどうかはステータスに表示されます。

## 4. アップデート → アプリのアップデート
現在のバージョンを表示し、新しいリリースを確認し、進行状況バーを表示してダウンロードしてインストールします。チャット、記憶、設定は残ります。 Android のインストールに許可が必要な場合は、ボタンをクリックしてその設定を開きます。

## 5. モデルとアイデンティティ
- アイデンティティ: キャラクターを選択します (「キャラクター」の章を参照)。
- モデル: 検索ボックス、「すべてのモデル」および「カスタム」フィルターを備えたライブ モデル カタログ。まずは高速モデルから。
- オンデバイス: オフラインで実行されるモデルをダウンロード、ロード、アンロードします。小さいものから大きいものまで並べ替えられます。オプションの Hugging Face トークン;ロード済み、ロード中、および失敗した状態を示します。

## 6. オーラとテーマ
- テーマ: ホラー、ダークまたはライト。
- オーラと背景: 微妙な色相制御によるオーラのスタイルと色 (血、ピンク、紫、空、緑、火)。オーラのサイズ、グローの強さ、回転速度、パネルの透明度。浮遊する目（オン/オフ、デザイン、画面端、音声コマンド/ウェイクワード、独自の追加）。シェーダモード。カスタム背景 URL (mp4、gif、または画像);アニメーションの速度。

## 7. セキュリティとプライバシー
- アプリロック: パスワード (4 ～ 8 桁) または 3×3 ドット パターン。 2 回入力して確認します。ロックを外します。
- 権限: Play Protect ヘルプ付きの「権限」の章のリスト。
- プライバシーとデータ: すべてのデータは電話機内に残ります。ボタン: すべてのメモリを削除、チャット履歴を削除、GitHub トークンを削除。

## 8. システム
このセクションには横にスクロールする独自のボタンの列があるため、何も押されることはありません。
- 自動化: 承認レベルおよびオンデバイスのみ (「承認レベル」を参照)。
- ナビゲーション: ジャンプ先の領域のリスト — 「上部にボタンはなく、すべてがここにあります」 — ⌘ ZX システム シェル、「新しいセッション」ボタン (クリーン スタートのためにチャット履歴を消去します)、メッセージ数、マイクの切り替えを含みます。
- 記憶: ZYRAXON が記憶する事実を含むローカル SQL 記憶。キーと値を追加します。すべて削除します。
- スキル ガイド: 能力例 (メッセージング アプリ、ウェブサイト構築、スクリーン リーダー、トーチ、カメラ、Wi-Fi および設定) とフレーズ例の簡単なリスト。
- 自動化ハブ: スキル、自動操縦、お金、タイムライン、頭脳、コール エージェントを 1 か所にまとめました (自動化ハブを参照)。

## 9. ドキュメント
システムとは別に、設定内の独自のセクション。このガイド: 21 章、検索ボックス、および言語チップの行。アプリ内のすべての言語は、アプリ内ですでに完全に記述されています。携帯電話では何も翻訳されず、それを読むためにインターネットは必要ありません。
