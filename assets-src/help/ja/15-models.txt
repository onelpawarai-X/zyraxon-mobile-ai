プロバイダー、モデル、キー
## プロバイダー
ZYRAXON (独自の回線と Apex クラウド エージェント、常に接続)、OpenCode (無料割り当て)、Groq (非常に高速な Llama)、Gemini、OpenAI、Grok (xAI)、Claude、DeepSeek、および OpenRouter。設定 → プロバイダーと API にキーを追加します。キーは電話機に保存され、プロバイダーのカタログと照合され、各プロバイダーが応答するとモデルがセレクターにストリーミングされます。

## モデルの選択
メッセージ バーのモデル ボタンを使用するか、設定 → モデルとアイデンティティ → モデルを使用します。名前で検索し、すべてまたはカスタムでフィルターします。選択内容は保存され、起動時に復元されます。更新によって保存されたモデルが置き換えられることはありません。 Live とマークされたモデルは、自分の声で話すことができます (「Live voice」を参照)。

## オンデバイスモデル
設定 → モデルと ID → デバイス上。モデルは携帯電話上で実行され、データはそこに残りません。ファイルは大きいため (数百 MB ～ 数 GB)、Wi-Fi にダウンロードしてください。それらは小さいものから大きいものまでリストされています。 RAM が少ない携帯電話では、最も軽いものを選択してください。ツール呼び出しは、Gemma バンドルと FunctionGemma バンドルでサポートされています。 Hugging Face トークンはゲートされたファイルのみに使用されます。ロードされたモデルは記憶されます。

## ZYRAXON ウェブサイト
zyraxonai.lovable.app: アカウント (電子メールまたは Google) を作成し、設定、API キー / アクセス トークンを開き、キーを作成してアプリに貼り付けます。キーがなくても、オンデバイス モデルやローカル ツールでアプリを使用できます。

## コストとデータ
クラウド プロバイダーは、独自のルールに従って料金を請求します。 「オンデバイスのみ」をオンにすると、プロバイダーには何も送信されません。
