Seguridad at privacy
- Ang lahat ng data ni ZYRAXON ay nasa iyong telepono: mga chat, memorya, ledger, mga kasanayan, timeline, index ng utak. Walang itinatago sa isang ZYRAXON server.
- Ang mga modelo ng cloud ay tumatanggap lamang ng kung ano ang kinakailangan para sa pagliko na iyong ipinadala. Sa "On-device lang" walang ipinapadala.
- Ang mga prompt at mga file ng wika na ipinadala sa app ay naka-encrypt sa loob ng APK.
- Lock ng app: magtakda ng password o pattern sa Mga Setting → Seguridad at privacy → Lock ng app. ZYRAXON pagkatapos ay magla-lock kapag binuksan mo ito o bumalik mula sa background. Tinatanggal ng "Remove lock" ang naka-save na password o pattern.
- Ang mga antas ng pag-apruba ay nagbabantay sa bawat tawag sa tool sa code (tingnan ang mga antas ng Pag-apruba). Palaging nagtatanong ang hindi kilalang mga tool.
- Maaari mong burahin ang: lahat ng memorya, ang kasaysayan ng chat, at ang iyong GitHub token, bawat isa ay may isang button sa Privacy at data.
- Kaligtasan: kung sasabihin mong may nananakot o sumusunod sa iyo, o gusto ang iyong telepono o data, i-lock muna ng ahente ang telepono (kung naka-on ang pahintulot ng device-admin) at pagkatapos ay kausapin ka nang mahinahon.
- Mga Pagbabayad: bago ang anumang pagbabayad o paglipat, sasabihin ng ahente kung ano ang babayaran nito at hihilingin sa iyo na kumpirmahin.
- Katapatan: may sinabi lang ang ahente na gumana pagkatapos nitong makakita ng resulta. Hindi ito kailanman nag-imbento ng mga link, file o resulta.
- Content Shield: anuman ang nabasa ng ahente mula sa labas — ang screen ng isa pang app, isang web page, isang mensahe, isang file, isang nakakonektang server — ay naka-check sa code para sa text na sumusubok na magbigay ng mga order sa ahente (sa maraming wika, kabilang ang text na nakatago sa mga hindi nakikitang character). Ang kahina-hinalang text ay nabakuran kaya tinatrato ito ng modelo bilang data lamang. Gaano ito kahigpit sumusunod sa iyong antas ng pag-apruba: Itinuturing ng naka-lock ang anumang kahina-hinala bilang pagalit; Ang mga pinangangasiwaang bakod ay may kahina-hinalang text at, kapag ang text ay malinaw na pagalit, i-lock ang natitirang bahagi ng pagliko na iyon upang ang bawat pagbabago ng tool ay magtanong muna sa iyo (sinasabi ng card kung bakit); Ang balanse ay kumikilos lamang sa malinaw na pagalit na teksto at tanging mga tool sa antas ng system ang humihinto upang magtanong; Awtomatikong pinapatay ang kalasag — walang na-scan, huminto, minarkahan o binago. Isang bagong mensahe mula sa iyo ang nag-clear nito.
