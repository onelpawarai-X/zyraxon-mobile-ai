الملفات والطرفية والنظام
## الملفات
- `read_file` و`list_dir` و`find_files` و`grep_files` (Safe): القراءة، والسرد، والعثور بنمط الاسم، والبحث عن نص داخل الملفات.
- `write_file` و`edit_file`: إنشاء الملفات أو تغييرها. يفعل `edit_file` كل شيء: ملف جديد، أو إعادة كتابة كاملة، أو بحث واستبدال دقيق؛ وتظهر الشيفرة مباشرة في المحادثة. `delete_file` (System): حذف ملف أو مجلد.
- أي مجلد مسموح (/sdcard وDownload وDocuments وبطاقة SD …). أعطِ مسارًا كاملًا ويُستخدم كما كُتب.
- يفتح الوكيل ما يصنعه: `open_file` (Safe) يفتح ملفًا في التطبيق الحقيقي بالهاتف أو داخل معاينة ZYRAXON.

## الطرفيات (اثنتان حقيقيتان)
- android: قشرة الهاتف نفسه (busybox مع `sh`)، داخل صندوق حماية التطبيق. `run_shell` (System) يشغّل أمرًا هناك بعيدًا عن الأنظار.
- linux: نظام Unix الكامل الخاص بـ ZYRAXON، مدمج في التطبيق: bash وapt/pkg وgit حقيقي وpython وnode وclang. يعمل دون اتصال. `linux_run` (System) يشغّل أمرًا هناك.
- `terminal_run` (System): يشغّل سطرًا في تبويب Terminal الذي تشاهده، لترى العمل وتتولى زمام الأمر. استخدم القشرة android أو linux. `terminal_open` يجلب تبويب Terminal إلى الأمام (فقط عندما تطلب).
- `system_shell` (System): أمر على مستوى النظام، فوق صندوق حماية التطبيق، كما تفعل قشرة النظام؛ ومع Shizuku أو root يمكنه الوصول إلى أبعد من ذلك بكثير.
- لا يوجد حد زمني افتراضي؛ فـ `apt upgrade` الكبير أو البناء يعمل حتى النهاية.

## Shizuku (وصول النظام)
`setup_shizuku` (System) يعدّ Shizuku المضمّن داخل ZYRAXON: فحص الحالة، والتثبيت، والفتح، وطلب الإذن. أنت وحدك تستطيع النقر على Install وAllow؛ ويخبرك الوكيل بالخطوة في سطر واحد ويفعل الباقي.

## الأعمال الطويلة والتوقيت
- `background_command` (System): أمر يستمر في العمل بعد إغلاق التطبيق (تنزيل كبير، استنساخ، بناء)، مع إشعار وزر Stop.
- `schedule_command` (System): تشغيل أمر في وقت حقيقي ("بعد 10 دقائق"، "عند الساعة 2 صباحًا")؛ يحتفظ Android بالمؤقت، فيعمل والتطبيق مغلق.
- `wait` (Safe): انتظر عمدًا (ثوانٍ، أو حتى يُفتح منفذ، أو يظهر ملف، أو ينتهي أمر) بدل التخمين.

## استخدامات Linux
تثبيت الحزم (`apt install …`)، وتشغيل سكربتات Python أو Node، وترجمة C، واستخدام git، وتشغيل الخوادم، وzip وunzip، وcurl، وffmpeg. يُفك النظام بهدوء عند بدء التطبيق ويبقى عبر عمليات إعادة التشغيل.

## شاشة الطرفية
تبويب Terminal طرفية حقيقية مع تبويب ⌘ ZX. اكتب أوامرك أو شاهد أوامر الوكيل. في شاشة Navigation بالإعدادات اختصار إلى قشرة النظام وزر "New session" يمسح سجل المحادثة لبدء جديد.
