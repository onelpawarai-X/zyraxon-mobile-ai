استكشاف الأخطاء
- لا جواب: افحص الإنترنت ومفتاح API (الإعدادات ← Providers & API تعرض الخطأ الحقيقي). جرّب نموذجًا آخر أو نموذجًا على الجهاز.
- الميكروفون لا يفعل شيئًا: امنح إذن الميكروفون؛ وافحص "Keep the mic on"؛ وافحص لغة التعرف.
- ZYRAXON يسمع نفسه: يُرشَّح هذا بالنص؛ وإن استمر فاخفض الصوت أو استخدم سماعات.
- تظهر جملة مرتين: أُصلح في الإصدارات الحالية؛ حدّث التطبيق.
- لا ينقر ولا يقرأ الشاشة: شغّل خدمة إمكانية الوصول (الإعدادات ← Permissions).
- يتوقف في الخلفية: اسمح بالإشعارات واستثناء تحسين البطارية؛ والتراكب للعين العائمة.
- أداة تستمر في طلب الإذن: غيّر المستوى في الإعدادات ← Automation، أو أجب عن البطاقة.
- Play Protect يحجب شيئًا: راجع فصل الأذونات، أو دع الوكيل يرشدك في الخطوات.
- لا تبدأ الطرفية أو Linux: انتظر فك الضغط أول مرة عند بدء التطبيق؛ وافحص المساحة الحرة.
- لا يُثبَّت التحديث: اسمح لـ ZYRAXON كمصدر تثبيت.
- لا يمكن النشر: أضف رمز GitHub لـ GitHub؛ ولرابط عام يستطيع الوكيل استخدام نفق.
- يظهر فصل بالإنجليزية: ليس لذلك الفصل نص بلغتك في هذا الإصدار؛ حدّث التطبيق.
- شيء غريب: استخدم الإعدادات ← Navigation ← New session لبدء نظيف (يمسح سجل المحادثة فقط؛ وتبقى الذاكرة).
