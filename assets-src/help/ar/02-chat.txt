شاشة المحادثة وكل زر فيها
## أعلى الشاشة
- Menu: يفتح الدرج الأيسر بمحادثاتك.
- Chat / Terminal / Code / Preview: تبدّل العرض الرئيسي. Chat هي المحادثة؛ Terminal هي الطرفية الحقيقية؛ Code هي مساحة الملفات مع Git؛ Preview هو المتصفح المدمج.
- Aura: يعرض شاشة الشخصية المتحركة. أزرارها الجانبية هي Mic وChat (العودة إلى المحادثة) وRefresh (يعيد اتصال السحابة ويعيد تحميل قائمة النماذج).
- Settings: يفتح أقسام الإعدادات الثمانية.
- شريط يعرض حالة الميكروفون: "أستمع…" أو "الميكروفون مغلق — اضغط" أو "أتحدث… اضغط للإيقاف".
- عندما يكون إصدار جديد جاهزًا يظهر شريط تحديث بأزرار Download وInstall وAllow (راجع التحديثات).

## القائمة اليسرى (المحادثات)
- "+ محادثة جديدة": تبدأ محادثة جديدة.
- تُظهر كل محادثة في القائمة علامة تشغيل عندما يكون الوكيل مشغولًا فيها. القلم يعيد تسميتها؛ والصليب يحذفها (بعد تأكيد: تُمحى كل رسائلها).
- السمة: اختر Horror (دم ونار وظل) أو Dark (زجاج داكن نظيف) أو Light (زجاج ساطع).

## شريط الرسائل
- Attach (مشبك الورق): صورة من المعرض، وصورة من الكاميرا، ومسح مستند (يحوّل النص في الصورة إلى ملف .docx قابل للتحرير)، ومشاركة الشاشة ليراها الوكيل ("Screen watching" تشغيل أو إيقاف)، وملفات الصوت أو الفيديو. تظهر العناصر المرفقة كبطاقات؛ الصليب يزيل واحدة، و"Clear all" يزيلها كلها.
- زر الوضع: Agent أو Build.
- زر Mic: يشغّل أو يوقف الميكروفون الذي يستمع دائمًا.
- زر النموذج: يفتح قائمة النماذج مع مربع بحث. النماذج المعلّمة "Live" تستطيع التحدث بصوتها الخاص.
- Send: يرسل الرسالة. وأثناء عمل الوكيل يصبح Stop.
- يقول الحقل "ماذا أفعل؟" في وضع Agent و"ماذا أبني؟ قلها باختصار" في وضع Build.

## الرسائل
- Copy وShare وListen (يقرأ الرسالة بصوت عالٍ؛ اضغط مرة أخرى للإيقاف) تحت كل رسالة.
- "Thinking" يُظهر تفكير النموذج عندما يوفره النموذج.
- الشيفرة التي يكتبها الوكيل تظهر مباشرة في صندوق، سطرًا سطرًا، مع Copy وDownload وOpen.
- الملفات التي ينشئها الوكيل تظهر كبطاقات مع Open (في التطبيق الحقيقي بالهاتف) وPlay وShare و"Other app…".
- تعرض الصور والصوت والفيديو نسبة تقدّم حية أثناء صنعها.
- تُظهر بطاقات الأدوات ما يفعله الوكيل: قيد التشغيل، تم، نجح أو فشل.

## اللوحات (المهام، الأدوات، الملفات، الوكلاء الفرعيون)
- لوحة Todo: الخطة التي يكتبها الوكيل لعمل كبير وتقدّمها (n/الإجمالي أُنجز). يمكنك إضافة مهمتك الخاصة وحذف المهام.
- Tools: قائمة بكل استدعاء أداة مع حالة حية.
- Files: كل ملف أنشأه الوكيل، مع Open وShare وPublish وDelete (مع تأكيد) ومربع بحث.
- Sub-agents: وكلاء مساعدون يعملون في الخلفية، مع زر Stop.
- تبويب Terminal: الطرفية الحقيقية (راجع فصل الملفات والطرفية).

## لوحة Preview
- Back وForward وStop وReload وشريط عنوان (اكتب عنوان ويب أو ابحث في Google).
- Open file: يعرض Word وExcel وPowerPoint وPDF والصور وMarkdown وCSV والشيفرة والمواقع داخل التطبيق مباشرة.
- Size: صغّر اللوحة أو كبّرها.
- Fix: يرسل مشكلات الصفحة (أخطاء وحدة التحكم، وتحميلات فاشلة) إلى الوكيل الذي يصلحها في الخلفية.
- Pick part: انقر على جزء من الصفحة ثم أخبر الوكيل بما يفعله بذلك الجزء.
- زر Agent: اسأل عن الصفحة؛ يتلقى الوكيل صورة لها.
- Quick open: اختصارات إلى الصفحات الأخيرة.

## مساحة الشيفرة
- الجانب الأيسر: ملفاتك (ملف جديد، فتح، حفظ).
- المحرر: يعرض الأسطر والأحرف؛ تظهر التغييرات التي يجريها الوكيل فورًا.
- Git: مستودع جديد، واستنساخ من GitHub، وفحص، وحالة، وcommit برسالة، وpush، وpull، وفروع، ورمز.
- Pull requests: إنشاء ودمج وإغلاق. Workflows: عرض التشغيلات، وتشغيل workflow. Log يعرض مخرجات الأوامر.
