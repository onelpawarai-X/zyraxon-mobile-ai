每个设置屏幕一一对应
设置有八个部分。每个部分的子屏幕都有药丸。您上次使用的部分下次将重新打开。

## 1. 语言和翻译 → 应用程序和工具语言
选择整个应用程序和代理工具消息的语言。搜索列表并点击其中一项。屏幕显示当前语言以及 UI 翻译和工具消息翻译是否打开。有 60 种语言可供选择。请参阅语言章节。

## 2. 语音和麦克风
- 语音配置文件：选择女声或男声、速度、音调、“大声朗读答案”、测试语音、孟加拉语语音下载提示。
- 麦克风和语言：识别语言，保持麦克风打开，停止说话时自动发送。
- 实时语音：语音到语音开/关、状态、实时模型列表。

## 3. 提供商和 API
- AI 提供商：您自己的 API 密钥（ZYRAXON、OpenCode 免费配额、Groq、Gemini、OpenAI、Grok、Claude、DeepSeek、OpenRouter）和 ZYRAXON Apex 云代理。保存的密钥通过读取提供商的真实目录进行验证，并显示模型计数或确切的错误。按钮可打开您在其中创建密钥的 ZYRAXON 网站。
- GitHub：您的 GitHub 访问令牌（需要存储库范围）用于发布、Git 推送和拉取请求。保存或删除token；状态显示是否已设置。

## 4.更新→应用程序更新
显示当前版本，检查是否有较新版本，使用进度条下载并安装。您的聊天记录、内存和设置都会保留。如果 Android 需要安装权限，则会有一个按钮打开该设置。

## 5. 型号及标识
- 身份：选择角色（参见角色章节）。
- 模型：带有搜索框、“所有模型”和“自定义”过滤器的实时模型目录；首先是快速模型。
- 设备端：下载、加载和卸载离线运行的模型；从小到大排序；可选的 Hugging Face 标记；显示已加载、正在加载和失败状态。

## 6. 气场与主题
- 主题：恐怖、黑暗或光明。
- 光环&背景：光环风格和颜色（血、粉、紫、天、绿、火），具有精细的色调控制；光环大小、发光强度、旋转速度、面板透明度；浮动眼睛（开/关、设计、屏幕边缘、语音命令/唤醒词，添加您自己的）；着色器模式；自定义背景 URL（mp4、gif 或图像）；动画速度。

## 7. 安全与隐私
- 应用锁：密码（4-8位）或3×3点阵图案；输入两次确认；移除锁。
- 权限：权限章节中的列表，有 Play Protect 帮助。
- 隐私和数据：所有数据都保留在手机上。按钮：删除所有内存、删除聊天记录、删除GitHub令牌。

## 8. 系统
该部分有自己的一排按钮，可以横向滚动，因此不会挤压任何东西。
- 自动化：批准级别且仅限设备上（请参阅批准级别）。
- 导航：要跳转到的区域列表 - “顶部没有按钮，一切都在这里” - 包括 ⌘ ZX 系统 shell、“新会话”按钮（删除聊天记录以重新开始）、消息计数和麦克风切换。
- 内存：本地SQL内存，包含事实ZYRAXON记忆；添加键和值；全部删除。
- 技能指南：示例能力的快速列表（消息应用程序、网站构建、屏幕阅读器、手电筒、相机、Wi-Fi 和设置）以及示例短语。
- 自动化中心：技能、自动驾驶仪、金钱、时间线、大脑和呼叫代理集中在一处（请参阅自动化中心）。

## 9. 文档
“设置”中有自己的部分，与系统分开。本指南：二十一章、一个搜索框和一个语言芯片行。应用程序中的每种语言都已在应用程序内完整编写 - 您的手机上不会翻译任何内容，也不需要互联网即可阅读。
