故障排除
- 没有答案：检查您的互联网和 API 密钥（设置 → 提供商和 API 显示真正的错误）。尝试其他模型或设备上的模型。
- 麦克风不执行任何操作：允许麦克风权限；选中“保持麦克风打开”；检查识别语言。
- ZYRAXON 听到自己的声音：这是通过文本过滤的；如果仍然出现这种情况，请降低音量或使用耳机。
- 一句话出现两次：当前版本已修复；更新应用程序。
- 它不会点击或阅读屏幕：打开辅助功能服务（设置 → 权限）。
- 它在后台停止：允许通知和电池优化豁免；浮动眼睛的覆盖层。
- 工具不断请求许可：更改设置 → 自动化中的级别，或应答卡片。
- Play Protect 阻止某些内容：请参阅“权限”一章，或让代理指导步骤。
- 终端或Linux未启动：等待应用程序启动时首次解压；检查免费存储空间。
- 更新将无法安装：允许 ZYRAXON 作为安装源。
- 无法发布：为GitHub添加GitHub令牌；对于公共链路，代理可以使用隧道。
- 某个章节显示英语：该章节在此版本中没有您的语言的文本；更新应用程序。
- 奇怪的是：使用设置 → 导航 → 新会话开始清理（它仅清除聊天历史记录；内存保留）。
