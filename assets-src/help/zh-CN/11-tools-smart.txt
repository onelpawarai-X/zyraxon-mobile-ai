技能、自动驾驶仪、金钱、时间线和撤消、大脑、呼叫代理和记忆
您可以通过交谈来使用所有这些：说出您想要的内容，然后代理就会调用正确的工具。这里列出了每个操作及其选项。

## 技能——边做边教
技能是客服人员通过观看您执行一次而学到的一项电话任务。它存储如何再次找到每个元素（它的 id、单词和邻居，而不是它的屏幕位置），因此当应用程序的布局发生变化时它仍然可以工作。
- 添加技能：`skill_record`（个人）。说“以<名字>的身份学习这个”。 `action: start`（有名字）开始录音；然后执行任务 — 打开应用程序，点击、键入、按键；每一步都被记录下来。 `action: stop` 保存它。在停止时，您可以传递 `params` 将键入的值转换为参数（例如电话号码变为 `number`，金额变为 `amount`）和 `description`。 `action: status` 告诉您录音是否已开启。
- 运行技能：`skill_run`（个人）。为其参数提供 `args`，例如数量和金额。它会重播一小部分步骤，并在应用程序更改时自行修复。如果其中一个步骤失败，结果会显示哪一步以及屏幕上显示的内容，然后代理手动完成其余部分。
- 列出技能：`skill_list`（安全）显示名称、参数、步骤以及每次运行的频率。加上名称并导出即可创建可共享的 `.zxskill` 文件。
- 共享和加载：`skill_import`（个人）从下载或共享文件中加载 `.zxskill` 文件作为技能。
- 删除技能：`skill_delete`（系统）。
- 示例：“了解我如何通过我的钱包应用程序向 Rahim 发送 500 美元”→ 您执行一次 → 下次“向 Karim 发送 700 美元”。

## 自动驾驶仪——“当 X 发生时，执行 Y”
规则会自行唤醒代理，它会在不询问您的情况下完成任务。
- 添加：`autopilot_add`（系统）。种类：短信、通知、通话、每日、一次、间隔、电池、应用程序。仅填写规则需要的字段：`from`（发件人姓名或号码或应用程序标题）、`any`（至少其中一个单词）、`all`（每个单词）、`none`（这些单词都不是）、`time`“HH:MM”（每天）、`in_minutes` 或 `at_ms`（一次）、`every_minutes`（间隔）、`below`（电池百分比）、 `pkg`（应用程序包或名称，用于应用程序和通知规则）。代理会将您的句子转换为这些字段。结果列出了仍然需要的任何权限（短信、通知访问......），并且代理要求您将其打开。
- 示例：“当我的钱包应用程序收到付款短信时，将其添加到我的分类帐中。” “每天早上八点，告诉我天气。” “二十分钟后，提醒我把面包拿出来。” “每30分钟，喝水提醒。” “当电池电量低于 15% 时，请告诉我。” “当有人打电话给我时，记下号码。” “当我打开银行应用程序时，提醒我检查预算。”
- 列表：`autopilot_list`（安全）显示每条规则及其下一次运行时间以及触发频率。
- 暂停或恢复：`autopilot_toggle`（系统）。删除：`autopilot_remove`（系统），按 ID 或标题。
- 当规则触发时，您会收到一条消息，代理就会完成这项工作。

## 资金分类账（个人CFO）
- `ledger_scan`（个人）：将钱包和银行短信读取到私人分类账中：收入、支出、费用、余额和类别。 `days` 表示回溯多远（默认 30）。启用 `auto` 后，每条新的资金短信都会自行添加，并且当预算通过时您会收到警告。适用于任何国家/地区的任何货币的钱包和银行信息。
- `ledger_report`（个人）：今天、昨天、一周、一个月或全部。格式化文本（现成的口头摘要）或 xlsx（为您打开的包含交易和类别总计的 Excel 文件）。
- `ledger_budget`（个人）：为某个类别设置每月预算（食品、账单、交通、购物、手机充值、转账……）； 0 的限制将其删除；它毫无争议地列出了预算和当前的警告。
- 代理人从不发明金钱数字；它从账本中读取它们。

## 时间轴和撤消
- 代理所做的所有操作都会写入时间线（最后 400 个操作）。文件更改会保留之前内容的副本。
- `timeline_list`（安全）：代理最近做了什么，每个都有一个 ID，以及哪些更改可以撤消。
- `timeline_undo`（个人）：`id` 撤消一次写入、编辑或删除 — 文件完全按原样返回（不存在的文件将再次删除）。 `since_id` 撤消从该 id 开始的所有内容，最新的在前。当你说“把它拿回来”或“像以前一样放回去”时使用它。
- 撤消涵盖文件写入、编辑和删除。已运行的命令（例如安装某些内容或发送消息）无法以这种方式撤消。
- 聊天消息：要删除整个对话，请使用左侧菜单中的铅笔和十字，或设置 → 隐私和数据 → 删除聊天记录，或导航 → 新会话。

## Brain——文件的第二个记忆
- `brain_index`（安全）：在文件夹或文件（文本、Markdown、CSV、Word、Excel、PowerPoint）以及可选的 SMS 收件箱（`sms` 上）上构建或刷新脱机索引。在第一次搜索之前和新文件出现之后运行它。默认是您的工作区。
- `brain_search`（安全）：用你自己的话问，“我的租房合同在哪里？” — 它可以以任何语言离线工作。 `kind` 是文件或短信； `days` 限制最近的项目。使用 `open_file` 打开找到的文件。

## 呼叫代理
- `call_agent`（个人）：打开、关闭或状态的操作。 `owner` 是它所说的名字（“我是<所有者>的助手”）。 `answer_after_seconds`（默认 6）让您先接听。当有电话打来而您无法接听时，它会用呼叫者的语言打招呼，询问姓名和原因，回答简单的问题，礼貌地挂断电话并告诉您摘要。
- `call_log`（安全）：其应答的呼叫摘要，最新的在前。
- 需要呼叫和电话状态权限。

## 记忆
- `memory_write`、`memory_read`、`memory_delete`（安全）：关于您的持久事实（姓名、偏好、人员、日期、项目）存在于本地数据库中，并且在重新启动后仍然有效。说“记住这个”，它就会按顺序写出来；如果有问题，就会被删除或重写。每一次旧的对话也会被保留，甚至几个月后，与你所说的相匹配的过去的对话也会自动出现。
- 在设置 → 系统 → 内存中查看和更改所有内容（键、值、保存、全部删除）。
