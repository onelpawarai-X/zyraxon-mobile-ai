安全和隐私
- ZYRAXON 的所有数据都存储在您的手机上：聊天、内存、账本、技能、时间线、大脑索引。 ZYRAXON 服务器上不保存任何内容。
- 云模型仅接收您发送的回合所需的内容。对于“仅限设备上”，根本不会发送任何内容。
- 应用程序中附带的提示和语言文件在 APK 内加密。
- 应用程序锁定：在设置 → 安全和隐私 → 应用程序锁定中设置密码或图案。 ZYRAXON 然后在您打开它或从后台返回时锁定。 “解除锁定”会删除已保存的密码或图案。
- 批准级别保护代码中的每个工具调用（请参阅批准级别）。未知的工具总是会询问。
- 您可以擦除：所有内存、聊天历史记录和您的 GitHub 令牌，每一项都可以通过“隐私和数据”中的一个按钮来擦除。
- 安全：如果您说有人威胁或跟踪您，或者想要您的手机或数据，代理会先锁定手机（如果设备管理员权限已打开），然后平静地与您交谈。
- 付款：在任何付款或转账之前，代理会说明将支付的金额并要求您确认。
- 诚实：代理商在看到结果后才说某件事有效。它从不发明链接、文件或结果。
- 内容屏蔽：代理从外部读取的任何内容（另一个应用程序的屏幕、网页、消息、文件、连接的服务器）都会在代码中检查试图向代理发出命令的文本（在许多语言中，包括用不可见字符隐藏的文本）。可疑文本被隔离，因此模型仅将其视为数据。其严格程度取决于您的批准级别：锁定将任何可疑的行为视为敌对；受监督的围栏会屏蔽可疑文本，并且当文本明显具有敌意时，会锁定该回合的其余部分，因此每个更改工具都会首先询问您（卡片上会说明原因）；平衡仅对明显敌对的文本起作用，并且只有系统级工具停止询问；自动完全关闭防护罩 - 不会扫描、停止、标记或更改任何内容。您发送的新消息会将其清除。
