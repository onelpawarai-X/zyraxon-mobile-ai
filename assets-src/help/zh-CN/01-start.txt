入门
ZYRAXON 是位于您 Android 手机内的助手。它会与你交谈，倾听你的声音，并且可以做真正的工作：打开应用程序、在屏幕上点击和打字、打电话给别人、编写文件、构建网站和应用程序、运行 Linux 系统、制作图片、音频、视频和办公文档，并在几个月内记住你。它适用于您所说的任何语言。

## 最初几分钟
- 首次启动时 ZYRAXON 会显示一条简短通知，表明代理可以自行对您的手机进行操作。按“知道了，开始”继续。
- 添加 AI 密钥（设置 → 提供商和 API → AI 提供商）。粘贴您喜欢的任何提供商的密钥（ZYRAXON、Groq、Gemini、OpenAI、Grok、Claude、DeepSeek、OpenRouter、OpenCode）。当您保存密钥时，应用程序会读取该提供商的目录并检查其是否真实，以便您看到真正的“已连接”和模型数量。
- 没有钥匙？您仍然可以使用设备上的模型（设置 → 模型和身份 → 设备上）。他们在没有互联网的情况下通过手机运行。
- 使用消息栏中的模型按钮选择模型和角色（设置 → 模型和身份 → 身份）。
- 当某项功能需要权限时授予权限（请参阅“权限”一章）。客服人员还可以一键为您打开权限对话框。
- 只需说话或打字即可。 “为我的面包店制作一个登陆页面”、“打开 YouTube 并播放歌曲”、“我的电池是什么？”、“给妈妈打电话”。

## 两种工作方式
消息框旁边有一个模式按钮，有两种模式：代理和构建。请参阅模式章节。

## 东西在哪里
- 左侧菜单：您的聊天记录、新聊天记录、重命名、删除和主题切换。
- 聊天屏幕：消息、待办事项板、工具列表、文件、终端。
- 预览和代码面板：查看和编辑代理构建的内容。
- 设置：八个部分，本文档一一介绍。
- 本文档：设置 → 文档（您在此处）。
