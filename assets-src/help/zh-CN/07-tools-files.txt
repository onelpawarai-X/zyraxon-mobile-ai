文件、终端和系统
## 文件
- `read_file`、`list_dir`、`find_files`、`grep_files`（安全）：读取、列出、按名称模式查找以及搜索文件内的文本。
- `write_file`、`edit_file`：创建或更改文件。 `edit_file` 完成这一切：新文件、完全重写或精确查找和替换；该代码实时显示在聊天中。 `delete_file`（系统）：删除文件或文件夹。
- 允许任何文件夹（/sdcard、下载、文档、SD 卡...）。给出完整路径，并按书面形式使用。
- 代理打开它所做的内容：`open_file`（安全）在手机的真实应用程序中或ZYRAXON的预览中打开文件。

## 终端（两个真实的）
- android：手机自己的 shell（busybox 加 `sh`），位于应用程序的沙箱内。 `run_shell`（系统）在看不见的地方运行命令。
- linux：ZYRAXON自己的完整Unix系统，内置于应用程序中：bash、apt/pkg、real git、python、node、clang。它可以离线工作。 `linux_run`（系统）在那里运行命令。
- `terminal_run`（系统）：在您正在观看的“终端”选项卡中运行一行，以便您可以看到它工作并接管。使用 shell android 或 linux。 `terminal_open` 将“终端”选项卡置于前面（仅当您询问时）。
- `system_shell`（系统）：系统级命令，位于应用程序沙箱之上，与系统 shell 的方式相同；使用 Shizuku 或 root 可以达到更多。
- 没有默认的时间限制；一个大的 `apt upgrade` 或构建运行到最后。

## Shizuku（系统访问）
`setup_shizuku`（系统）设置Shizuku，捆绑在ZYRAXON内：检查状态、安装、打开、请求权限。只有您可以点击安装并允许；代理会在一行中告诉您步骤并完成其余的工作。

## 长期工作和时间安排
- `background_command`（系统）：关闭应用程序（大下载、克隆、构建）后继续运行的命令，带有通知和停止按钮。
- `schedule_command`（系统）：实时运行命令（“10 分钟后”、“凌晨 2 点”）； Android 保存计时器，因此它会在应用程序关闭时运行。
- `wait`（安全）：有目的地等待（几秒钟，直到端口打开、文件出现、命令完成）而不是猜测。

## Linux用途
安装软件包 (`apt install …`)、运行 Python 或 Node 脚本、编译 C、使用 git、运行服务器、压缩和解压缩、curl、ffmpeg。当应用程序启动时，系统会安静地解压，并在重新启动后保持不变。

## 终端屏幕
终端选项卡是带有 ⌘ ZX 选项卡的真实终端。输入您自己的命令或观看代理的命令。设置中的导航屏幕有一个系统 shell 的快捷方式和一个“新会话”按钮，可以清除聊天历史记录以重新开始。
