模式：Agent 和 Build
有两种模式，通过消息框旁边的模式按钮选择。你的选择会一直保留，直到你更改。实时语音不是第三种模式；它是一种可以在设置中开启的说话方式（参见语音章节）。

## Agent
"手机和系统的完全自动化。"一切都是开放的：读取并操控手机屏幕、打开应用、通话、消息、相机、文件、终端和 Linux、Git、预览、媒体、子代理、MCP 服务器、技能、autopilot 等等。当你想让手机上的某件事被完成，或只是想聊聊天时，请选择 Agent。

## Build
"全栈应用、网站和自动化。"代理是一个构建引擎：从一句简短的话出发，它会完成整个作品，运行它，查看它并展示给你。它拥有文件、终端、Git、预览、发布、媒体、记忆和待办面板。手机控制、子代理和设备锁属于 Agent 模式；如果在 Build 中需要它们，请切换模式。
- 落地页或网站：说明它的用途。代理会立即构建它，在你的手机上启动，并在 Preview 面板中打开，然后告诉你它做了什么。除非你要求，否则它不会发布。
- 应用：说出你想要什么，它就按要求构建应用。只有在你要求时才会添加后端、数据库或登录。
- Full-stack：当你要求后端或数据库时，代理会先问你一个关于选择的简短问题（语言、数据库、登录、运行位置），并给出它的推荐，在你回答后再构建。

## "询问"的含义
当代理真正需要你做决定时，它会先做完其他所有事情，附上推荐问一个简短的问题，然后等待。你的回答会从它停下的地方继续工作。
