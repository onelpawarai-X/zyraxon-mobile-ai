समस्यानिवारण
- उत्तर नाही: तुमची इंटरनेट आणि API की तपासा (सेटिंग्ज → प्रदाता आणि API वास्तविक त्रुटी दर्शविते). दुसरे मॉडेल किंवा ऑन-डिव्हाइस मॉडेल वापरून पहा.
- मायक्रोफोन काहीही करत नाही: मायक्रोफोनला परवानगी द्या; "माइक चालू ठेवा" तपासा; ओळख भाषा तपासा.
- ZYRAXON स्वतः ऐकतो: हे मजकूराद्वारे फिल्टर केले जाते; तरीही असे होत असल्यास, आवाज कमी करा किंवा हेडफोन वापरा.
- एक वाक्य दोनदा दिसते: वर्तमान आवृत्त्यांमध्ये निश्चित; ॲप अपडेट करा.
- ते स्क्रीनवर टॅप किंवा वाचणार नाही: प्रवेशयोग्यता सेवा चालू करा (सेटिंग्ज → परवानग्या).
- हे पार्श्वभूमीत थांबते: सूचना आणि बॅटरी ऑप्टिमायझेशन सूटला अनुमती द्या; तरंगणाऱ्या डोळ्यासाठी आच्छादन.
- एक साधन परवानगी मागत राहते: सेटिंग्ज → ऑटोमेशनमध्ये स्तर बदला किंवा कार्डला उत्तर द्या.
- Play Protect काहीतरी अवरोधित करते: परवानग्या प्रकरण पहा किंवा एजंटला चरणांचे मार्गदर्शन करू द्या.
- टर्मिनल किंवा ZYRAXON OS सुरू होत नाही: ॲप सुरू झाल्यावर प्रथमच अनपॅक होण्याची प्रतीक्षा करा; विनामूल्य स्टोरेज तपासा.
- अपडेट इंस्टॉल होणार नाही: ZYRAXON ला इंस्टॉल स्त्रोत म्हणून परवानगी द्या.
- प्रकाशित करू शकत नाही: GitHub साठी GitHub टोकन जोडा; सार्वजनिक दुव्यासाठी एजंट बोगदा वापरू शकतो.
- एक अध्याय इंग्रजी दर्शवितो: या बिल्डमध्ये त्या अध्यायात तुमच्या भाषेत कोणताही मजकूर नाही; ॲप अपडेट करा.
- काहीतरी विचित्र: स्वच्छ सुरू करण्यासाठी सेटिंग्ज → नेव्हिगेशन → नवीन सत्र वापरा (हे फक्त चॅट इतिहास साफ करते; मेमरी राहते).
