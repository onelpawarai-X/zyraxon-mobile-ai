ผู้ให้บริการ รุ่น และกุญแจ
## ผู้ให้บริการ
ZYRAXON (สายของตัวเองและตัวแทนคลาวด์ Apex เชื่อมต่อตลอดเวลา), OpenCode (โควต้าฟรี), Groq (ลามะเร็วมาก), Gemini, OpenAI, Grok (xAI), Claude, DeepSeek และ OpenRouter เพิ่มคีย์ใด ๆ ในการตั้งค่า → ผู้ให้บริการ & API รหัสจะถูกบันทึกไว้ในโทรศัพท์ของคุณ ตรวจสอบกับแค็ตตาล็อกของผู้ให้บริการ และโมเดลจะสตรีมไปยังตัวเลือกเมื่อผู้ให้บริการแต่ละรายรับสาย

## การเลือกรุ่น
ใช้ปุ่มโมเดลในแถบข้อความหรือการตั้งค่า → โมเดลและเอกลักษณ์ → โมเดล ค้นหาตามชื่อ กรองทั้งหมดหรือกำหนดเอง ตัวเลือกของคุณจะถูกบันทึกและกู้คืนเมื่อเปิดตัว การรีเฟรชจะไม่แทนที่โมเดลที่คุณบันทึกไว้ รุ่นที่ทำเครื่องหมายว่า Live สามารถพูดด้วยเสียงของตนเองได้ (ดูเสียงสด)

## รุ่นบนอุปกรณ์
การตั้งค่า → รุ่นและตัวตน → บนอุปกรณ์ โมเดลทำงานบนโทรศัพท์โดยไม่มีข้อมูลเหลืออยู่ ไฟล์มีขนาดใหญ่ (หลายร้อย MB ถึงไม่กี่ GB) ดังนั้นให้ดาวน์โหลดใน Wi-Fi มีรายการเล็กไปใหญ่ บนโทรศัพท์ที่มี RAM น้อยให้เลือกรุ่นที่เบาที่สุด การเรียกเครื่องมือได้รับการสนับสนุนโดยชุด Gemma และ FunctionGemma โทเค็น Hugging Face ใช้สำหรับไฟล์ที่มีรั้วรอบขอบชิดเท่านั้น จดจำโมเดลที่โหลดไว้

## เว็บไซต์ ZYRAXON
zyraxonai.lovable.app: สร้างบัญชี (อีเมลหรือ Google) เปิดการตั้งค่า คีย์ API / โทเค็นการเข้าถึง สร้างคีย์และวางลงในแอป หากไม่มีรหัส คุณยังคงใช้แอปกับรุ่นในอุปกรณ์และเครื่องมือในเครื่องได้

## ต้นทุนและข้อมูล
ผู้ให้บริการคลาวด์จะเรียกเก็บเงินคุณตามกฎของพวกเขาเอง เมื่อเปิด "บนอุปกรณ์เท่านั้น" จะไม่มีการส่งไปยังผู้ให้บริการใดๆ
