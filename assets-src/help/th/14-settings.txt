ทุกหน้าจอการตั้งค่าทีละรายการ
การตั้งค่ามีแปดส่วน แต่ละส่วนจะมียาสำหรับหน้าจอย่อย ส่วนสุดท้ายที่คุณใช้จะถูกเปิดอีกครั้งในครั้งถัดไป

## 1. ภาษาและการแปล → ภาษาของแอปและเครื่องมือ
เลือกภาษาของทั้งแอปและข้อความเครื่องมือของตัวแทน ค้นหารายการแล้วแตะรายการใดรายการหนึ่ง หน้าจอจะแสดงภาษาปัจจุบันและดูว่าการแปล UI และการแปลข้อความเครื่องมือเปิดอยู่หรือไม่ มี 60 ภาษา ดูบทภาษา

## 2. เสียงและไมโครโฟน
- โปรไฟล์เสียง: เลือกเสียงผู้หญิงหรือผู้ชาย ความเร็ว ระดับเสียง "อ่านคำตอบออกเสียง" ทดสอบเสียง คำแนะนำในการดาวน์โหลดเสียงภาษาเบงกาลี
- ไมโครโฟนและภาษา: ภาษาในการจดจำ เปิดไมโครโฟนไว้ ส่งอัตโนมัติเมื่อคุณหยุดพูด
- เสียงสด: เปิด/ปิดคำพูดเป็นคำพูด สถานะ รายการโมเดลเรียลไทม์

## 3. ผู้ให้บริการและ API
- ผู้ให้บริการ AI: คีย์ API ของคุณเอง (ZYRAXON, OpenCode โควต้าฟรี, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter) และตัวแทนระบบคลาวด์ ZYRAXON Apex รหัสที่บันทึกไว้ได้รับการตรวจสอบโดยการอ่านแค็ตตาล็อกจริงของผู้ให้บริการ และแสดงจำนวนรุ่นหรือข้อผิดพลาดที่แน่นอน ปุ่มจะเปิดเว็บไซต์ ZYRAXON ที่คุณสร้างรหัส
- GitHub: โทเค็นการเข้าถึง GitHub ของคุณ (ต้องการขอบเขต repo) สำหรับการเผยแพร่ Git คำขอแบบพุชและพุล บันทึกโทเค็นหรือลบออก สถานะจะแสดงหากมีการตั้งค่าไว้

## 4. อัปเดต → อัปเดตแอป
แสดงเวอร์ชันปัจจุบัน ตรวจสอบรุ่นที่ใหม่กว่า ดาวน์โหลดพร้อมแถบความคืบหน้า และติดตั้ง แชท หน่วยความจำ และการตั้งค่าของคุณยังคงอยู่ หาก Android ต้องการสิทธิ์ในการติดตั้ง ปุ่มจะเปิดการตั้งค่านั้น

## 5. รูปแบบและเอกลักษณ์
- ข้อมูลประจำตัว: เลือกตัวละคร (ดูบทตัวละคร)
- โมเดล: แค็ตตาล็อกโมเดลสดพร้อมช่องค้นหา ตัวกรอง "ทุกรุ่น" และ "กำหนดเอง" รุ่นที่รวดเร็วก่อน
- บนอุปกรณ์: ดาวน์โหลด โหลด และยกเลิกการโหลดโมเดลที่ทำงานแบบออฟไลน์ เรียงจากเล็กไปใหญ่ โทเค็นเสริม Hugging Face; แสดงสถานะโหลด กำลังโหลด และล้มเหลว

## 6. ออร่าและธีม
- ธีม: สยองขวัญ ความมืด หรือแสงสว่าง
- ออร่าและพื้นหลัง: รูปแบบและสีออร่า (เลือด, ชมพู, ม่วง, ท้องฟ้า, เขียว, ไฟ) พร้อมการควบคุมเฉดสีอย่างละเอียด ขนาดออร่า, ความแรงของแสง, ความเร็วในการหมุน, ความโปร่งใสของแผง; ตาลอย (เปิด/ปิด, การออกแบบ, ขอบหน้าจอ, คำสั่งเสียง/คำปลุก, เพิ่มของคุณเอง); โหมดเชเดอร์; URL พื้นหลังที่กำหนดเอง (mp4, gif หรือรูปภาพ); ความเร็วของภาพเคลื่อนไหว

## 7. ความปลอดภัยและความเป็นส่วนตัว
- ล็อคแอพ: รหัสผ่าน (4–8 หลัก) หรือรูปแบบ 3 × 3 จุด; ยืนยันโดยป้อนสองครั้ง ถอดล็อค
- สิทธิ์: รายการในบทสิทธิ์พร้อมความช่วยเหลือ Play Protect
- ความเป็นส่วนตัวและข้อมูล: ข้อมูลทั้งหมดยังคงอยู่ในโทรศัพท์ ปุ่ม: ลบหน่วยความจำทั้งหมด, ลบประวัติการแชท, ลบโทเค็น GitHub

## 8. ระบบ
ส่วนนี้มีปุ่มเรียงกันเป็นแถวซึ่งเลื่อนไปด้านข้าง ดังนั้นจึงไม่มีอะไรถูกบีบ
- ระบบอัตโนมัติ: ระดับการอนุมัติและบนอุปกรณ์เท่านั้น (ดูระดับการอนุมัติ)
- การนำทาง: รายการพื้นที่ที่จะข้ามไป — "ไม่มีปุ่มด้านบน ทุกอย่างอยู่ที่นี่" — รวมถึงเชลล์ระบบ ⌘ ZX ปุ่ม "เซสชันใหม่" (ลบประวัติการแชทเพื่อเริ่มต้นใหม่ทั้งหมด) จำนวนข้อความ และการสลับไมโครโฟน
- หน่วยความจำ: หน่วยความจำภายในเครื่อง SQL พร้อมด้วยข้อเท็จจริง ZYRAXON จำได้; เพิ่มคีย์และค่า ลบทั้งหมด
- คู่มือทักษะ: รายการตัวอย่างความสามารถโดยย่อ (แอปส่งข้อความ การสร้างเว็บไซต์ โปรแกรมอ่านหน้าจอ ไฟฉาย กล้อง Wi-Fi และการตั้งค่า) พร้อมวลีตัวอย่าง
- ศูนย์กลางระบบอัตโนมัติ: ทักษะ หม้อแปลงไฟฟ้าอัตโนมัติ เงิน ไทม์ไลน์ สมอง และเจ้าหน้าที่รับสายในที่เดียว (ดูฮับระบบอัตโนมัติ)

## 9. เอกสารประกอบ
ส่วนของตัวเองในการตั้งค่า แยกจากระบบ คู่มือนี้: ยี่สิบเอ็ดบท ช่องค้นหา และแถวชิปภาษา ทุกภาษาในแอปได้รับการเขียนออกมาอย่างครบถ้วนภายในแอปแล้ว ไม่มีการแปลใดๆ บนโทรศัพท์ของคุณ และไม่จำเป็นต้องใช้อินเทอร์เน็ตในการอ่าน
