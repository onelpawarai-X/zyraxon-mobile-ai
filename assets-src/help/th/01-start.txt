เริ่มต้นใช้งาน
ZYRAXON คือผู้ช่วยที่อยู่ภายในโทรศัพท์ Android ของคุณ มันพูดคุยกับคุณ ฟังคุณ และสามารถทำงานได้จริง: เปิดแอป แตะและพิมพ์บนหน้าจอ โทรหาผู้อื่น เขียนไฟล์ สร้างเว็บไซต์และแอป เรียกใช้ระบบ ZYRAXON OS สร้างรูปภาพ เสียง วิดีโอ และเอกสารสำนักงาน และจดจำคุณตลอดหลายเดือน มันทำงานได้ในภาษาใด ๆ ที่คุณพูด

## นาทีแรก
- ในการเปิดตัวครั้งแรก ZYRAXON จะแสดงการแจ้งเตือนสั้นๆ ว่าตัวแทนสามารถดำเนินการกับโทรศัพท์ของคุณได้ด้วยตัวเอง กด "เข้าใจแล้ว เริ่ม" เพื่อดำเนินการต่อ
- เพิ่มคีย์ AI (การตั้งค่า → ผู้ให้บริการ & API → ผู้ให้บริการ AI) วางรหัสสำหรับผู้ให้บริการที่คุณต้องการ (ZYRAXON, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode) เมื่อคุณบันทึกคีย์ แอปจะอ่านแค็ตตาล็อกของผู้ให้บริการและตรวจสอบจริง ดังนั้นคุณจึงเห็น "การเชื่อมต่อ" ที่แท้จริงและจำนวนรุ่น
- ไม่มีกุญแจเหรอ? คุณยังคงใช้รุ่นบนอุปกรณ์ได้ (การตั้งค่า → รุ่นและข้อมูลระบุตัวตน → บนอุปกรณ์) พวกเขาทำงานบนโทรศัพท์โดยไม่มีอินเทอร์เน็ต
- เลือกโมเดลด้วยปุ่มโมเดลในแถบข้อความ และอักขระ (การตั้งค่า → โมเดลและตัวตน → ตัวตน)
- ให้สิทธิ์เมื่อคุณสมบัติต้องการ (ดูบทสิทธิ์) เจ้าหน้าที่ยังสามารถเปิดกล่องโต้ตอบการอนุญาตให้คุณได้ด้วยการแตะเพียงครั้งเดียว
- เพียงแค่พูดคุยหรือพิมพ์ "สร้างหน้า Landing Page สำหรับร้านเบเกอรี่ของฉัน", "เปิด YouTube และเล่นเพลง", "แบตเตอรี่ของฉันคืออะไร", "โทรหาแม่"

## ทั้งสองวิธีในการทำงาน
ถัดจากกล่องข้อความจะมีปุ่มโหมดที่มีสองโหมด: Agent และ Build ดูบทโหมด

## สิ่งต่าง ๆ อยู่ที่ไหน
- เมนูด้านซ้าย: แชทของคุณ แชทใหม่ เปลี่ยนชื่อ ลบ และสลับธีม
- หน้าจอแชท: ข้อความ กระดานสิ่งที่ต้องทำ รายการเครื่องมือ ไฟล์ เทอร์มินัล
- แผงแสดงตัวอย่างและโค้ด: ดูและแก้ไขสิ่งที่ตัวแทนสร้าง
- การตั้งค่า: แปดส่วน ครอบคลุมทีละส่วนในเอกสารนี้
- เอกสารนี้: การตั้งค่า → เอกสารประกอบ (คุณอยู่ที่นี่)
