การแก้ไขปัญหา
- ไม่มีคำตอบ: ตรวจสอบอินเทอร์เน็ตและคีย์ API ของคุณ (การตั้งค่า → ผู้ให้บริการและ API แสดงข้อผิดพลาดจริง) ลองรุ่นอื่นหรือรุ่นบนอุปกรณ์
- ไมโครโฟนไม่ทำอะไรเลย: อนุญาตการอนุญาตไมโครโฟน ทำเครื่องหมาย "เปิดไมโครโฟนไว้"; ตรวจสอบภาษาการจดจำ
- ZYRAXON ได้ยินตัวเอง: สิ่งนี้ถูกกรองด้วยข้อความ หากยังคงเกิดขึ้น ให้ลดระดับเสียงลงหรือใช้หูฟัง
- ประโยคปรากฏขึ้นสองครั้ง: แก้ไขแล้วในเวอร์ชันปัจจุบัน อัปเดตแอป
- มันจะไม่แตะหรืออ่านหน้าจอ: เปิดบริการการเข้าถึง (การตั้งค่า → สิทธิ์)
- มันหยุดในพื้นหลัง: อนุญาตการแจ้งเตือนและการยกเว้นการเพิ่มประสิทธิภาพแบตเตอรี่ การซ้อนทับสำหรับตาลอย
- เครื่องมือขออนุญาตอย่างต่อเนื่อง: เปลี่ยนระดับในการตั้งค่า → การทำงานอัตโนมัติ หรือตอบรับการ์ด
- Play Protect บล็อกบางสิ่ง: ดูบทการอนุญาต หรือให้ตัวแทนแนะนำขั้นตอนต่างๆ
- เทอร์มินัลหรือ Linux ไม่เริ่มทำงาน: รอการแตกไฟล์ครั้งแรกเมื่อเริ่มแอป ตรวจสอบพื้นที่เก็บข้อมูลฟรี
- การอัปเดตจะไม่ติดตั้ง: อนุญาตให้ ZYRAXON เป็นแหล่งการติดตั้ง
- ไม่สามารถเผยแพร่: เพิ่มโทเค็น GitHub สำหรับ GitHub; สำหรับลิงก์สาธารณะ เจ้าหน้าที่สามารถใช้อุโมงค์ได้
- บทแสดงภาษาอังกฤษ: บทนั้นไม่มีข้อความในภาษาของคุณในโครงสร้างนี้ อัปเดตแอป
- สิ่งแปลก ๆ: ใช้การตั้งค่า → การนำทาง → เซสชันใหม่เพื่อเริ่มล้างข้อมูล (จะล้างประวัติการแชทเท่านั้น หน่วยความจำยังคงอยู่)
