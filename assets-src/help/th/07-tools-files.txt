ไฟล์ เทอร์มินัล และระบบ
## ไฟล์
- `read_file`, `list_dir`, `find_files`, `grep_files` (ปลอดภัย): อ่าน แสดงรายการ ค้นหาตามรูปแบบชื่อ และค้นหาข้อความภายในไฟล์
- `write_file`, `edit_file`: สร้างหรือเปลี่ยนแปลงไฟล์ `edit_file` ทำทุกอย่าง: ไฟล์ใหม่ เขียนใหม่ทั้งหมด หรือค้นหาและแทนที่ทุกประการ รหัสปรากฏอยู่ในแชท `delete_file` (ระบบ): ลบไฟล์หรือโฟลเดอร์
- อนุญาตให้ใช้โฟลเดอร์ใดก็ได้ (/sdcard, ดาวน์โหลด, เอกสาร, การ์ด SD …) ให้เส้นทางแบบเต็มและถูกใช้ตามที่เขียนไว้
- ตัวแทนเปิดสิ่งที่ทำให้: `open_file` (ปลอดภัย) เปิดไฟล์ในแอปจริงของโทรศัพท์หรือภายในหน้าตัวอย่างของ ZYRAXON

## เทอร์มินัล (สองอันจริง)
- android: เชลล์ของโทรศัพท์ (busybox บวก `sh`) ภายในแซนด์บ็อกซ์ของแอป `run_shell` (ระบบ) รันคำสั่งที่นั่นโดยไม่อยู่ในสายตา
- linux: ระบบ Unix เต็มรูปแบบของ ZYRAXON ที่สร้างไว้ในแอป: bash, apt/pkg, real git, python, node, clang มันทำงานแบบออฟไลน์ `linux_run` (ระบบ) รันคำสั่งที่นั่น
- `terminal_run` (ระบบ): รันบรรทัดในแท็บ Terminal ที่คุณกำลังดูอยู่ เพื่อให้คุณสามารถเห็นว่ามันทำงานและเข้าควบคุม ใช้เชลล์ android หรือ linux `terminal_open` นำแท็บ Terminal มาไว้ด้านหน้า (เฉพาะเมื่อคุณถามเท่านั้น)
- `system_shell` (ระบบ): คำสั่งระดับระบบ เหนือแซนด์บ็อกซ์ของแอป วิธีที่เชลล์ระบบทำ ด้วย Shizuku หรือรูทมันสามารถเข้าถึงได้ไกลยิ่งขึ้น
- ไม่มีการจำกัดเวลาเริ่มต้น `apt upgrade` ขนาดใหญ่หรืองานสร้างวิ่งไปจนสุด

## Shizuku (การเข้าถึงระบบ)
`setup_shizuku` (ระบบ) ตั้งค่า Shizuku รวมอยู่ภายใน ZYRAXON: ตรวจสอบสถานะ ติดตั้ง เปิด ขอสิทธิ์ มีเพียงคุณเท่านั้นที่สามารถแตะติดตั้งและอนุญาต เจ้าหน้าที่จะแจ้งขั้นตอนให้คุณทราบในบรรทัดเดียวและดำเนินการส่วนที่เหลือ

## งานที่ยาวนานและจังหวะเวลา
- `background_command` (ระบบ): คำสั่งที่ทำงานต่อไปหลังจากที่คุณปิดแอป (การดาวน์โหลดครั้งใหญ่ โคลน บิลด์) พร้อมการแจ้งเตือนและปุ่มหยุด
- `schedule_command` (ระบบ): รันคำสั่งแบบเรียลไทม์ ("ใน 10 นาที", "เวลา 02.00 น."); Android จับเวลาไว้ จึงทำงานโดยปิดแอป
- `wait` (ปลอดภัย): รอโดยตั้งใจ (วินาทีจนกระทั่งพอร์ตเปิด ไฟล์ปรากฏขึ้น คำสั่งเสร็จสิ้น) แทนที่จะเดา

## Linux ใช้
ติดตั้งแพ็คเกจ (`apt install …`), รันสคริปต์ Python หรือ Node, คอมไพล์ C, ใช้ git, รันเซิร์ฟเวอร์, zip และแตกไฟล์ zip, curl, ffmpeg ระบบจะแตกไฟล์อย่างเงียบๆ เมื่อแอปเริ่มทำงานและค้างข้ามการรีสตาร์ท

## หน้าจอเทอร์มินัล
แท็บ Terminal เป็นเทอร์มินัลจริงที่มีแท็บ ⌘ ZX พิมพ์คำสั่งของคุณเองหรือดูของตัวแทน หน้าจอการนำทางในการตั้งค่ามีทางลัดไปยังเปลือกระบบและปุ่ม "เซสชันใหม่" ที่จะล้างประวัติการแชทเพื่อเริ่มต้นใหม่
