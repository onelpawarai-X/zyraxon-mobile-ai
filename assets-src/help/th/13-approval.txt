ระดับการอนุมัติและความปลอดภัยของระบบอัตโนมัติ
การตั้งค่า → ระบบ → อัตโนมัติ วิธีนี้จะตัดสินว่าตัวแทนสามารถทำได้มากน้อยเพียงใดก่อนที่จะหยุดและถามคุณ การตั้งค่านี้บังคับใช้ในโค้ดทุกครั้งที่เรียกใช้เครื่องมือ โมเดลไม่สามารถขยายได้

## ทั้งสี่ระดับ
เปลี่ยนระดับในการตั้งค่า → ระบบ → การทำงานอัตโนมัติ แต่ละระดับจะตัดสินใจว่าเมื่อใดที่เจ้าหน้าที่หยุดและถาม และรวมถึงความเคร่งครัดของ Content Shield (ดูความปลอดภัยและความเป็นส่วนตัว) ที่จะปฏิบัติต่อข้อความที่เจ้าหน้าที่อ่านจากภายนอก
1. ถามเต็ม (ล็อค): ถามก่อนสิ่งใดก็ตามที่เปลี่ยนแปลงโทรศัพท์ไม่ว่าจะเล็กน้อยก็ตาม ปลอดภัยที่สุด Content Shield นั้นเข้มงวด: ข้อความที่น่าสงสัยจะถูกนับว่าเป็นศัตรู ใช้งานบนโทรศัพท์ที่ใช้ร่วมกันหรือในขณะที่คุณกำลังทดสอบสิ่งใหม่
2. ควบคุมดูแล (ค่าเริ่มต้น): ถามก่อนระบบและการดำเนินการส่วนบุคคล และทำงานปกติ (อ่าน เปิด ค้นหา สร้าง) ด้วยตัวเอง Content Shield เป็นมาตรฐาน: ข้อความที่น่าสงสัยจะถูกกั้นเป็นข้อมูล และเมื่อข้อความเห็นได้ชัดว่าไม่เป็นมิตร เครื่องมือที่เปลี่ยนแปลงทุกเครื่องมือจะขอให้คุณใช้เวลาที่เหลือในเทิร์นนั้น
3. สมดุล: ถามก่อนการดำเนินการระดับระบบเท่านั้น (เชลล์ การลบ การเผยแพร่ การกำหนดเวลา…) การดำเนินการส่วนบุคคล เช่น ข้อความ การแตะ และการพิมพ์จะดำเนินการโดยลำพัง Content Shield นั้นไม่ซับซ้อน: มันทำหน้าที่เฉพาะกับข้อความที่ไม่เป็นมิตรอย่างชัดเจน จากนั้นมีเพียงเครื่องมือระดับระบบเท่านั้นที่จะหยุดถาม
4. ระบบอัตโนมัติเต็มรูปแบบ: ไม่เคยถามและไม่เคยหยุด ทุกอย่างดำเนินไปในทันที และ Content Shield ก็ถูกปิดโดยสมบูรณ์ ไม่มีอะไรถูกสแกน ทำเครื่องหมาย ลบหรือเปลี่ยนแปลง นี่คือระบบอัตโนมัติในความหมายที่สมบูรณ์: คุณเป็นเจ้าของความเสี่ยง

## เครื่องมือสามชั้น
- ปลอดภัย (ไม่ต้องถามในทุกระดับ): การอ่านและแสดงรายการไฟล์ หน่วยความจำ เอกสาร การออกแบบ สถานะ การเปิดแอปและไฟล์ การรอ ทักษะ/ระบบอัตโนมัติ/ไทม์ไลน์/รายการการโทร การค้นหาสมอง
- ส่วนบุคคล (ถามในสองระดับแรก): SMS, การโทร, กล้อง, การอ่านหน้าจอ, การแตะและพิมพ์, คลิปบอร์ด, ดาวน์โหลด, การแจ้งเตือน, การแชร์, การเปลี่ยนเสียง, เล่นซ้ำทักษะ, บัญชีแยกประเภทเงิน, ตัวแทนการโทร, เลิกทำไทม์ไลน์
- ระบบ (ถามในทุกระดับยกเว้นการทำงานอัตโนมัติเต็มรูปแบบ): เชลล์, Linux, การสร้าง, การเผยแพร่, การลบ, ล็อคอุปกรณ์, การตั้งเวลา, Git และ GitHub, ffmpeg, โมเดลบนอุปกรณ์, การโพสต์ไปยังแชนเนล, กฎอัตโนมัติ, การลบทักษะ, Shizuku เครื่องมือใดๆ ที่แอปไม่รู้จัก — รวมถึงเครื่องมือ MCP — จะถือเป็นระบบ

## บัตรอนุมัติ
เมื่อเครื่องมือต้องการการอนุมัติจากคุณ การ์ดจะแจ้งว่า "จำเป็นต้องได้รับอนุญาต" บอกคุณว่าเจ้าหน้าที่ต้องการทำอะไร แสดงระดับ (ปลอดภัย ส่วนบุคคล หรือระบบ) และเสนอว่า "ใช่ เรียกใช้งาน" หรือ "ไม่ ปิดไว้" การ์ดยังช่วยเตือนด้วยว่าคุณเปลี่ยนความถี่ที่จะถามสิ่งนี้ได้ในการตั้งค่า → การทำงานอัตโนมัติ

## บนอุปกรณ์เท่านั้น
เมื่อเปิดเครื่อง จะไม่มีอะไรออกจากโทรศัพท์ มีเพียงรุ่นในอุปกรณ์และเครื่องมือในเครื่องเท่านั้นที่ทำงาน เครื่องมือเครือข่ายทั้งหมด (ค้นหา ดึงข้อมูล อัปโหลด เผยแพร่ GitHub การสร้างสื่อ MCP โมเดลคลาวด์) จะถูกปฏิเสธในรูปแบบโค้ด

## ประกาศเปิดตัวครั้งแรก
ครั้งแรก ZYRAXON อธิบายว่าตัวแทนสามารถดำเนินการกับโทรศัพท์ของคุณได้และตำแหน่งที่จะเปิดการอนุญาต กด "เข้าใจแล้ว เริ่ม"
