คลาวด์ เครือข่าย โมเดล และผู้ช่วยเหลือ
## คลาวด์และอินเทอร์เน็ต
- `web_search` (เครือข่าย): ค้นหาเว็บจริง `read_url` (เครือข่าย): ดึงข้อมูลเพจเป็นข้อความ `http_request` (เครือข่าย): การเรียก HTTP ใด ๆ (GET, POST, PUT, PATCH, DELETE) พร้อมส่วนหัวและเนื้อหา `verify_url` (เครือข่าย): ตรวจสอบลิงก์ที่มีอยู่จริงและรับสถานะที่แท้จริง `download_file` (ส่วนตัว, เครือข่าย): ดาวน์โหลด URL ไปยังไฟล์
- ตัวแทนจะเปิดลิงก์เฉพาะเมื่อคุณร้องขอเท่านั้น
- โมเดล AI ทำงานบนคลาวด์ผ่านผู้ให้บริการที่คุณเพิ่ม (ZYRAXON, ZYRAXON Apex ตัวแทนคลาวด์, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode) รายการโมเดลโหลดสดและเติมตามคำตอบของผู้ให้บริการแต่ละราย
- คำขอบิวด์ การเผยแพร่ และการดึงทำงานผ่าน GitHub และ Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git`)
- เปิด "บนอุปกรณ์เท่านั้น" (การตั้งค่าอัตโนมัติ) และไม่มีการโทรบนคลาวด์เลย: ไม่มีผู้ให้บริการ ไม่มีเว็บ หรือไม่มีการอัปโหลด

## MCP เซิร์ฟเวอร์
MCP ให้บริการภายนอกมอบเครื่องมือพิเศษให้กับตัวแทน เชื่อมต่อ Canva, Cloudflare, Supabase, GitHub หรือเซิร์ฟเวอร์ของคุณเองตามที่อยู่ (โทเค็นเสริม) เครื่องมือของเซิร์ฟเวอร์ที่เชื่อมต่อเข้าร่วมรายการเครื่องมือของตัวแทนเป็น `server__tool`
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (ดูว่ามีอะไรเชื่อมต่ออยู่และมีเครื่องมือใดบ้าง), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (ดูแหล่งข้อมูลสำหรับการเปลี่ยนแปลง), `mcp_complete` (อาร์กิวเมนต์เติมข้อความอัตโนมัติ), `mcp_ping`, `mcp_log_level` การโทรของพวกเขาคือการโทรผ่านเครือข่าย และเครื่องมือ MCP ที่ไม่รู้จักจะขออนุญาตตามค่าเริ่มต้น
- หน้าจอ MCP จะแสดงรายการเซิร์ฟเวอร์แต่ละรายการที่มีสถานะเชื่อมต่อแล้ว เครื่องมือ ทรัพยากร และเทมเพลตข้อความแจ้ง รวมถึงปุ่มเพิ่ม ตัดการเชื่อมต่อ ลบ อนุญาต

## ตัวแทนย่อย
`sub_agent` (ระบบ): ส่งมอบชิ้นส่วนของงานใหญ่ให้กับตัวแทนผู้ช่วยที่ทำงานอยู่เบื้องหลัง การดำเนินการ: วางไข่ สถานะ รายการ ผลลัพธ์ ข้อความ หยุด รอ แต่ละคนสามารถใช้รูปแบบของตัวเองได้ เจ้าหน้าที่จะรวมและตรวจสอบผลลัพธ์ก่อนที่จะพูดว่า "เสร็จสิ้น"

## รุ่นบนอุปกรณ์
`on_device_model` (ระบบ): แสดงรายการ โหลด และรันโมเดลภาษาที่ใช้งานบนโทรศัพท์โดยไม่มีอินเทอร์เน็ต ในการตั้งค่า → รุ่นและเอกลักษณ์ → บนอุปกรณ์ที่คุณดาวน์โหลดรุ่น (เล็กไปใหญ่: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B…); โทเค็น Hugging Face เป็นทางเลือกและจำเป็นสำหรับไฟล์ที่มีรั้วรอบขอบชิดเท่านั้น โมเดลที่โหลดแล้วจะถูกจดจำและโหลดซ้ำเมื่อเปิดตัว

## ช่องทางการส่งข้อความ
`channel_post` (ระบบ) เปิด Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail หรือ SMS พร้อมข้อความของคุณ คุณกดส่งเอง
