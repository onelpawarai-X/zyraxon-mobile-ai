समस्या समाधान
- जवाफ छैन: तपाईंको इन्टरनेट र API कुञ्जी जाँच्नुहोस् (Settings → Providers & API ले साँचो त्रुटि देखाउँछ)। अर्को मोडेल वा फोनमै भएको मोडेल प्रयास गर्नुहोस्।
- माइक्रोफोनले केही गर्दैन: माइक्रोफोन अनुमति दिनुहोस्; "Keep the mic on" जाँच्नुहोस्; पहिचान भाषा जाँच्नुहोस्।
- ZYRAXON ले आफैंलाई सुन्छ: यो पाठले छानिन्छ; अझै भए, भोल्युम घटाउनुहोस् वा हेडफोन प्रयोग गर्नुहोस्।
- एउटा वाक्य दुई पटक देखिन्छ: हालका संस्करणमा ठीक भयो; एप अपडेट गर्नुहोस्।
- यो ट्याप वा स्क्रिन पढ्दैन: Accessibility सेवा अन गर्नुहोस् (Settings → Permissions)।
- यो पृष्ठभूमिमा रोकिन्छ: सूचना र ब्याट्री optimization छुट दिनुहोस्; तैरने आँखाका लागि overlay।
- कुनै औजारले अनुमति सोधिरहन्छ: Settings → Automation मा स्तर बदल्नुहोस्, वा कार्डको जवाफ दिनुहोस्।
- Play Protect ले केही रोक्छ: Permissions अध्याय हेर्नुहोस्, वा एजेन्टलाई चरणमा डोर्याउन दिनुहोस्।
- Terminal वा ZYRAXON OS सुरु हुँदैन: एप सुरु हुँदा पहिलो पटक खुल्ने प्रतीक्षा गर्नुहोस्; खाली भण्डारण जाँच्नुहोस्।
- अपडेट स्थापना हुँदैन: ZYRAXON लाई स्थापना स्रोतको रूपमा अनुमति दिनुहोस्।
- प्रकाशित गर्न सकिँदैन: GitHub का लागि GitHub टोकन थप्नुहोस्; सार्वजनिक लिंकका लागि एजेन्टले tunnel प्रयोग गर्न सक्छ।
- कुनै अध्याय अंग्रेजीमा देखिन्छ: यो build मा त्यो अध्यायको तपाईंको भाषामा पाठ छैन; एप अपडेट गर्नुहोस्।
- केही अनौठो: सफा सुरु गर्न Settings → Navigation → New session प्रयोग गर्नुहोस् (यसले कुराकानी इतिहास मात्र मेटाउँछ; सम्झना रहन्छ)।
