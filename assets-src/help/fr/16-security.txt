Sécurité et confidentialité
- Toutes les données de ZYRAXON vivent sur votre téléphone : discussions, mémoire, registre, skills, chronologie, index brain. Rien n'est conservé sur un serveur ZYRAXON.
- Les modèles cloud ne reçoivent que ce qui est nécessaire pour le tour que vous envoyez. Avec « On-device only », rien n'est envoyé du tout.
- Les prompts et fichiers de langue livrés dans l'application sont chiffrés à l'intérieur de l'APK.
- App lock : définissez un mot de passe ou un schéma dans Réglages → Security & privacy → App lock. ZYRAXON se verrouille alors à l'ouverture ou au retour de l'arrière-plan. « Remove lock » supprime le mot de passe ou le schéma enregistré.
- Les niveaux d'approbation protègent chaque appel d'outil dans le code (voir Niveaux d'approbation). Les outils inconnus demandent toujours.
- Vous pouvez effacer : toute la mémoire, l'historique des discussions et votre jeton GitHub, chacun d'un bouton dans Privacy & data.
- Sécurité : si vous dites que quelqu'un vous menace ou vous suit, ou veut votre téléphone ou vos données, l'agent verrouille d'abord le téléphone (si l'autorisation d'administrateur d'appareil est activée) puis vous parle calmement.
- Paiements : avant tout paiement ou virement, l'agent dit ce qu'il va payer et vous demande de confirmer.
- Honnêteté : l'agent ne dit qu'une chose a fonctionné qu'après avoir vu un résultat. Il n'invente jamais de liens, de fichiers ou de résultats.
- Content Shield : tout ce que l'agent lit à l'extérieur — l'écran d'une autre application, une page web, un message, un fichier, un serveur connecté — est vérifié dans le code à la recherche d'un texte qui tente de donner des ordres à l'agent (dans de nombreuses langues, y compris un texte caché par des caractères invisibles). Le texte suspect est encadré pour que le modèle le traite uniquement comme des données. Sa rigueur suit votre niveau d'approbation : Locked traite tout ce qui est suspect comme hostile ; Supervised encadre le texte suspect et, quand le texte est clairement hostile, verrouille le reste de ce tour pour que chaque outil qui modifie quelque chose vous demande d'abord (la carte dit pourquoi) ; Balanced n'agit que sur un texte clairement hostile et seuls les outils de niveau système s'arrêtent pour demander ; Automatic désactive totalement le bouclier — rien n'est analysé, arrêté, marqué ni modifié. Un nouveau message de votre part l'efface.
