Sicherheit und Privatsphäre
- Alle Daten von ZYRAXON befinden sich auf Ihrem Telefon: Chats, Speicher, Hauptbuch, Fähigkeiten, Zeitleiste, Gehirnindex. Auf einem ZYRAXON-Server wird nichts gespeichert.
- Cloud-Modelle erhalten nur das, was für den von Ihnen gesendeten Zug benötigt wird. Bei „Nur auf dem Gerät“ wird überhaupt nichts gesendet.
- Die in der App gelieferten Eingabeaufforderungen und Sprachdateien werden im APK verschlüsselt.
- App-Sperre: Legen Sie ein Passwort oder Muster in den Einstellungen → Sicherheit und Datenschutz → App-Sperre fest. ZYRAXON wird dann gesperrt, wenn Sie es öffnen oder aus dem Hintergrund zurückkehren. „Sperre entfernen“ löscht das gespeicherte Passwort oder Muster.
- Genehmigungsstufen schützen jeden Toolaufruf im Code (siehe Genehmigungsstufen). Unbekannte Tools fragen immer.
- Sie können Folgendes löschen: den gesamten Speicher, den Chat-Verlauf und Ihr GitHub-Token, jeweils mit einer Schaltfläche unter Datenschutz und Daten.
- Sicherheit: Wenn Sie sagen, dass jemand Sie bedroht oder verfolgt oder Ihr Telefon oder Ihre Daten haben möchte, sperrt der Agent zuerst das Telefon (sofern die Geräteadministratorberechtigung aktiviert ist) und spricht dann ruhig mit Ihnen.
- Zahlungen: Vor jeder Zahlung oder Überweisung sagt der Agent, was er zahlen wird, und bittet Sie um eine Bestätigung.
- Ehrlichkeit: Der Agent sagt erst, dass etwas funktioniert hat, nachdem er ein Ergebnis gesehen hat. Es erfindet niemals Links, Dateien oder Ergebnisse.
- Content Shield: Was auch immer der Agent von außen liest – der Bildschirm einer anderen App, eine Webseite, eine Nachricht, eine Datei, ein verbundener Server – wird im Code auf Text überprüft, der versucht, dem Agent Befehle zu erteilen (in vielen Sprachen, einschließlich Text, der mit unsichtbaren Zeichen verborgen ist). Verdächtiger Text wird eingegrenzt, sodass das Modell ihn nur als Daten behandelt. Wie streng es ist, hängt von Ihrer Zustimmungsstufe ab: „Locked“ behandelt alles Verdächtige als feindselig; Supervised grenzt verdächtigen Text ein und sperrt, wenn der Text eindeutig feindselig ist, den Rest dieser Runde, sodass Sie bei jedem Werkzeugwechsel zuerst gefragt werden (auf der Karte steht der Grund); Balanced handelt nur bei eindeutig feindseligem Text und nur Tools auf Systemebene hören auf zu fragen; Automatisches Abschalten des Schildes komplett – es wird nichts gescannt, angehalten, markiert oder verändert. Eine neue Nachricht von Ihnen klärt es.
