Bilder, Audio, Video, Dokumente und Design
- `generate_image` (Netzwerk): Erstellen Sie ein Bild aus einer Beschreibung (schreiben Sie es detailliert; Englisch funktioniert am besten). Es erscheint im Chat mit Teilen-Buttons. Für mehrere fragen Sie nach mehreren.
- `generate_audio` (Netzwerk): gesprochenes Audio (.mp3) aus einem beliebigen Text. Geben Sie bei einem Dialog oder einer Geschichte jedem Teil eine eigene Stimme (Geschlecht, Alter, Sprache, Tonfall). Viele Sprachen, darunter Bengali, Hindi und Englisch.
- `generate_video`: ein echtes bearbeitetes Video (kein AI-Filmmaterial) aus Szenen – Bildern, Clips, Text, Farbe, Kommentar, Bildunterschriften, Musik. `ffmpeg`: jede direkte Bearbeitung – Ausschneiden, Zusammenfügen, Überlagern, Untertitel, Geschwindigkeit, Audiomischung, Konvertieren. Es sind 5–10-minütige Videos möglich, die Schritt für Schritt aufgebaut werden.
- Der Fortschritt wird im Chat live als Prozentsatz angezeigt; Wenn Sie fertig sind, wird die Datei mit den Schaltflächen „Wiedergabe“ und „Teilen“ angezeigt.
- `make_document`: eine echte Word (.docx), Excel (.xlsx) oder PowerPoint (.pptx) Datei auf dem Telefon, keine Installation erforderlich, beliebige Sprache. `office_template`: Bereite Bürounterlagen mit auszufüllenden Lücken (Urlaubsbewerbung, Stellenbewerbung, Rechnung, Lebenslauf, Geschäftsvorschlag, Kostenvoranschlag, Bekanntmachung, Besprechungsprotokoll, Vertrag, Monatsabschlüsse und mehr).
- Dokument aus einem Foto: Hängen Sie ein Foto an (Doc-Scan). Der Text wird genau so kopiert, wie er geschrieben wurde (unklare Wörter werden markiert), eine Tabelle wird zu .xlsx, andernfalls zu .docx.
- Besprechungsnotizen: aus Audio, einem Transkript oder dem, was Sie sagen. Das Dokument enthält eine Zusammenfassung, Entscheidungen, Aktionspunkte (Aufgabe, Eigentümer, Fälligkeitsdatum) und einen fertigen E-Mail-Entwurf.
- `make_design`: Poster, Banner, Logos, Karten, Geschichten, Cover als PNG und PDF. `brand_kit`: Geben Sie ein Logo oder Farben an; Sie werden gespeichert, das App-Design ändert sich und von da an verwenden Dokumente, Folien und Websites Ihre Markenfarben.
- `present_slides`: Der Charakter spricht, während Folienkarten angezeigt werden. Die Folien ändern sich von selbst, wenn die Stimme zu Ende ist. Wenn Sie eine Datei wünschen, fragen Sie nach einer PPTX-Datei.
- `open_file`: öffnet, was in der echten App des Telefons (Word/Docs, Sheets, Slides, PDF, Galerie, Browser) oder im Vorschaufenster erstellt wurde; Der Agent überprüft den Bildschirm, um sicherzustellen, dass er geöffnet wurde.
