Поиск неисправностей
- Нет ответа: проверьте свой Интернет и ключ API (Настройки → Поставщики и API показывают реальную ошибку). Попробуйте другую модель или модель на устройстве.
- Микрофон ничего не делает: разрешите разрешение микрофона; установите флажок «Оставлять микрофон включенным»; проверьте язык распознавания.
- ZYRAXON слышит себя: фильтруется по тексту; если это все равно происходит, уменьшите громкость или воспользуйтесь наушниками.
- Предложение появляется дважды: исправлено в текущих версиях; обновите приложение.
- Он не будет касаться или читать экран: включите службу специальных возможностей (Настройки → Разрешения).
- Он останавливается в фоновом режиме: разрешает уведомления и исключение оптимизации батареи; накладка для плавающего глаза.
- Инструмент продолжает запрашивать разрешение: измените уровень в Настройках → Автоматизация или ответьте на карту.
- Play Protect что-то блокирует: см. главу «Разрешения» или позвольте агенту выполнить действия.
- Терминал или Linux не запускается: дождитесь первой распаковки при запуске приложения; проверьте бесплатное хранилище.
- Обновление не будет установлено: разрешите ZYRAXON в качестве источника установки.
- Невозможно опубликовать: добавьте токен GitHub для GitHub; для публичного канала агент может использовать туннель.
- Глава отображается на английском языке: в этой сборке в этой главе нет текста на вашем языке; обновите приложение.
- Что-то странное: используйте «Настройки» → «Навигация» → «Новый сеанс», чтобы начать чисто (очищается только история чата; память остается).
