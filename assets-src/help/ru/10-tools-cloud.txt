Облако, сеть, модели и помощники
## Облако и Интернет
- `web_search` (сеть): поиск в реальной сети. `read_url` (сеть): получить страницу в виде текста. `http_request` (сеть): любой HTTP-вызов (GET, POST, PUT, PATCH, DELETE) с заголовками и телом. `verify_url` (сеть): проверьте, действительно ли ссылка существует, и получите истинный статус. `download_file` (Личный, сетевой): загрузить URL-адрес файла.
- Агент открывает ссылки только тогда, когда вы его об этом попросите.
- Модели ИИ запускаются в облаке через добавленных вами поставщиков (ZYRAXON, ZYRAXON Apex облачный агент, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode). Список моделей загружается в реальном времени и заполняется по мере ответа каждого поставщика.
- Сборки, публикация и запросы на включение выполняются через GitHub и Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git`).
- Включите «Только на устройстве» (настройки автоматизации), и облачные вызовы вообще не будут выполняться: ни провайдер, ни Интернет, ни загрузка.

## MCP серверы
MCP позволяет внешним службам предоставлять агенту дополнительные инструменты. Подключите Canva, Cloudflare, Supabase, GitHub или свой собственный сервер по его адресу (необязательный токен). Инструменты подключенных серверов присоединяются к списку инструментов агента как `server__tool`.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (посмотрите, что подключено и какие инструменты существуют), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (следите за изменениями на ресурсе), `mcp_complete` (аргументы автозаполнения), `mcp_ping`, `mcp_log_level`. Их вызовы являются сетевыми вызовами, и неизвестные MCP инструменты по умолчанию запрашивают разрешение.
- На экране MCP перечислены все серверы со статусом «Подключено», его инструменты, ресурсы и шаблоны подсказок, а также кнопки «Добавить», «Отключить», «Удалить», «Разрешить».

## Субагенты
`sub_agent` (Система): передать часть большой работы вспомогательным агентам, работающим в фоновом режиме. Действия: появление, статус, список, результат, сообщение, остановка, ожидание. Каждый может использовать свою модель. Агент объединяет и проверяет результаты, прежде чем сказать «Готово».

## Модель на устройстве
`on_device_model` (Система): список, загрузка и запуск языковой модели, которая находится на телефоне, без Интернета. В настройках → Модель и личность → На устройстве загружаются модели (от маленького к большому: FunctionGemma 270M, Qwen3 0,6B, Gemma 4 E2B…); токен Hugging Face не является обязательным и необходим только для закрытых файлов. Загруженная модель запоминается и перезагружается при запуске.

## Каналы обмена сообщениями
`channel_post` (Система) открывает Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail или SMS с готовым текстом. Нажимаешь отправить себе.
