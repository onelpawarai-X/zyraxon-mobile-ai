கிளவுட், நெட்வொர்க், மாதிரிகள் மற்றும் உதவியாளர்கள்
## கிளவுட் மற்றும் இணையம்
- `web_search` (நெட்வொர்க்): உண்மையான இணையத்தில் தேடவும். `read_url` (நெட்வொர்க்): ஒரு பக்கத்தை உரையாகப் பெறவும். `http_request` (நெட்வொர்க்): தலைப்புகள் மற்றும் உடலுடன் கூடிய எந்த HTTP அழைப்பும் (GET, POST, PUT, PATCH, DELETE). `verify_url` (நெட்வொர்க்): இணைப்பு உண்மையில் உள்ளதா எனச் சரிபார்த்து உண்மையான நிலையைப் பெறவும். `download_file` (தனிப்பட்ட, நெட்வொர்க்): ஒரு கோப்பில் URL ஐப் பதிவிறக்கவும்.
- நீங்கள் கேட்கும் போது மட்டுமே முகவர் இணைப்புகளைத் திறக்கிறார்.
- நீங்கள் சேர்த்த வழங்குநர்கள் (ZYRAXON, ZYRAXON Apex கிளவுட் ஏஜென்ட், Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode) மூலம் AI மாதிரிகள் கிளவுட்டில் இயங்குகின்றன. ஒவ்வொரு வழங்குநரும் பதிலளிக்கும்போது மாதிரி பட்டியல் நேரலையில் ஏற்றப்பட்டு நிரப்பப்படும்.
- உருவாக்குதல், வெளியிடுதல் மற்றும் இழுத்தல் கோரிக்கைகள் GitHub மற்றும் Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git`) மூலம் இயங்கும்.
- "சாதனத்தில் மட்டும்" (ஆட்டோமேஷன் அமைப்புகள்) இயக்கவும், கிளவுட் அழைப்பு எதுவும் செய்யப்படவில்லை: வழங்குநர் இல்லை, இணையம் இல்லை, பதிவேற்றம் இல்லை.

## MCP சேவையகங்கள்
MCP வெளிப்புற சேவைகள் முகவருக்கு கூடுதல் கருவிகளை வழங்க அனுமதிக்கிறது. Canva, Cloudflare, Supabase, GitHub அல்லது உங்கள் சொந்த சேவையகத்தை அதன் முகவரி மூலம் இணைக்கவும் (விரும்பினால் டோக்கன்). இணைக்கப்பட்ட சேவையகங்களின் கருவிகள் முகவரின் கருவிப் பட்டியலில் `server__tool` சேரும்.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (என்ன இணைக்கப்பட்டுள்ளது மற்றும் எந்த கருவிகள் உள்ளன என்பதைப் பார்க்கவும்), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (மாற்றங்களுக்கான ஆதாரத்தைப் பார்க்கவும்), `mcp_complete` (தானியங்கி வாதங்கள்), `mcp_ping`, `mcp_log_level`. அவர்களின் அழைப்புகள் நெட்வொர்க் அழைப்புகள் மற்றும் அறியப்படாத MCP கருவிகள் இயல்பாகவே அனுமதி கேட்கும்.
- MCP திரையானது இணைக்கப்பட்ட நிலை, அதன் கருவிகள், ஆதாரங்கள் மற்றும் உடனடி வார்ப்புருக்கள் மற்றும் சேர், துண்டிப்பு, அகற்று, அனுமதி பொத்தான்கள் கொண்ட ஒவ்வொரு சேவையகத்தையும் பட்டியலிடுகிறது.

## துணை முகவர்கள்
`sub_agent` (அமைப்பு): பின்னணியில் இயங்கும் உதவி முகவர்களுக்கு ஒரு பெரிய வேலையின் பாகங்கள். செயல்கள்: ஸ்பான், நிலை, பட்டியல், முடிவு, செய்தி, நிறுத்து, காத்திரு. ஒவ்வொன்றும் அதன் சொந்த மாதிரியைப் பயன்படுத்தலாம். "முடிந்தது" என்று கூறும் முன், முகவர் அவற்றின் முடிவுகளை ஒருங்கிணைத்து சரிபார்க்கிறார்.

## சாதனத்தில் மாதிரி
`on_device_model` (அமைப்பு): இணையம் இல்லாமல், மொபைலில் வாழும் மொழி மாதிரியை பட்டியலிட்டு, ஏற்றி இயக்கவும். அமைப்புகளில் → மாடல் & அடையாளம் → சாதனத்தில் நீங்கள் மாடல்களைப் பதிவிறக்குகிறீர்கள் (சிறியது முதல் பெரியது: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B…); ஒரு Hugging Face டோக்கன் விருப்பமானது மற்றும் கேடட் கோப்புகளுக்கு மட்டுமே தேவைப்படும். ஏற்றப்பட்ட மாதிரி நினைவில் வைக்கப்பட்டு துவக்கத்தில் மீண்டும் ஏற்றப்படுகிறது.

## செய்தி அனுப்பும் சேனல்கள்
`channel_post` (கணினி) Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail அல்லது எஸ்எம்எஸ் திறக்கிறது. நீங்களே அனுப்பு என்பதை அழுத்தவும்.
