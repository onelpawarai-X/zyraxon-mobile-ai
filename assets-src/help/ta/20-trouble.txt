சரிசெய்தல்
- பதில் இல்லை: உங்கள் இணையம் மற்றும் API விசையைச் சரிபார்க்கவும் (அமைப்புகள் → வழங்குநர்கள் & API உண்மையான பிழையைக் காட்டுகிறது). மற்றொரு மாதிரி அல்லது சாதனத்தில் உள்ள மாதிரியை முயற்சிக்கவும்.
- மைக்ரோஃபோன் எதுவும் செய்யாது: மைக்ரோஃபோன் அனுமதியை அனுமதிக்கவும்; "மைக்கை இயக்கு" என்பதை சரிபார்க்கவும்; அங்கீகார மொழியைச் சரிபார்க்கவும்.
- ZYRAXON தன்னைக் கேட்கிறது: இது உரையால் வடிகட்டப்படுகிறது; அது இன்னும் நடந்தால், ஒலியளவைக் குறைக்கவும் அல்லது ஹெட்ஃபோன்களைப் பயன்படுத்தவும்.
- ஒரு வாக்கியம் இரண்டு முறை தோன்றும்: தற்போதைய பதிப்புகளில் சரி செய்யப்பட்டது; பயன்பாட்டைப் புதுப்பிக்கவும்.
- இது திரையைத் தட்டாது அல்லது படிக்காது: அணுகல் சேவையை இயக்கவும் (அமைப்புகள் → அனுமதிகள்).
- இது பின்னணியில் நிற்கிறது: அறிவிப்புகள் மற்றும் பேட்டரி தேர்வுமுறை விலக்குகளை அனுமதிக்கவும்; மிதக்கும் கண்ணுக்கான மேலடுக்கு.
- ஒரு கருவி தொடர்ந்து அனுமதி கேட்கிறது: அமைப்புகள் → ஆட்டோமேஷனில் அளவை மாற்றவும் அல்லது கார்டுக்கு பதிலளிக்கவும்.
- Play Protect எதையாவது தடுக்கிறது: அனுமதிகள் அத்தியாயத்தைப் பார்க்கவும் அல்லது ஏஜென்ட் படிகளை வழிநடத்தட்டும்.
- டெர்மினல் அல்லது ZYRAXON OS தொடங்கவில்லை: பயன்பாட்டின் தொடக்கத்தில் முதல் முறையாகத் திறக்கும் வரை காத்திருக்கவும்; இலவச சேமிப்பிடத்தை சரிபார்க்கவும்.
- புதுப்பிப்பு நிறுவப்படாது: ZYRAXON ஐ நிறுவல் மூலமாக அனுமதிக்கவும்.
- வெளியிட முடியாது: GitHubக்கான GitHub டோக்கனைச் சேர்க்கவும்; பொது இணைப்பிற்கு முகவர் ஒரு சுரங்கப்பாதையைப் பயன்படுத்தலாம்.
- ஒரு அத்தியாயம் ஆங்கிலத்தைக் காட்டுகிறது: இந்த பில்டில் உங்கள் மொழியில் அந்த அத்தியாயத்திற்கு உரை இல்லை; பயன்பாட்டைப் புதுப்பிக்கவும்.
- ஏதோ வித்தியாசமானது: அமைப்புகளை → வழிசெலுத்தல் → புதிய அமர்வை சுத்தமாகத் தொடங்க பயன்படுத்தவும் (இது அரட்டை வரலாற்றை மட்டும் அழிக்கும்; நினைவகம் இருக்கும்).
