ደመና፣ አውታረ መረብ፣ ሞዴሎች እና ረዳቶች
## ደመና እና በይነመረብ
- `web_search` (አውታረ መረብ): እውነተኛውን ድር ይፈልጉ። `read_url` (አውታረ መረብ): አንድ ገጽ እንደ ጽሑፍ ያውጡ። `http_request` (ኔትወርክ)፡ ማንኛውም የኤችቲቲፒ ጥሪ (GET፣ POST፣ PUT፣ PATCH፣ DELETE) ከአርዕስት እና አካል ጋር። `verify_url` (አውታረ መረብ)፡ አንድ ማገናኛ በትክክል መኖሩን ያረጋግጡ እና ትክክለኛውን ሁኔታ ያግኙ። `download_file` (የግል፣ አውታረ መረብ): URL ወደ ፋይል ያውርዱ።
- ወኪሉ አገናኞችን የሚከፍተው ሲጠይቁት ብቻ ነው።
- AI ሞዴሎች እርስዎ ባከሉዋቸው አቅራቢዎች (ZYRAXON፣ ZYRAXON Apex cloud agent, Groq), Gemini, OpenAI, Grok, Claude, Grok, Claude, DeepSeek, OpenRouter, OpenCode)። የሞዴሉ ዝርዝር በቀጥታ ይጫናል እና እያንዳንዱ አቅራቢ ሲመልስ ይሞላል።
- በGitHub እና Cloudflare (`publish_*`፣ `github_actions`፣ `github_pr`፣ `git`) ውስጥ የሚሄዱ ጥያቄዎችን ይገነባል፣ ያሳትማል እና ይጎትታል።
- "በመሣሪያ ላይ ብቻ" (ራስ-ሰር መቼቶች) ያብሩ እና ምንም የደመና ጥሪ አይደረግም: ምንም አቅራቢ የለም, ምንም ድር የለም, ምንም ጭነት የለም.

## MCP አገልጋዮች
MCP የውጪ አገልግሎቶች ለወኪሉ ተጨማሪ መገልገያዎችን እንዲሰጡ ያስችላቸዋል። Canva፣ Cloudflare፣ Supabase፣ GitHub ወይም የራስዎን አገልጋይ በአድራሻው ያገናኙ (አማራጭ ማስመሰያ)። የተገናኙ አገልጋዮች መሳሪያዎች የወኪሉን ዝርዝር እንደ `server__tool` ይቀላቀላሉ።
- `mcp_connect`፣ `mcp_disconnect`፣ `mcp_list` (ምን እንደተገናኘ እና የትኞቹ መሳሪያዎች እንዳሉ ይመልከቱ)፣ `mcp_resources`፣ `mcp_read_resource`፣ `mcp_prompts`፣ `mcp_prompt`፣ `mcp_subscribe` (ለለውጦች ምንጭን ይመልከቱ)፣ `mcp_complete` (በራስ-ሙላ ክርክሮች)፣ `mcp_ping`፣ `mcp_log_level`። ጥሪዎቻቸው የአውታረ መረብ ጥሪዎች ናቸው፣ እና ያልታወቁ MCP መሳሪያዎች በነባሪነት ፍቃድ ይጠይቃሉ።
- የ MCP ስክሪኑ እያንዳንዱ አገልጋይ የተገናኘ ሁኔታ፣ መሳሪያዎቹ፣ ሃብቶቹ እና መጠየቂያ አብነቶች፣ እና አክል፣ አቋርጥ፣ አስወግድ፣ ፍቀድ አዝራሮችን ይዘረዝራል።

## ንዑስ ወኪሎች
`sub_agent` (ሥርዓት)፡ የአንድ ትልቅ ሥራ ክፍሎችን ከበስተጀርባ ለሚሠሩ ረዳት ወኪሎች እጅ። ድርጊቶች፡ ስፓን፣ ሁኔታ፣ ዝርዝር፣ ውጤት፣ መልእክት፣ ቆም፣ ጠብቅ። እያንዳንዳቸው የራሳቸውን ሞዴል መጠቀም ይችላሉ. ተወካዩ "ተከናውኗል" ከማለት በፊት ውጤታቸውን አጣምሮ ይፈትሻል።

## በመሳሪያ ላይ ሞዴል
`on_device_model` (ስርዓት): በስልኮ ላይ የሚኖር የቋንቋ ሞዴል ዘርዝር፣ ጫን እና አሂድ፣ ያለ ኢንተርኔት። በቅንብሮች → ሞዴል እና ማንነት → በመሣሪያው ላይ ሞዴሎችን ያወርዳሉ (ከትንሽ እስከ ትልቅ፡ FunctionGemma 270M፣ Qwen3 0.6B፣ Gemma 4 E2B…); Hugging Face ማስመሰያ አማራጭ ነው እና የሚያስፈልገው ለተከለከሉ ፋይሎች ብቻ ነው። የተጫነ ሞዴል ይታወሳል እና በሚነሳበት ጊዜ እንደገና ይጫናል.

## የመልእክት መላላኪያ ቻናሎች
`channel_post` (ሥርዓት) Telegram፣ WhatsApp፣ Facebook፣ Messenger፣ YouTube፣ X፣ Instagram፣ Gmail ወይም SMS ከጽሑፍዎ ጋር ይከፍታል። አንተ ራስህ ላክ የሚለውን ተጫን።
