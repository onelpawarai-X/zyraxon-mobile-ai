වලාකුළු, ජාලය, ආකෘති සහ සහායකයින්
## වලාකුළු සහ අන්තර්ජාලය
- `web_search` (ජාලය): සැබෑ වෙබය සොයන්න. `read_url` (ජාලය): පිටුවක් පෙළ ලෙස ලබා ගන්න. `http_request` (ජාලය): ඕනෑම HTTP ඇමතුමක් (GET, POST, PUT, PATCH, DELETE) ශීර්ෂක සහ ශරීරය සමඟ. `verify_url` (ජාලය): සබැඳියක් ඇත්ත වශයෙන්ම තිබේදැයි පරීක්ෂා කර සත්‍ය තත්ත්වය ලබා ගන්න. `download_file` (පුද්ගලික, ජාලය): ගොනුවකට URL එකක් බාගන්න.
- නියෝජිතයා සබැඳි විවෘත කරන්නේ ඔබ එය ඉල්ලූ විට පමණි.
- ඔබ එකතු කළ (ZYRAXON, ZYRAXON Apex cloud agent, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode) සපයන්නන් හරහා AI මාදිලි ක්ලවුඩ් තුළ ක්‍රියාත්මක වේ. ආකෘති ලැයිස්තුව සජීවීව පූරණය වන අතර එක් එක් සැපයුම්කරු පිළිතුරු දෙන විට පුරවයි.
- ගොඩනැගීම්, ප්‍රකාශන සහ ඇදීමේ ඉල්ලීම් GitHub සහ Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git` හරහා ක්‍රියාත්මක වේ.
- "උපාංගය මත පමණක්" (ස්වයංක්‍රීය සැකසුම්) ක්‍රියාත්මක කරන්න සහ වලාකුළු ඇමතුමක් කිසිසේත් සිදු නොකෙරේ: සපයන්නා නැත, වෙබ් නැත, උඩුගත කිරීමක් නැත.

## MCP සේවාදායකයන්
MCP බාහිර සේවාවන්ට නියෝජිතයාට අමතර මෙවලම් ලබා දීමට ඉඩ දෙයි. Canva, Cloudflare, Supabase, GitHub හෝ ඔබේම සේවාදායකය එහි ලිපිනයෙන් සම්බන්ධ කරන්න (විකල්ප ටෝකනය). සම්බන්ධිත සේවාදායක මෙවලම් `server__tool` ලෙස නියෝජිතයාගේ මෙවලම් ලැයිස්තුවට එක් වේ.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (සම්බන්ධ වී ඇත්තේ කුමක්ද සහ කුමන මෙවලම් තිබේද යන්න බලන්න), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (වෙනස්කම් සඳහා සම්පතක් නරඹන්න), `mcp_complete` (ස්වයං සම්පුර්ණ තර්ක), `mcp_ping`, `mcp_log_level`. ඔවුන්ගේ ඇමතුම් ජාල ඇමතුම් වන අතර නොදන්නා MCP මෙවලම් පෙරනිමියෙන් අවසර ඉල්ලයි.
- MCP තිරය සෑම සේවාදායකයක්ම සම්බන්ධිත තත්ත්වය, එහි මෙවලම්, සම්පත් සහ ක්ෂණික සැකිලි සහ එක් කරන්න, විසන්ධි කරන්න, ඉවත් කරන්න, ඉඩ දෙන්න බොත්තම් ලැයිස්තුගත කරයි.

## උප නියෝජිතයන්
`sub_agent` (පද්ධතිය): විශාල රැකියාවක කොටස් පසුබිමේ ක්‍රියාත්මක වන උපකාරක නියෝජිතයින්ට ලබා දීම. ක්‍රියා: බිහිවීම, තත්ත්වය, ලැයිස්තුව, ප්‍රතිඵලය, පණිවිඩය, නවත්වන්න, රැඳී සිටින්න. සෑම කෙනෙකුටම තමන්ගේම ආකෘතියක් භාවිතා කළ හැකිය. නියෝජිතයා ඔවුන්ගේ ප්‍රතිඵල ඒකාබද්ධ කර "කර ඇත" යැයි පැවසීමට පෙර පරීක්ෂා කරයි.

## උපාංගය මත ආකෘතිය
`on_device_model` (පද්ධතිය): අන්තර්ජාලය නොමැතිව දුරකථනයේ ජීවත් වන භාෂා ආකෘතියක් ලැයිස්තුගත කරන්න, පූරණය කරන්න සහ ධාවනය කරන්න. සැකසීම් → මාදිලිය සහ අනන්‍යතාවය → උපාංගය මත ඔබ ආකෘති බාගන්න (කුඩා සිට විශාල: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B…); Hugging Face ටෝකනය වෛකල්පිත වන අතර දොරටු ගොනු සඳහා පමණක් අවශ්‍ය වේ. පටවන ලද ආකෘතියක් දියත් කිරීමේදී මතක තබා නැවත පූරණය වේ.

## පණිවිඩ යැවීමේ නාලිකා
`channel_post` (පද්ධතිය) විවෘත කරයි Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail හෝ ඔබේ පෙළ සූදානම් කර SMS කරන්න. ඔබ යවන්න ඔබන්න.
