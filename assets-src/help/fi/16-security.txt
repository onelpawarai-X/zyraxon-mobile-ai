Turvallisuus ja yksityisyys
- Kaikki käyttäjän ZYRAXON tiedot säilyvät puhelimessasi: keskustelut, muisti, kirjanpito, taidot, aikajana, aivohakemisto. Mitään ei säilytetä ZYRAXON-palvelimella.
- Pilvimallit vastaanottavat vain sen, mitä tarvitaan lähettämääsi vuoroon. "Vain laitteella" -asetuksella ei lähetetä mitään.
- Sovelluksessa toimitetut kehotteet ja kielitiedostot on salattu APK:n sisällä.
- Sovelluksen lukitus: aseta salasana tai kuvio asetuksissa → Suojaus ja yksityisyys → Sovelluksen lukitus. ZYRAXON lukittuu, kun avaat sen tai palaat taustalta. "Poista lukitus" poistaa tallennetun salasanan tai kuvion.
- Hyväksyntätasot suojaavat jokaista työkalukutsua koodissa (katso Hyväksyntätasot). Tuntemattomat työkalut kysyvät aina.
- Voit tyhjentää: kaiken muistin, chat-historian ja GitHub-tunnuksesi, joista jokaisessa on yksi painike kohdassa Yksityisyys ja tiedot.
- 
- Maksut: ennen maksua tai siirtoa agentti sanoo, mitä se maksaa ja pyytää sinua vahvistamaan.
- Rehellisyys: agentti sanoo vain, että jokin toimi, kun se oli nähnyt tuloksen. Se ei koskaan keksi linkkejä, tiedostoja tai tuloksia.
- Content Shield: whatever the agent reads from outside — the screen of another app, a web page, a message, a file, a connected server — is checked in code for text that tries to give the agent orders (in many languages, including text hidden with invisible characters). Epäilyttävä teksti on aidattu, joten malli käsittelee sitä vain datana. Kuinka tiukka se noudattaa hyväksyntätasoasi: Lukittu kohtelee kaikkea epäilyttävää vihamielisenä; Supervised fences suspicious text and, when text is clearly hostile, locks the rest of that turn so every changing tool asks you first (the card says why); Tasapainoiset teot vain selvästi vihamielisessä tekstissä ja vain järjestelmätason työkalut pysähtyvät kysymään; Automaattinen katkaisee suojan kokonaan pois päältä – mitään ei skannaa, pysäytä, merkitä tai muuttaa. Uusi viesti sinulta tyhjentää sen.
