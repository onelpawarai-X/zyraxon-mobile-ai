채팅 화면과 모든 버튼
## 화면 상단
- 메뉴: 채팅이 포함된 왼쪽 서랍을 엽니다.
- 채팅/터미널/코드/미리보기: 메인 보기를 전환합니다. 채팅은 대화입니다. 터미널은 실제 터미널입니다. 코드는 Git이 있는 파일 작업 공간입니다. 미리보기는 내장된 브라우저입니다.
- 아우라: 애니메이션 캐릭터 화면을 보여줍니다. 측면 버튼에는 마이크, 채팅(대화로 돌아가기) 및 새로 고침(클라우드를 다시 연결하고 모델 목록을 다시 로드)이 있습니다.
- 설정: 8개의 설정 섹션을 엽니다.
- 배너에는 마이크 상태("듣는 중...", "마이크 꺼짐 - 탭" 또는 "말하는 중... 탭하여 중지")가 표시됩니다.
- 새 버전이 준비되면 다운로드, 설치 및 허용 버튼이 있는 업데이트 배너가 나타납니다(업데이트 참조).

## 왼쪽 메뉴(채팅)
- "+ 새 채팅": 새 대화를 시작합니다.
- 목록의 각 채팅에는 상담원이 통화 중인 동안 실행 중 표시가 표시됩니다. 연필은 이름을 바꿉니다. 십자가는 그것을 삭제합니다(확인 후: 그 안의 모든 메시지가 지워집니다).
- 테마: 공포(피, 불, 그림자), 어둠(깨끗하고 어두운 유리) 또는 빛(밝은 유리)을 선택하세요.

## 메시지 표시줄
- 첨부(종이클립): 갤러리 사진, 카메라 사진, 문서 스캔(사진의 텍스트를 편집 가능한 .docx로 변환), 상담원이 볼 수 있도록 화면 공유('화면 보기' 켜기 또는 끄기), 오디오 또는 비디오 파일. 첨부된 항목은 칩으로 표시됩니다. 십자가는 하나를 제거하고 "모두 지우기"는 모두를 제거합니다.
- 모드 버튼: 에이전트 또는 빌드.
- 마이크 버튼: 항상 듣는 마이크를 켜거나 끕니다.
- 모델 버튼: 검색창으로 모델 목록을 엽니다. "Live"라고 표시된 모델은 자신의 목소리로 말할 수 있습니다.
- 보내기: 메시지를 보냅니다. 에이전트가 작업하는 동안에는 중지됩니다.
- 입력에는 "어떻게 해야 하나요?"라고 표시됩니다. 에이전트 모드에서는 "무엇을 빌드해야 합니까? 짧게 말해 보세요" 빌드 모드에서.

## 메시지
- 복사, 공유 및 듣기(메시지를 소리내어 읽습니다. 중지하려면 다시 누르십시오)는 각 메시지 아래에 있습니다.
- "생각"은 모델이 제공할 때 모델의 추론을 보여줍니다.
- 에이전트가 작성하는 코드는 복사, 다운로드 및 열기를 통해 한 줄씩 상자에 실시간으로 나타납니다.
- 상담원이 만든 파일은 열기(휴대전화의 실제 앱에서), 재생, 공유 및 '기타 앱…'이 포함된 카드로 표시됩니다.
- 사진, 오디오 및 비디오는 제작되는 동안 실시간 진행률을 보여줍니다.
- 도구 카드에는 에이전트가 수행 중인 작업(실행 중, 완료, 성공 또는 실패)이 표시됩니다.

## 패널(todo, 도구, 파일, 하위 에이전트)
- Todo 보드: 에이전트가 대규모 작업에 대해 작성하는 계획과 진행 상황(n/전체 완료)입니다. 자신만의 작업을 추가하고 작업을 삭제할 수 있습니다.
- 도구: 실시간 상태와 함께 모든 도구 호출 목록입니다.
- 파일: 에이전트가 생성한 모든 파일(열기, 공유, 게시, 삭제(확인 포함) 및 검색 상자 포함)
- 하위 에이전트: 중지 버튼을 사용하여 백그라운드에서 실행되는 도우미 에이전트입니다.
- 터미널 탭: 실제 터미널(파일 및 터미널 장 참조)

## 미리보기 패널
- 뒤로, 앞으로, 중지, 새로고침 및 주소 표시줄(웹 주소를 입력하거나 Google 검색).
- 파일 열기: Word, Excel, PowerPoint, PDF, 이미지, Markdown, CSV, 코드 및 사이트를 앱 내에서 바로 표시합니다.
- 크기: 패널을 축소하거나 확대합니다.
- 수정: 페이지의 문제(콘솔 오류, 로드 실패)를 에이전트에 보내고 에이전트는 백그라운드에서 문제를 수정합니다.
- 부분 선택: 페이지의 일부를 탭한 다음 상담원에게 해당 부분을 어떻게 해야 할지 알려줍니다.
- 상담원 버튼: 페이지에 관해 질문하세요. 상담원이 사진을 받습니다.
- 빠른 열기: 최근 페이지에 대한 바로가기.

## 코드 작업공간
- 왼쪽: 파일(새 파일, 열기, 저장)
- 편집기: 줄과 문자를 표시합니다. 상담원이 변경한 내용이 한 번에 표시됩니다.
- Git: 새 저장소, GitHub에서 복제, 스캔, 상태, 메시지로 커밋, 푸시, 풀, 분기, 토큰.
- 풀 요청: 생성, 병합, 닫기. 워크플로: 실행 목록을 표시하고 워크플로를 실행합니다. 로그에는 명령 출력이 표시됩니다.
