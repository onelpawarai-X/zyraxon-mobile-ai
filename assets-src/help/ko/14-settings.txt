모든 설정 화면을 하나씩
설정에는 8개의 섹션이 있습니다. 각 섹션에는 하위 화면에 대한 알약이 있습니다. 마지막으로 사용한 섹션이 다음에 다시 열립니다.

## 1. 언어 및 번역 → 앱 및 도구 언어
전체 앱과 에이전트 도구 메시지의 언어를 선택하세요. 목록을 검색하고 하나를 탭하세요. 화면에는 현재 언어와 UI 번역 및 도구 메시지 번역이 켜져 있는지 여부가 표시됩니다. 60개 언어를 사용할 수 있습니다. 언어 장을 참조하세요.

## 2. 음성 및 마이크
- 음성 프로필: 여성 또는 남성 음성, 속도, 음조, "답변을 소리내어 읽기", 테스트 음성, 벵골어 음성 다운로드 힌트를 선택합니다.
- 마이크 및 언어: 언어 인식, 마이크 켜짐 유지, 말을 멈추면 자동 전송.
- 라이브 음성: 음성 대 음성 켜기/끄기, 상태, 실시간 모델 목록.

## 3. 공급자 및 API
- AI 공급자: 자체 API 키(ZYRAXON, OpenCode 무료 할당량, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter) 및 ZYRAXON Apex 클라우드 에이전트. 저장된 키는 공급자의 실제 카탈로그를 읽어 확인하고 모델 수 또는 정확한 오류를 표시합니다. 버튼을 누르면 키를 생성하는 ZYRAXON 웹사이트가 열립니다.
- GitHub: 게시, Git 푸시 및 풀 요청을 위한 GitHub 액세스 토큰(저장소 범위 필요)입니다. 토큰을 저장하거나 삭제하세요. 상태가 설정되어 있는지 표시됩니다.

## 4. 업데이트 → 앱 업데이트
현재 버전을 표시하고, 최신 릴리스를 확인하고, 진행률 표시줄과 함께 다운로드하여 설치합니다. 채팅, 메모리, 설정은 그대로 유지됩니다. Android 설치에 권한이 필요한 경우 버튼을 누르면 해당 설정이 열립니다.

## 5. 모델 및 아이덴티티
- 정체성: 캐릭터를 선택합니다(캐릭터 장 참조).
- 모델: 검색 상자, "모든 모델" 및 "사용자 정의" 필터가 있는 실시간 모델 카탈로그입니다. 먼저 빠른 모델.
- 기기 내: 오프라인으로 실행되는 모델을 다운로드, 로드 및 언로드합니다. 작은 것에서 큰 것으로 정렬; 선택적 Hugging Face 토큰; 로드됨, 로드 중 및 실패 상태를 표시합니다.

## 6. 아우라 & 테마
- 테마: 공포, 어둠 또는 빛.
- 오라 및 배경: 오라 스타일 및 색상(혈액, 분홍색, 보라색, 하늘, 녹색, 불)을 정밀하게 제어합니다. 아우라 크기, 발광 강도, 회전 속도, 패널 투명도; 떠다니는 눈(켜기/끄기, 디자인, 화면 가장자리, 음성 명령/깨우기 단어, 직접 추가) 셰이더 모드; 사용자 정의 배경 URL(mp4, gif 또는 이미지) 애니메이션 속도.

## 7. 보안 및 개인정보 보호
- 앱 잠금: 비밀번호(4~8자리) 또는 3×3 도트 패턴 두 번 입력하여 확인하세요. 자물쇠를 제거하십시오.
- 권한: Play Protect 도움말이 포함된 권한 장의 목록입니다.
- 개인정보 보호 및 데이터: 모든 데이터는 휴대전화에 보관됩니다. 버튼: 모든 메모리 삭제, 채팅 기록 삭제, GitHub 토큰 삭제.

## 8. 시스템
이 섹션에는 옆으로 스크롤되는 자체 버튼 행이 있으므로 아무것도 눌려지지 않습니다.
- 자동화: 승인 수준 및 기기 내에서만 가능합니다(승인 수준 참조).
- 탐색: 이동할 영역 목록 - "상단에 버튼이 없고 모든 것이 여기에 있습니다" - ⌘ ZX 시스템 셸, "새 세션" 버튼(깨끗한 시작을 위해 채팅 기록 삭제), 메시지 수 및 마이크 토글을 포함합니다.
- 메모리: ZYRAXON이 기억하는 사실을 포함하는 로컬 SQL 메모리입니다. 키와 값을 추가합니다. 모두 삭제하세요.
- 기술 가이드: 예시 문구가 포함된 예시 기능(메시징 앱, 웹 사이트 구축, 스크린 리더, 토치, 카메라, Wi-Fi 및 설정)의 빠른 목록입니다.
- 자동화 허브: 기술, 자동 조종 장치, 돈, 타임라인, 두뇌 및 통화 에이전트가 한 곳에 있습니다(자동화 허브 참조).

## 9. 문서
시스템과 별개로 설정의 자체 섹션입니다. 이 가이드는 21개 장, 검색창, 언어 칩 행으로 구성되어 있습니다. 앱의 모든 언어는 이미 앱 내에 완전히 작성되어 있습니다. 휴대전화에서는 아무것도 번역되지 않으며 이를 읽는 데 인터넷이 필요하지 않습니다.
