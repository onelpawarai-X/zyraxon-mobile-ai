파일, 터미널 및 시스템
## 파일
- `read_file`, `list_dir`, `find_files`, `grep_files` (안전): 파일 내 텍스트 읽기, 나열, 이름 패턴으로 찾기 및 검색.
- `write_file`, `edit_file`: 파일을 생성하거나 변경합니다. `edit_file`는 새 파일, 전체 재작성, 정확한 찾기 및 바꾸기 등 모든 작업을 수행합니다. 코드가 채팅에 실시간으로 표시됩니다. `delete_file` (시스템): 파일이나 폴더를 삭제합니다.
- 모든 폴더가 허용됩니다(/sdcard, 다운로드, 문서, SD 카드…). 전체 경로를 제공하면 작성된 대로 사용됩니다.
- 에이전트는 자신이 만든 것을 엽니다. `open_file`(안전)은 휴대전화의 실제 앱이나 ZYRAXON의 미리보기에서 파일을 엽니다.

## 터미널(실제 터미널 2개)
- android: 앱의 샌드박스 내부에 있는 휴대폰 자체 셸(busybox + `sh`). `run_shell` (시스템)은 눈에 띄지 않는 곳에서 명령을 실행합니다.
- linux: ZYRAXON 자신의 전체 Unix 시스템이 앱에 내장되어 있습니다: bash, apt/pkg, real git, python, node, clang. 오프라인으로 작동합니다. `linux_run` (시스템)이 그곳에서 명령을 실행합니다.
- `terminal_run` (시스템): 보고 있는 터미널 탭에서 라인을 실행하면 작동하고 인계받는 것을 볼 수 있습니다. 쉘 안드로이드나 리눅스를 사용하세요. `terminal_open`은 터미널 탭을 앞으로 가져옵니다(요청하는 경우에만).
- `system_shell` (시스템): 시스템 셸이 수행하는 방식과 마찬가지로 앱 샌드박스 위의 시스템 수준 명령입니다. Shizuku 또는 루트를 사용하면 훨씬 더 많은 범위에 도달할 수 있습니다.
- 기본 시간 제한은 없습니다. 큰 `apt upgrade` 또는 빌드가 끝까지 실행됩니다.

## Shizuku (시스템 액세스)
`setup_shizuku` (시스템)은 ZYRAXON 안에 번들로 포함된 Shizuku을 설정합니다: 상태 확인, 설치, 열기, 권한 요청. 귀하만 설치 및 허용을 탭할 수 있습니다. 상담원은 한 줄로 단계를 알려주고 나머지 작업을 수행합니다.

## 긴 작업과 타이밍
- `background_command` (시스템): 앱을 닫은 후에도 알림 및 중지 버튼과 함께 계속 실행되는 명령(큰 다운로드, 복제, 빌드)입니다.
- `schedule_command` (시스템): 실시간("10분 후", "오전 2시")으로 명령을 실행합니다. Android은 타이머를 보유하므로 앱이 닫힌 상태로 실행됩니다.
- `wait` (안전): 추측하는 대신 의도적으로 기다립니다(포트가 열리고 파일이 나타나고 명령이 완료될 때까지 몇 초).

## Linux 사용
패키지(`apt install …`) 설치, Python 또는 Node 스크립트 실행, C 컴파일, git 사용, 서버 실행, zip 및 압축 풀기, 컬, ffmpeg. 앱이 시작될 때 시스템은 조용히 압축이 풀리고 다시 시작해도 유지됩니다.

## 터미널 화면
터미널 탭은 ⌘ ZX 탭이 있는 실제 터미널입니다. 자신만의 명령을 입력하거나 에이전트의 명령을 살펴보세요. 설정의 탐색 화면에는 시스템 셸에 대한 바로가기와 새로 시작하기 위해 채팅 기록을 지우는 "새 세션" 버튼이 있습니다.
