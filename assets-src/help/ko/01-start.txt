시작하기
ZYRAXON은(는) 귀하의 Android 전화기 안에 있는 보조자입니다. 그것은 당신과 대화하고, 당신의 말을 듣고, 실제 작업을 수행할 수 있습니다. 앱을 열고, 화면을 탭하고 입력하고, 사람들에게 전화를 걸고, 파일을 작성하고, 웹사이트와 앱을 구축하고, ZYRAXON OS 시스템을 실행하고, 사진, 오디오, 비디오 및 사무실 문서를 만들고, 몇 달 동안 당신을 기억합니다. 이는 귀하가 사용하는 모든 언어에서 작동합니다.

## 첫 번째 분
- 처음 실행 시 ZYRAXON 에이전트가 귀하의 전화기에서 스스로 작업을 수행할 수 있다는 짧은 알림을 표시합니다. 계속하려면 "확인, 시작"을 누르세요.
- AI 키를 추가합니다(설정 → 공급자 및 API → AI 공급자). 원하는 공급자에 대한 키를 붙여넣습니다(ZYRAXON, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode)). 키를 저장하면 앱이 해당 공급자의 카탈로그를 읽고 실제로 확인하므로 실제 "연결"과 모델 수가 표시됩니다.
- 열쇠가 없나요? 온디바이스 모델을 계속 사용할 수 있습니다(설정 → 모델 및 ID → 온디바이스). 그들은 인터넷 없이 전화로 실행됩니다.
- 메시지 표시줄의 모델 버튼을 눌러 모델을 선택하고, 캐릭터(설정→ 모델 및 아이덴티티→ 아이덴티티)를 선택하세요.
- 기능에 필요한 경우 권한을 부여합니다(권한 장 참조). 에이전트는 탭 한 번으로 권한 대화 상자를 열 수도 있습니다.
- 그냥 말하거나 입력하세요. "내 베이커리 랜딩 페이지 만들어 줘", "YouTube 열고 노래 틀어 줘", "내 배터리는 얼마야?", "엄마한테 전화해 줘".

## 두 가지 작업 방식
메시지 상자 옆에는 에이전트와 빌드라는 두 가지 모드가 있는 모드 버튼이 있습니다. 모드 장을 참조하세요.

## 물건이 있는 곳
- 왼쪽 메뉴: 채팅, 새 채팅, 이름 바꾸기, 삭제 및 테마 전환.
- 채팅 화면: 메시지, 할일 게시판, 도구 목록, 파일, 터미널.
- 미리보기 및 코드 패널: 에이전트가 빌드하는 내용을 확인하고 편집합니다.
- 설정: 이 문서에서 하나씩 다루는 8개 섹션.
- 이 문서: 설정 → 문서(현재 위치).
