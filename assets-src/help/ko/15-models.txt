공급자, 모델 및 키
## 공급자
ZYRAXON(자체 회선 및 Apex 클라우드 에이전트, 항상 연결됨), OpenCode(무료 할당량), Groq(매우 빠른 Llama), Gemini, OpenAI, Grok(xAI), Claude, DeepSeek 및 OpenRouter. 설정 → 공급자 및 API에 키를 추가하세요. 키는 휴대폰에 저장되어 제공업체의 카탈로그와 비교하여 확인되며, 각 제공업체가 응답할 때 모델이 선택기로 스트리밍됩니다.

## 모델 선택
메시지 표시줄의 모델 버튼을 사용하거나 설정 → 모델 및 ID → 모델을 사용하세요. 이름으로 검색하고 모두 또는 사용자 정의로 필터링하세요. 선택 사항은 실행 시 저장되고 복원됩니다. 새로 고침은 저장된 모델을 대체하지 않습니다. Live로 표시된 모델은 자신의 목소리로 말할 수 있습니다(실시간 음성 참조).

## 온디바이스 모델
설정 → 모델 및 신원 → 기기 내. 모델은 데이터를 남기지 않고 휴대폰에서 실행됩니다. 파일 크기가 크므로(수백 MB에서 몇 GB) Wi-Fi에서 다운로드하세요. 작은 것부터 큰 것까지 나열되어 있습니다. RAM이 작은 휴대폰에서는 가장 가벼운 것을 선택하세요. 도구 호출은 Gemma 및 FunctionGemma 번들에서 지원됩니다. Hugging Face 토큰은 제한 파일에만 사용됩니다. 로드된 모델이 기억됩니다.

## ZYRAXON 웹사이트
zyraxonai.lovable.app: 계정(이메일 또는 Google)을 생성하고 설정, API 키/액세스 토큰을 열고 키를 생성하여 앱에 붙여넣습니다. 키가 없어도 기기 내 모델 및 로컬 도구로 앱을 계속 사용할 수 있습니다.

## 비용 및 데이터
클라우드 제공업체는 자체 규칙에 따라 비용을 청구합니다. '기기 내에서만'이 켜져 있으면 어떤 공급자에게도 아무 것도 전송되지 않습니다.
