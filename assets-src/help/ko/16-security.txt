보안 및 개인정보 보호
- 채팅, 기억, 장부, 기술, 타임라인, 두뇌 지수 등 ZYRAXON의 모든 데이터는 귀하의 휴대폰에 있습니다. ZYRAXON 서버에는 아무것도 보관되지 않습니다.
- 클라우드 모델은 보내는 차례에 필요한 것만 수신합니다. "기기 내에서만"을 선택하면 아무 것도 전송되지 않습니다.
- 앱에 포함된 프롬프트와 언어 파일은 APK 내부에 암호화되어 있습니다.
- 앱 잠금: 설정 → 보안 및 개인 정보 보호 → 앱 잠금에서 비밀번호 또는 패턴을 설정하세요. ZYRAXON 그러면 열거나 백그라운드에서 돌아올 때 잠깁니다. "잠금 제거"는 저장된 비밀번호나 패턴을 삭제합니다.
- 승인 수준은 코드의 모든 도구 호출을 보호합니다(승인 수준 참조). 알 수 없는 도구는 항상 묻습니다.
- 개인 정보 보호 및 데이터에 있는 버튼 하나로 모든 메모리, 채팅 기록, GitHub 토큰을 지울 수 있습니다.
- 안전: 누군가가 당신을 위협하거나 따라오거나 당신의 전화나 데이터를 요구한다고 말하면 에이전트는 먼저 전화를 잠근 다음(기기 관리자 권한이 켜져 있는 경우) 침착하게 대화합니다.
- 지불: 지불이나 이체 전에 대리인은 지불할 금액을 말하고 귀하에게 확인을 요청합니다.
- 정직: 상담원은 결과를 확인한 후에만 효과가 있었다고 말합니다. 링크, 파일 또는 결과를 만들어내지 않습니다.
- Content Shield: 에이전트가 외부에서 읽는 모든 것(다른 앱의 화면, 웹 페이지, 메시지, 파일, 연결된 서버)은 코드에서 에이전트에게 명령을 내리려는 텍스트(보이지 않는 문자로 숨겨진 텍스트를 포함하여 다양한 언어)를 확인합니다. 의심스러운 텍스트는 펜싱되어 모델이 이를 데이터로만 처리합니다. 얼마나 엄격한지는 귀하의 승인 수준에 따릅니다. 잠김은 의심스러운 모든 것을 적대적인 것으로 취급합니다. 감독된 울타리는 의심스러운 텍스트를 차단하고 텍스트가 명백히 적대적인 경우 나머지 턴을 잠그므로 모든 변경 도구가 먼저 묻습니다(카드에 이유가 표시됩니다). 균형 잡힌 행동은 명백히 적대적인 텍스트에만 적용되며 시스템 수준 도구만 중지하여 묻습니다. 자동으로 쉴드가 완전히 꺼집니다. 아무 것도 스캔, 중지, 표시 또는 변경되지 않습니다. 귀하의 새 메시지가 삭제됩니다.
