সমস্যা সমাধান
- কোনো উত্তৰ নাই: আপোনাৰ ইন্টাৰনেট আৰু API চাবি পৰীক্ষা কৰক (সংহতিসমূহ → প্ৰদানকাৰী আৰু API এ প্ৰকৃত ভুল দেখুৱায়)। আন এটা মডেল বা এটা অন-ডিভাইচ মডেল চেষ্টা কৰক।
- মাইক্ৰ’ফোনে একো নকৰে: মাইক্ৰ’ফোনৰ অনুমতি দিয়ক; "মাইক অন ৰাখক" পৰীক্ষা কৰক; স্বীকৃতি ভাষা পৰীক্ষা কৰক।
- ZYRAXON নিজেই শুনিছে: এইটো লিখনীৰ দ্বাৰা ফিল্টাৰ কৰা হয়; যদি এতিয়াও হয়, ভলিউম কম কৰক বা হেডফোন ব্যৱহাৰ কৰক।
- এটা বাক্য দুবাৰ দেখা দিয়ে: বৰ্তমান সংস্কৰণত স্থিৰ; এপটো আপডেট কৰক।
- ই পৰ্দা টেপ নকৰে বা পঢ়িব নোৱাৰে: অভিগম্যতা সেৱা অন কৰক (সংহতিসমূহ → অনুমতিসমূহ)।
- ই পটভূমিত বন্ধ হয়: অধিসূচনা আৰু বেটাৰি অনুকূলন ৰেহাইৰ অনুমতি দিয়ক; ভাসমান চকুৰ বাবে ওভাৰলে।
- এটা সঁজুলিয়ে অনুমতি বিচাৰি থাকে: সংহতিসমূহ → স্বয়ংক্ৰিয়কৰণত স্তৰ সলনি কৰক, বা কাৰ্ডৰ উত্তৰ দিয়ক।
- Play Protect এ কিবা এটা বাধা দিয়ে: অনুমতিসমূহ অধ্যায় চাওক, বা এজেন্টক পদক্ষেপসমূহ নিৰ্দেশনা দিবলৈ দিয়ক।
- টাৰ্মিনেল বা ZYRAXON OS আৰম্ভ নহয়: এপ আৰম্ভ হোৱাৰ সময়ত প্ৰথমবাৰৰ বাবে আনপেক কৰাৰ বাবে অপেক্ষা কৰক; বিনামূলীয়া সংৰক্ষণ পৰীক্ষা কৰক।
- আপডেইটে সংস্থাপন নকৰে: ZYRAXONক সংস্থাপনৰ উৎস হিচাপে অনুমতি দিয়ক ।
- প্ৰকাশ কৰিব নোৱাৰি: GitHub ৰ বাবে GitHub টোকেন যোগ কৰক; এটা ৰাজহুৱা সংযোগৰ বাবে এজেণ্টে এটা সুৰংগ ব্যৱহাৰ কৰিব পাৰে।
- এটা অধ্যায়ত ইংৰাজী দেখুওৱা হৈছে: সেই অধ্যায়টোত এই বিল্ডত আপোনাৰ ভাষাত কোনো লিখনী নাই; এপটো আপডেট কৰক।
- কিবা এটা অদ্ভুত: সংহতিসমূহ ব্যৱহাৰ কৰক → নেভিগেচন → পৰিষ্কাৰ আৰম্ভ কৰিবলৈ নতুন অধিবেশন (ই কেৱল আড্ডাৰ ইতিহাস পৰিষ্কাৰ কৰে; মেমৰি থাকে)।
