ഓരോ ക്രമീകരണ സ്‌ക്രീനും ഓരോന്നായി
ക്രമീകരണങ്ങളിൽ എട്ട് വിഭാഗങ്ങളുണ്ട്. ഓരോ വിഭാഗത്തിനും അതിൻ്റെ ഉപ സ്ക്രീനുകൾക്കുള്ള ഗുളികകൾ ഉണ്ട്. നിങ്ങൾ അവസാനമായി ഉപയോഗിച്ച ഭാഗം അടുത്ത തവണ വീണ്ടും തുറക്കും.

## 1. ഭാഷയും വിവർത്തനവും → ആപ്പ് & ടൂൾ ഭാഷ
മുഴുവൻ ആപ്പിൻ്റെയും ഏജൻ്റിൻ്റെ ടൂൾ സന്ദേശങ്ങളുടെയും ഭാഷ തിരഞ്ഞെടുക്കുക. ലിസ്റ്റ് തിരഞ്ഞ് ഒന്ന് ടാപ്പ് ചെയ്യുക. സ്‌ക്രീൻ നിലവിലെ ഭാഷയും UI വിവർത്തനവും ടൂൾ-സന്ദേശ വിവർത്തനവും ഓണാണോ എന്ന് കാണിക്കുന്നു. 60 ഭാഷകൾ ലഭ്യമാണ്. ഭാഷാ അധ്യായം കാണുക.

## 2. ശബ്ദവും മൈക്കും
- വോയ്സ് പ്രൊഫൈൽ: സ്ത്രീ അല്ലെങ്കിൽ പുരുഷ ശബ്ദം, വേഗത, പിച്ച്, "ഉത്തരങ്ങൾ ഉറക്കെ വായിക്കുക", ടെസ്റ്റ് വോയ്സ്, ബംഗാളി ശബ്ദ ഡൗൺലോഡ് സൂചന എന്നിവ തിരഞ്ഞെടുക്കുക.
- മൈക്കും ഭാഷയും: തിരിച്ചറിയൽ ഭാഷ, മൈക്ക് ഓണാക്കി വയ്ക്കുക, നിങ്ങൾ സംസാരിക്കുന്നത് നിർത്തുമ്പോൾ സ്വയമേവ അയയ്‌ക്കുക.
- തത്സമയ ശബ്ദം: സ്‌പീച്ച്-ടു-സ്പീച്ച് ഓൺ/ഓഫ്, സ്റ്റാറ്റസ്, തത്സമയ മോഡലുകളുടെ ലിസ്റ്റ്.

## 3. ദാതാക്കളും API
- AI ദാതാക്കൾ: നിങ്ങളുടെ സ്വന്തം API കീകൾ (ZYRAXON, OpenCode സൗജന്യ ക്വാട്ട, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter) കൂടാതെ ZYRAXON Apex ക്ലൗഡ് ഏജൻ്റ്. സംരക്ഷിച്ച കീ ദാതാവിൻ്റെ യഥാർത്ഥ കാറ്റലോഗ് വായിച്ച് പരിശോധിച്ചുറപ്പിക്കുകയും മോഡൽ എണ്ണമോ കൃത്യമായ പിശകോ കാണിക്കുകയും ചെയ്യുന്നു. നിങ്ങൾ ഒരു കീ സൃഷ്‌ടിക്കുന്ന ZYRAXON വെബ്‌സൈറ്റ് ഒരു ബട്ടൺ തുറക്കുന്നു.
- GitHub: പ്രസിദ്ധീകരിക്കുന്നതിന് നിങ്ങളുടെ GitHub ആക്‌സസ് ടോക്കൺ (റിപ്പോ സ്കോപ്പ് ആവശ്യമാണ്), Git അഭ്യർത്ഥനകൾ പുഷ് ആൻഡ് പുൾ ചെയ്യുക. ടോക്കൺ സംരക്ഷിക്കുക അല്ലെങ്കിൽ ഇല്ലാതാക്കുക; അത് സജ്ജീകരിച്ചിട്ടുണ്ടെങ്കിൽ സ്റ്റാറ്റസ് കാണിക്കുന്നു.

## 4. അപ്ഡേറ്റുകൾ → ആപ്പ് അപ്ഡേറ്റ്
നിലവിലെ പതിപ്പ് കാണിക്കുന്നു, പുതിയ പതിപ്പിനായി പരിശോധിക്കുന്നു, ഒരു പ്രോഗ്രസ് ബാർ ഉപയോഗിച്ച് അത് ഡൗൺലോഡ് ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്യുന്നു. നിങ്ങളുടെ ചാറ്റുകൾ, മെമ്മറി, ക്രമീകരണങ്ങൾ എന്നിവ നിലനിൽക്കും. ഇൻസ്റ്റാൾ ചെയ്യാൻ Android അനുമതി ആവശ്യമുണ്ടെങ്കിൽ, ഒരു ബട്ടൺ ആ ക്രമീകരണം തുറക്കുന്നു.

## 5. മോഡലും ഐഡൻ്റിറ്റിയും
- ഐഡൻ്റിറ്റി: പ്രതീകം തിരഞ്ഞെടുക്കുക (കഥാപാത്രങ്ങളുടെ അധ്യായം കാണുക).
- മോഡൽ: "എല്ലാ മോഡലുകളും", "ഇഷ്‌ടാനുസൃത" ഫിൽട്ടറുകളും ഉള്ള ഒരു തിരയൽ ബോക്സുള്ള തത്സമയ മോഡൽ കാറ്റലോഗ്; വേഗതയേറിയ മോഡലുകൾ ആദ്യം.
- ഉപകരണത്തിൽ: ഓഫ്‌ലൈനിൽ പ്രവർത്തിക്കുന്ന മോഡലുകൾ ഡൗൺലോഡ് ചെയ്യുക, ലോഡ് ചെയ്യുക, അൺലോഡ് ചെയ്യുക; ചെറുതും വലുതുമായ തരംതിരിച്ചിരിക്കുന്നു; ഓപ്ഷണൽ Hugging Face ടോക്കൺ; ലോഡ് ചെയ്തതും ലോഡുചെയ്യുന്നതും പരാജയപ്പെട്ടതുമായ അവസ്ഥകൾ കാണിക്കുന്നു.

## 6. പ്രഭാവലയം & തീം
- തീം: ഹൊറർ, ഡാർക്ക് അല്ലെങ്കിൽ ലൈറ്റ്.
- പ്രഭാവലയവും പശ്ചാത്തലവും: പ്രഭാവലയവും നിറവും (രക്തം, പിങ്ക്, വയലറ്റ്, ആകാശം, പച്ച, തീ) മികച്ച നിയന്ത്രിതമായ നിറം; പ്രഭാവലയം, തിളങ്ങുന്ന ശക്തി, ഭ്രമണ വേഗത, പാനൽ സുതാര്യത; ഫ്ലോട്ടിംഗ് ഐ (ഓൺ/ഓഫ്, ഡിസൈൻ, സ്ക്രീൻ എഡ്ജ്, വോയിസ് കമാൻഡുകൾ/വേക്ക് പദങ്ങൾ, നിങ്ങളുടേത് ചേർക്കുക); ഷേഡർ മോഡ്; ഇഷ്‌ടാനുസൃത പശ്ചാത്തല URL (mp4, gif അല്ലെങ്കിൽ ചിത്രം); ആനിമേഷൻ വേഗത.

## 7. സുരക്ഷയും സ്വകാര്യതയും
- ആപ്പ് ലോക്ക്: ഒരു പാസ്‌വേഡ് (4–8 അക്കങ്ങൾ) അല്ലെങ്കിൽ ഒരു 3×3 ഡോട്ട് പാറ്റേൺ; രണ്ടുതവണ നൽകി സ്ഥിരീകരിക്കുക; ലോക്ക് നീക്കം ചെയ്യുക.
- അനുമതികൾ: Play Protect സഹായത്തോടെ അനുമതികളുടെ അധ്യായത്തിലെ ലിസ്റ്റ്.
- സ്വകാര്യതയും ഡാറ്റയും: എല്ലാ ഡാറ്റയും ഫോണിൽ തന്നെ തുടരും. ബട്ടണുകൾ: എല്ലാ മെമ്മറിയും ഇല്ലാതാക്കുക, ചാറ്റ് ചരിത്രം ഇല്ലാതാക്കുക, GitHub ടോക്കൺ ഇല്ലാതാക്കുക.

## 8. സിസ്റ്റം
ഈ വിഭാഗത്തിന് അതിൻ്റേതായ ബട്ടണുകൾ ഉണ്ട്, അത് വശത്തേക്ക് സ്ക്രോൾ ചെയ്യുന്നു, അതിനാൽ ഒന്നും ഞെക്കിയിട്ടില്ല.
- ഓട്ടോമേഷൻ: അംഗീകാര നിലയും ഉപകരണത്തിൽ മാത്രം (അനുമതി ലെവലും കാണുക).
- നാവിഗേഷൻ: പോകേണ്ട മേഖലകളുടെ ഒരു ലിസ്റ്റ് — "മുകളിൽ ബട്ടണുകളൊന്നുമില്ല, എല്ലാം ഇവിടെയുണ്ട്" — ⌘ ZX സിസ്റ്റം ഷെൽ, ഒരു "പുതിയ സെഷൻ" ബട്ടൺ (വൃത്തിയുള്ള തുടക്കത്തിനായി ചാറ്റ് ചരിത്രം മായ്‌ക്കുന്നു), സന്ദേശങ്ങളുടെ എണ്ണം, മൈക്ക് ടോഗിൾ എന്നിവ ഉൾപ്പെടെ.
- മെമ്മറി: വസ്തുതകൾ ZYRAXON ഉള്ള പ്രാദേശിക SQL മെമ്മറി ഓർക്കുന്നു; ഒരു കീയും മൂല്യവും ചേർക്കുക; എല്ലാം ഇല്ലാതാക്കുക.
- നൈപുണ്യ ഗൈഡ്: ഉദാഹരണ വാക്യങ്ങളോടുകൂടിയ ഉദാഹരണ കഴിവുകളുടെ (മെസേജിംഗ് ആപ്പുകൾ, വെബ്‌സൈറ്റ് നിർമ്മാണം, സ്‌ക്രീൻ റീഡർ, ടോർച്ച്, ക്യാമറ, Wi-Fi കൂടാതെ ക്രമീകരണങ്ങൾ) ഒരു ദ്രുത ലിസ്റ്റ്.
- ഓട്ടോമേഷൻ ഹബ്: കഴിവുകൾ, ഓട്ടോപൈലറ്റ്, പണം, ടൈംലൈൻ, തലച്ചോറ്, കോൾ ഏജൻ്റ് എന്നിവ ഒരിടത്ത് (ഓട്ടോമേഷൻ ഹബ് കാണുക).

## 9. ഡോക്യുമെൻ്റേഷൻ
സിസ്റ്റത്തിൽ നിന്ന് വേറിട്ട് ക്രമീകരണങ്ങളിൽ അതിൻ്റേതായ വിഭാഗം. ഈ ഗൈഡ്: ഇരുപത്തിയൊന്ന് അധ്യായങ്ങൾ, ഒരു തിരയൽ ബോക്സ്, ഒരു ഭാഷ ചിപ്പ് വരി. ആപ്പിലെ എല്ലാ ഭാഷകളും ഇതിനകം തന്നെ ആപ്പിനുള്ളിൽ പൂർണ്ണമായി എഴുതിയിട്ടുണ്ട് - നിങ്ങളുടെ ഫോണിൽ ഒന്നും വിവർത്തനം ചെയ്യപ്പെടുന്നില്ല, അത് വായിക്കാൻ ഇൻ്റർനെറ്റ് ആവശ്യമില്ല.
