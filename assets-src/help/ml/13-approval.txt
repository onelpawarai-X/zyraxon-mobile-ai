ഓട്ടോമേഷൻ്റെ അംഗീകാര നിലകളും സുരക്ഷയും
ക്രമീകരണങ്ങൾ → സിസ്റ്റം → ഓട്ടോമേഷൻ. ഇത് നിർത്തുകയും നിങ്ങളോട് ചോദിക്കുകയും ചെയ്യുന്നതിനുമുമ്പ് ഏജൻ്റ് എത്രത്തോളം ചെയ്യണമെന്ന് ഇത് തീരുമാനിക്കുന്നു. എല്ലാ ടൂൾ കോളിലും ക്രമീകരണം കോഡിൽ നടപ്പിലാക്കുന്നു; ഒരു മോഡലിന് അതിനെ വിശാലമാക്കാൻ കഴിയില്ല.

## നാല് ലെവലുകൾ
ക്രമീകരണങ്ങൾ → സിസ്റ്റം → ഓട്ടോമേഷനിൽ ലെവൽ മാറ്റുക. ഏജൻ്റ് എപ്പോൾ നിർത്തുകയും ചോദിക്കുകയും ചെയ്യുന്നുവെന്ന് ഓരോ ലെവലും തീരുമാനിക്കുന്നു, കൂടാതെ ഏജൻ്റ് പുറത്ത് നിന്ന് വായിക്കുന്ന വാചകത്തെ ഉള്ളടക്ക ഷീൽഡ് (സുരക്ഷയും സ്വകാര്യതയും കാണുക) എത്ര കർശനമായി കൈകാര്യം ചെയ്യുന്നുവെന്നും തീരുമാനിക്കുന്നു.
1. പൂർണ്ണമായി ചോദിക്കുക (ലോക്ക് ചെയ്‌തത്): ഫോൺ മാറ്റുന്ന എന്തും ചെറുതാണെങ്കിലും മുമ്പ് ചോദിക്കുന്നു. സുരക്ഷിതം. ഉള്ളടക്ക ഷീൽഡ് കർശനമാണ്: സംശയാസ്പദമായ ഏത് വാചകവും ശത്രുതയുള്ളതായി കണക്കാക്കുന്നു. പങ്കിട്ട ഫോണിലോ പുതിയ എന്തെങ്കിലും പരീക്ഷിക്കുമ്പോഴോ ഇത് ഉപയോഗിക്കുക.
2. സൂപ്പർവൈസ് ചെയ്‌തത് (സ്ഥിരസ്ഥിതി): സിസ്റ്റത്തിനും വ്യക്തിഗത പ്രവർത്തനങ്ങൾക്കും മുമ്പായി ചോദിക്കുകയും സാധാരണ ജോലികൾ (വായന, തുറക്കൽ, തിരയൽ, കെട്ടിടം) സ്വയം ചെയ്യുകയും ചെയ്യുന്നു. ഉള്ളടക്ക ഷീൽഡ് സ്റ്റാൻഡേർഡ് ആണ്: സംശയാസ്പദമായ ടെക്‌സ്‌റ്റ് ഡാറ്റയായി വേലിയിറക്കിയിരിക്കുന്നു, ടെക്‌സ്‌റ്റ് വ്യക്തമായി ശത്രുതയുള്ളതാണെങ്കിൽ, മാറുന്ന എല്ലാ ഉപകരണവും നിങ്ങളോട് ആ ടേണിൻ്റെ ബാക്കി ആവശ്യപ്പെടുന്നു.
3. ബാലൻസ്ഡ്: സിസ്റ്റം-ലെവൽ പ്രവർത്തനങ്ങൾക്ക് മുമ്പ് മാത്രം ചോദിക്കുന്നു (ഷെൽ, ഇല്ലാതാക്കൽ, പ്രസിദ്ധീകരിക്കൽ, ഷെഡ്യൂളിംഗ്...). സന്ദേശങ്ങൾ, ടാപ്പുകൾ, ടൈപ്പിംഗ് എന്നിവ പോലുള്ള വ്യക്തിഗത പ്രവർത്തനങ്ങൾ ഒറ്റയ്ക്ക് പ്രവർത്തിക്കുന്നു. ഉള്ളടക്ക ഷീൽഡ് ഭാരം കുറഞ്ഞതാണ്: ഇത് വ്യക്തമായി ശത്രുതാപരമായ വാചകത്തിൽ മാത്രം പ്രവർത്തിക്കുന്നു, തുടർന്ന് സിസ്റ്റം-ലെവൽ ടൂളുകൾ മാത്രം ചോദിക്കുന്നത് നിർത്തുന്നു.
4. പൂർണ്ണ ഓട്ടോമേഷൻ: ഒരിക്കലും ചോദിക്കില്ല, ഒരിക്കലും നിർത്തുകയുമില്ല. എല്ലാം നേരിട്ട് പ്രവർത്തിക്കുന്നു, ഉള്ളടക്ക ഷീൽഡ് പൂർണ്ണമായും സ്വിച്ച് ഓഫ് ചെയ്യുന്നു - ഒന്നും സ്കാൻ ചെയ്യുകയോ അടയാളപ്പെടുത്തുകയോ നീക്കം ചെയ്യുകയോ മാറ്റുകയോ ചെയ്യില്ല. ഇത് പൂർണ്ണമായ അർത്ഥത്തിൽ ഓട്ടോമേഷൻ ആണ്: നിങ്ങൾക്ക് അപകടസാധ്യതയുണ്ട്.

## മൂന്ന് തലത്തിലുള്ള ഉപകരണങ്ങൾ
- സുരക്ഷിതം (ഒരിക്കലും ഒരു തലത്തിലും ചോദിക്കരുത്): ഫയലുകൾ, മെമ്മറി, ഡോക്യുമെൻ്റുകൾ, ഡിസൈനുകൾ, സ്റ്റാറ്റസ്, ഓപ്പണിംഗ് ആപ്പുകളും ഫയലുകളും, കാത്തിരിപ്പ്, കഴിവുകൾ/ഓട്ടോപൈലറ്റ്/ടൈംലൈൻ/കോൾ ലിസ്റ്റുകൾ, ബ്രെയിൻ സെർച്ച് എന്നിവ വായിക്കുകയും ലിസ്റ്റുചെയ്യുകയും ചെയ്യുക.
- വ്യക്തിപരം (ആദ്യത്തെ രണ്ട് തലങ്ങളിൽ ചോദിച്ചത്): SMS, കോളുകൾ, ക്യാമറ, സ്‌ക്രീൻ റീഡിംഗ്, ടാപ്പുകളും ടൈപ്പിംഗും, ക്ലിപ്പ്ബോർഡ്, ഡൗൺലോഡുകൾ, അറിയിപ്പുകൾ, പങ്കിടൽ, വോയ്‌സ് മാറ്റം, കഴിവുകൾ റീപ്ലേ, മണി ലെഡ്ജർ, കോൾ ഏജൻ്റ്, ടൈംലൈൻ പഴയപടിയാക്കൽ.
- സിസ്റ്റം (പൂർണ്ണമായ ഓട്ടോമേഷൻ ഒഴികെയുള്ള എല്ലാ തലത്തിലും ചോദിക്കുന്നു): ഷെൽ, ZYRAXON OS, ബിൽഡ്‌സ്, പബ്ലിഷിംഗ്, ഡിലീറ്റിംഗ്, ഡിവൈസ് ലോക്ക്, ഷെഡ്യൂളിംഗ്, Git കൂടാതെ GitHub, ffmpeg, ഉപകരണത്തിലെ മോഡൽ, ചാനലുകളിലേക്ക് പോസ്റ്റുചെയ്യൽ, ഓട്ടോപൈലറ്റ് നിയമങ്ങൾ, കഴിവുകൾ ഇല്ലാതാക്കൽ, Shizuku. ആപ്പ് തിരിച്ചറിയാത്ത ഏതൊരു ടൂളും — MCP ടൂളുകൾ ഉൾപ്പെടെ — സിസ്റ്റം ആയി കണക്കാക്കുന്നു.

## അംഗീകാര കാർഡ്
ഒരു ഉപകരണത്തിന് നിങ്ങളുടെ അംഗീകാരം ആവശ്യമായി വരുമ്പോൾ, ഒരു കാർഡ് "അനുമതി ആവശ്യമാണ്" എന്ന് പറയുന്നു, ഏജൻ്റ് എന്താണ് ചെയ്യാൻ ആഗ്രഹിക്കുന്നതെന്ന് നിങ്ങളോട് പറയുന്നു, അതിൻ്റെ ടയർ (സുരക്ഷിതം, വ്യക്തിഗത അല്ലെങ്കിൽ സിസ്റ്റം) കാണിക്കുന്നു, കൂടാതെ "അതെ, പ്രവർത്തിപ്പിക്കുക" അല്ലെങ്കിൽ "ഇല്ല, അത് ഓഫ് ചെയ്യുക" എന്ന ഓഫർ നൽകുന്നു. ക്രമീകരണങ്ങൾ → ഓട്ടോമേഷനിൽ ഇത് എത്ര തവണ ചോദിക്കണമെന്ന് നിങ്ങൾക്ക് മാറ്റാമെന്നും കാർഡ് നിങ്ങളെ ഓർമ്മിപ്പിക്കുന്നു.

## ഉപകരണത്തിൽ മാത്രം
ഓണായിരിക്കുമ്പോൾ, ഒന്നും ഫോണിൽ നിന്ന് പുറത്തുപോകില്ല: ഉപകരണ മോഡലും പ്രാദേശിക ഉപകരണങ്ങളും മാത്രം പ്രവർത്തിക്കുന്നു. എല്ലാ നെറ്റ്‌വർക്ക് ടൂളുകളും (തിരയൽ, ലഭ്യമാക്കൽ, അപ്‌ലോഡുകൾ, പ്രസിദ്ധീകരിക്കൽ, GitHub, മീഡിയ ജനറേഷൻ, MCP, ക്ലൗഡ് മോഡലുകൾ) കോഡിൽ നിരസിക്കപ്പെട്ടിരിക്കുന്നു.
