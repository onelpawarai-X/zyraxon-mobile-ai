ഫയലുകൾ, ടെർമിനൽ, സിസ്റ്റം
## ഫയലുകൾ
- `read_file`, `list_dir`, `find_files`, `grep_files` (സുരക്ഷിതം): വായിക്കുക, ലിസ്റ്റുചെയ്യുക, പേരിൻ്റെ പാറ്റേൺ പ്രകാരം കണ്ടെത്തുക, ഫയലുകൾക്കുള്ളിലെ ടെക്‌സ്‌റ്റ് തിരയുക.
- `write_file`, `edit_file`: ഫയലുകൾ സൃഷ്‌ടിക്കുക അല്ലെങ്കിൽ മാറ്റുക. `edit_file` എല്ലാം ചെയ്യുന്നു: പുതിയ ഫയൽ, പൂർണ്ണമായി മാറ്റിയെഴുതുക, അല്ലെങ്കിൽ കൃത്യമായ കണ്ടെത്തലും മാറ്റിസ്ഥാപിക്കലും; കോഡ് ചാറ്റിൽ തത്സമയം ദൃശ്യമാകും. `delete_file` (സിസ്റ്റം): ഒരു ഫയലോ ഫോൾഡറോ ഇല്ലാതാക്കുക.
- ഏത് ഫോൾഡറും അനുവദനീയമാണ് (/sdcard, ഡൗൺലോഡ്, പ്രമാണങ്ങൾ, SD കാർഡ് ...). ഒരു പൂർണ്ണ പാത നൽകുക, അത് എഴുതിയത് പോലെ ഉപയോഗിക്കുന്നു.
- ഏജൻ്റ് അത് സൃഷ്ടിക്കുന്നത് തുറക്കുന്നു: `open_file` (സുരക്ഷിതം) ഫോണിൻ്റെ യഥാർത്ഥ ആപ്പിൽ അല്ലെങ്കിൽ ZYRAXON പ്രിവ്യൂവിൽ ഒരു ഫയൽ തുറക്കുന്നു.

## ടെർമിനലുകൾ (രണ്ട് യഥാർത്ഥമായവ)
- android: ഫോണിൻ്റെ സ്വന്തം ഷെൽ (busybox പ്ലസ് `sh`), ആപ്പിൻ്റെ സാൻഡ്‌ബോക്‌സിനുള്ളിൽ. `run_shell` (സിസ്റ്റം) അവിടെ ഒരു കമാൻഡ് പ്രവർത്തിപ്പിക്കുന്നു, കാഴ്ചയിൽ നിന്ന്.
- linux: ZYRAXON ൻ്റെ സ്വന്തം പൂർണ്ണമായ യുണിക്സ് സിസ്റ്റം, ആപ്പിൽ നിർമ്മിച്ചിരിക്കുന്നു: ബാഷ്, apt/pkg, real git, python, node, clang. ഇത് ഓഫ്‌ലൈനായി പ്രവർത്തിക്കുന്നു. `linux_run` (സിസ്റ്റം) അവിടെ ഒരു കമാൻഡ് പ്രവർത്തിപ്പിക്കുന്നു.
- `terminal_run` (സിസ്റ്റം): നിങ്ങൾ കാണുന്ന ടെർമിനൽ ടാബിൽ ഒരു ലൈൻ പ്രവർത്തിപ്പിക്കുന്നു, അതിനാൽ അത് പ്രവർത്തിക്കുന്നതും ഏറ്റെടുക്കുന്നതും നിങ്ങൾക്ക് കാണാം. ഷെൽ ആൻഡ്രോയിഡ് അല്ലെങ്കിൽ ലിനക്സ് ഉപയോഗിക്കുക. `terminal_open` ടെർമിനൽ ടാബ് മുന്നിലേക്ക് കൊണ്ടുവരുന്നു (നിങ്ങൾ ചോദിക്കുമ്പോൾ മാത്രം).
- `system_shell` (സിസ്റ്റം): ഒരു സിസ്റ്റം-ലെവൽ കമാൻഡ്, ആപ്പ് സാൻഡ്‌ബോക്‌സിന് മുകളിൽ, ഒരു സിസ്റ്റം ഷെൽ ചെയ്യുന്ന രീതി; Shizuku അല്ലെങ്കിൽ റൂട്ട് ഉപയോഗിച്ച് ഇതിന് കൂടുതൽ എത്താൻ കഴിയും.
- സ്ഥിരസ്ഥിതി സമയ പരിധി ഇല്ല; ഒരു വലിയ `apt upgrade` അല്ലെങ്കിൽ ബിൽഡ് റൺ അവസാനം വരെ.

## Shizuku (സിസ്റ്റം ആക്‌സസ്)
`setup_shizuku` (സിസ്റ്റം) സജ്ജീകരിക്കുന്നു Shizuku, ഉള്ളിൽ ബണ്ടിൽ ചെയ്‌തിരിക്കുന്നു ZYRAXON: നില പരിശോധിക്കുക, ഇൻസ്റ്റാൾ ചെയ്യുക, തുറക്കുക, അനുമതി അഭ്യർത്ഥിക്കുക. നിങ്ങൾക്ക് മാത്രമേ ഇൻസ്റ്റാൾ ചെയ്യാനും അനുവദിക്കാനും ടാപ്പുചെയ്യാനാകൂ; ഏജൻ്റ് നിങ്ങളോട് ഒരു വരിയിൽ ഘട്ടം പറയുകയും ബാക്കിയുള്ളവ ചെയ്യുകയും ചെയ്യുന്നു.

## നീണ്ട ജോലികളും സമയവും
- `background_command` (സിസ്റ്റം): നിങ്ങൾ ആപ്പ് അടച്ചതിനുശേഷം (വലിയ ഡൗൺലോഡ്, ക്ലോൺ, ബിൽഡ്) ഒരു അറിയിപ്പും ഒരു സ്റ്റോപ്പ് ബട്ടണും ഉപയോഗിച്ച് പ്രവർത്തിക്കുന്ന ഒരു കമാൻഡ്.
- `schedule_command` (സിസ്റ്റം): തത്സമയം ഒരു കമാൻഡ് പ്രവർത്തിപ്പിക്കുക ("10 മിനിറ്റിനുള്ളിൽ", "പുലർച്ചെ 2 മണിക്ക്"); Android ടൈമർ പിടിക്കുന്നു, അതിനാൽ ഇത് ആപ്പ് അടച്ചിട്ടാണ് പ്രവർത്തിക്കുന്നത്.
- `wait` (സുരക്ഷിതം): ഊഹിക്കുന്നതിനുപകരം ഉദ്ദേശ്യത്തോടെ കാത്തിരിക്കുക (സെക്കൻഡ്, ഒരു പോർട്ട് തുറക്കുന്നതുവരെ, ഒരു ഫയൽ ദൃശ്യമാകും, ഒരു കമാൻഡ് പൂർത്തിയാകും വരെ).

## Linux ഉപയോഗിക്കുന്നു
പാക്കേജുകൾ ഇൻസ്റ്റാൾ ചെയ്യുക (`apt install …`), Python അല്ലെങ്കിൽ Node സ്ക്രിപ്റ്റുകൾ പ്രവർത്തിപ്പിക്കുക, സി കംപൈൽ ചെയ്യുക, ജിറ്റ് ഉപയോഗിക്കുക, സെർവറുകൾ പ്രവർത്തിപ്പിക്കുക, സിപ്പ് ചെയ്ത് അൺസിപ്പ് ചെയ്യുക, ചുരുളുക, ffmpeg. ആപ്പ് ആരംഭിക്കുമ്പോൾ സിസ്റ്റം നിശബ്ദമായി അൺപാക്ക് ചെയ്യപ്പെടുകയും പുനരാരംഭിക്കുമ്പോൾ ഉടനീളം നിലനിൽക്കുകയും ചെയ്യും.

## ടെർമിനൽ സ്ക്രീൻ
ടെർമിനൽ ടാബ് ⌘ ZX ടാബ് ഉള്ള ഒരു യഥാർത്ഥ ടെർമിനലാണ്. നിങ്ങളുടെ സ്വന്തം കമാൻഡുകൾ ടൈപ്പ് ചെയ്യുക അല്ലെങ്കിൽ ഏജൻ്റ് കാണുക. ക്രമീകരണങ്ങളിലെ നാവിഗേഷൻ സ്‌ക്രീനിൽ സിസ്റ്റം ഷെല്ലിലേക്കുള്ള ഒരു കുറുക്കുവഴിയും പുതുതായി ആരംഭിക്കാൻ ചാറ്റ് ചരിത്രം മായ്‌ക്കുന്ന "പുതിയ സെഷൻ" ബട്ടണും ഉണ്ട്.
