ക്ലൗഡ്, നെറ്റ്‌വർക്ക്, മോഡലുകൾ, സഹായികൾ
## ക്ലൗഡും ഇൻ്റർനെറ്റും
- `web_search` (നെറ്റ്‌വർക്ക്): യഥാർത്ഥ വെബിൽ തിരയുക. `read_url` (നെറ്റ്‌വർക്ക്): ഒരു പേജ് വാചകമായി കൊണ്ടുവരിക. `http_request` (നെറ്റ്‌വർക്ക്): ഹെഡറുകളും ബോഡിയും ഉള്ള ഏതെങ്കിലും HTTP കോൾ (GET, POST, PUT, PATCH, DELETE). `verify_url` (നെറ്റ്‌വർക്ക്): ഒരു ലിങ്ക് ശരിക്കും നിലവിലുണ്ടോ എന്ന് പരിശോധിച്ച് യഥാർത്ഥ നില നേടുക. `download_file` (വ്യക്തിഗത, നെറ്റ്‌വർക്ക്): ഒരു ഫയലിലേക്ക് ഒരു URL ഡൗൺലോഡ് ചെയ്യുക.
- നിങ്ങൾ ആവശ്യപ്പെടുമ്പോൾ മാത്രമേ ഏജൻ്റ് ലിങ്കുകൾ തുറക്കുകയുള്ളൂ.
- നിങ്ങൾ ചേർത്ത ദാതാക്കളിലൂടെ (ZYRAXON, ZYRAXON Apex ക്ലൗഡ് ഏജൻ്റ്, Groq, Gemini, OpenAI, Grok, Claude, DeepSeek, OpenRouter, OpenCode) AI മോഡലുകൾ ക്ലൗഡിൽ പ്രവർത്തിക്കുന്നു. മോഡൽ ലിസ്റ്റ് തത്സമയം ലോഡ് ചെയ്യുകയും ഓരോ ദാതാവും ഉത്തരം നൽകുമ്പോൾ പൂരിപ്പിക്കുകയും ചെയ്യുന്നു.
- GitHub, Cloudflare (`publish_*`, `github_actions`, `github_pr`, `git` എന്നിവയിലൂടെ ബിൽഡ്, പബ്ലിഷ്, പുൾ അഭ്യർത്ഥനകൾ പ്രവർത്തിക്കുന്നു.
- "ഉപകരണത്തിൽ മാത്രം" (ഓട്ടോമേഷൻ ക്രമീകരണങ്ങൾ) ഓണാക്കുക, ക്ലൗഡ് കോളൊന്നും ചെയ്യില്ല: ദാതാവില്ല, വെബ് ഇല്ല, അപ്‌ലോഡ് ഇല്ല.

## MCP സെർവറുകൾ
MCP ബാഹ്യ സേവനങ്ങളെ ഏജൻ്റിന് അധിക ഉപകരണങ്ങൾ നൽകാൻ അനുവദിക്കുന്നു. Canva, Cloudflare, Supabase, GitHub അല്ലെങ്കിൽ നിങ്ങളുടെ സ്വന്തം സെർവറിനെ അതിൻ്റെ വിലാസം (ഓപ്ഷണൽ ടോക്കൺ) ഉപയോഗിച്ച് ബന്ധിപ്പിക്കുക. ബന്ധിപ്പിച്ച സെർവറുകളുടെ ടൂളുകൾ `server__tool` ആയി ഏജൻ്റിൻ്റെ ടൂൾ ലിസ്റ്റിൽ ചേരുന്നു.
- `mcp_connect`, `mcp_disconnect`, `mcp_list` (എന്താണ് ബന്ധിപ്പിച്ചിരിക്കുന്നതെന്നും ഏതൊക്കെ ഉപകരണങ്ങൾ നിലവിലുണ്ടെന്നും കാണുക), `mcp_resources`, `mcp_read_resource`, `mcp_prompts`, `mcp_prompt`, `mcp_subscribe` (മാറ്റങ്ങൾക്കായി ഒരു റിസോഴ്‌സ് കാണുക), `mcp_complete` (സ്വയമേവ പൂർത്തീകരിക്കുന്ന ആർഗ്യുമെൻ്റുകൾ), `mcp_ping`, `mcp_log_level`. അവരുടെ കോളുകൾ നെറ്റ്‌വർക്ക് കോളുകളാണ്, അജ്ഞാത MCP ടൂളുകൾ ഡിഫോൾട്ടായി അനുമതി ചോദിക്കുന്നു.
- MCP സ്‌ക്രീൻ കണക്റ്റഡ് സ്റ്റാറ്റസ്, അതിൻ്റെ ടൂളുകൾ, റിസോഴ്‌സുകൾ, പ്രോംപ്റ്റ് ടെംപ്ലേറ്റുകൾ, കൂടാതെ ബട്ടണുകൾ ചേർക്കുക, വിച്ഛേദിക്കുക, നീക്കം ചെയ്യുക, അനുവദിക്കുക എന്നിവയുള്ള ഓരോ സെർവറിനെയും ലിസ്റ്റുചെയ്യുന്നു.

## ഉപ ഏജൻ്റുമാർ
`sub_agent` (സിസ്റ്റം): ഒരു വലിയ ജോലിയുടെ ഭാഗങ്ങൾ പശ്ചാത്തലത്തിൽ പ്രവർത്തിക്കുന്ന സഹായ ഏജൻ്റുമാർക്ക് കൈമാറുക. പ്രവർത്തനങ്ങൾ: മുട്ടയിടുക, സ്റ്റാറ്റസ്, ലിസ്റ്റ്, ഫലം, സന്ദേശം, നിർത്തുക, കാത്തിരിക്കുക. ഓരോരുത്തർക്കും സ്വന്തം മോഡൽ ഉപയോഗിക്കാം. "പൂർത്തിയായി" എന്ന് പറയുന്നതിന് മുമ്പ് ഏജൻ്റ് അവരുടെ ഫലങ്ങൾ സംയോജിപ്പിച്ച് പരിശോധിക്കുന്നു.

## ഉപകരണത്തിൽ മോഡൽ
`on_device_model` (സിസ്റ്റം): ഇൻ്റർനെറ്റ് ഇല്ലാതെ ഫോണിൽ ജീവിക്കുന്ന ഒരു ഭാഷാ മോഡൽ ലിസ്റ്റ് ചെയ്യുക, ലോഡ് ചെയ്യുക, പ്രവർത്തിപ്പിക്കുക. ക്രമീകരണങ്ങളിൽ → മോഡലും ഐഡൻ്റിറ്റിയും → ഉപകരണത്തിൽ നിങ്ങൾ മോഡലുകൾ ഡൗൺലോഡ് ചെയ്യുന്നു (ചെറുത് മുതൽ വലുത് വരെ: FunctionGemma 270M, Qwen3 0.6B, Gemma 4 E2B...); ഒരു Hugging Face ടോക്കൺ ഓപ്ഷണൽ ആണ് കൂടാതെ ഗേറ്റഡ് ഫയലുകൾക്ക് മാത്രം ആവശ്യമാണ്. ലോഞ്ച് ചെയ്യുമ്പോൾ ഒരു ലോഡ് ചെയ്ത മോഡൽ ഓർമ്മിക്കുകയും വീണ്ടും ലോഡുചെയ്യുകയും ചെയ്യുന്നു.

## സന്ദേശമയയ്‌ക്കൽ ചാനലുകൾ
`channel_post` (സിസ്റ്റം) നിങ്ങളുടെ ടെക്‌സ്‌റ്റ് തയ്യാറായി Telegram, WhatsApp, Facebook, Messenger, YouTube, X, Instagram, Gmail അല്ലെങ്കിൽ SMS തുറക്കുന്നു. നിങ്ങൾ സ്വയം അയയ്ക്കുക അമർത്തുക.
