ട്രബിൾഷൂട്ടിംഗ്
- ഉത്തരമില്ല: നിങ്ങളുടെ ഇൻ്റർനെറ്റും API കീയും പരിശോധിക്കുക (ക്രമീകരണങ്ങൾ → ദാതാക്കളും API യഥാർത്ഥ പിശക് കാണിക്കുന്നു). മറ്റൊരു മോഡൽ അല്ലെങ്കിൽ ഒരു ഉപകരണ മോഡൽ പരീക്ഷിക്കുക.
- മൈക്രോഫോൺ ഒന്നും ചെയ്യുന്നില്ല: മൈക്രോഫോൺ അനുമതി അനുവദിക്കുക; "മൈക്ക് ഓണാക്കി വയ്ക്കുക" പരിശോധിക്കുക; തിരിച്ചറിയൽ ഭാഷ പരിശോധിക്കുക.
- ZYRAXON സ്വയം കേൾക്കുന്നു: ഇത് വാചകം ഉപയോഗിച്ച് ഫിൽട്ടർ ചെയ്യുന്നു; ഇപ്പോഴും സംഭവിക്കുകയാണെങ്കിൽ, ശബ്ദം കുറയ്ക്കുക അല്ലെങ്കിൽ ഹെഡ്‌ഫോണുകൾ ഉപയോഗിക്കുക.
- ഒരു വാചകം രണ്ടുതവണ ദൃശ്യമാകുന്നു: നിലവിലെ പതിപ്പുകളിൽ ഉറപ്പിച്ചിരിക്കുന്നു; ആപ്പ് അപ്ഡേറ്റ് ചെയ്യുക.
- ഇത് സ്‌ക്രീനിൽ ടാപ്പുചെയ്യുകയോ വായിക്കുകയോ ചെയ്യില്ല: പ്രവേശനക്ഷമത സേവനം ഓണാക്കുക (ക്രമീകരണങ്ങൾ → അനുമതികൾ).
- ഇത് പശ്ചാത്തലത്തിൽ നിർത്തുന്നു: അറിയിപ്പുകളും ബാറ്ററി ഒപ്റ്റിമൈസേഷൻ ഒഴിവാക്കലും അനുവദിക്കുക; ഫ്ലോട്ടിംഗ് കണ്ണിനുള്ള ഓവർലേ.
- ഒരു ടൂൾ അനുവാദം ചോദിക്കുന്നു: ക്രമീകരണങ്ങൾ → ഓട്ടോമേഷനിൽ ലെവൽ മാറ്റുക അല്ലെങ്കിൽ കാർഡിന് ഉത്തരം നൽകുക.
- Play Protect എന്തെങ്കിലും തടയുന്നു: അനുമതികളുടെ അധ്യായം കാണുക അല്ലെങ്കിൽ ഘട്ടങ്ങൾ നയിക്കാൻ ഏജൻ്റിനെ അനുവദിക്കുക.
- ടെർമിനൽ അല്ലെങ്കിൽ Linux ആരംഭിക്കുന്നില്ല: ആപ്പ് ആരംഭത്തിൽ ആദ്യമായി അൺപാക്ക് ചെയ്യുന്നതിനായി കാത്തിരിക്കുക; സൗജന്യ സംഭരണം പരിശോധിക്കുക.
- അപ്‌ഡേറ്റ് ഇൻസ്റ്റാൾ ചെയ്യില്ല: ZYRAXON ഒരു ഇൻസ്റ്റാളേഷൻ ഉറവിടമായി അനുവദിക്കുക.
- പ്രസിദ്ധീകരിക്കാൻ കഴിയില്ല: GitHub എന്നതിനായി GitHub ടോക്കൺ ചേർക്കുക; ഒരു പൊതു ലിങ്കിനായി ഏജൻ്റിന് ഒരു തുരങ്കം ഉപയോഗിക്കാം.
- ഒരു അധ്യായം ഇംഗ്ലീഷ് കാണിക്കുന്നു: ഈ ബിൽഡിൽ ആ അധ്യായത്തിന് നിങ്ങളുടെ ഭാഷയിൽ വാചകമില്ല; ആപ്പ് അപ്ഡേറ്റ് ചെയ്യുക.
- വിചിത്രമായ എന്തോ ഒന്ന്: വൃത്തിയായി ആരംഭിക്കാൻ ക്രമീകരണങ്ങൾ → നാവിഗേഷൻ → പുതിയ സെഷൻ ഉപയോഗിക്കുക (ഇത് ചാറ്റ് ചരിത്രം മാത്രം മായ്‌ക്കുന്നു; മെമ്മറി നിലനിൽക്കും).
