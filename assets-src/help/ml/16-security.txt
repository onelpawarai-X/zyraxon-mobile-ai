സുരക്ഷയും സ്വകാര്യതയും
- ZYRAXON ൻ്റെ എല്ലാ ഡാറ്റയും നിങ്ങളുടെ ഫോണിൽ നിലനിൽക്കുന്നു: ചാറ്റുകൾ, മെമ്മറി, ലെഡ്ജർ, കഴിവുകൾ, ടൈംലൈൻ, ബ്രെയിൻ ഇൻഡക്സ്. ZYRAXON സെർവറിൽ ഒന്നും സൂക്ഷിച്ചിട്ടില്ല.
- നിങ്ങൾ അയയ്ക്കുന്ന ടേണിന് ആവശ്യമുള്ളത് മാത്രമേ ക്ലൗഡ് മോഡലുകൾക്ക് ലഭിക്കൂ. "ഉപകരണത്തിൽ മാത്രം" ഉപയോഗിച്ച് ഒന്നും അയയ്‌ക്കില്ല.
- ആപ്പിൽ അയച്ച നിർദ്ദേശങ്ങളും ഭാഷാ ഫയലുകളും APK എന്നതിനുള്ളിൽ എൻക്രിപ്റ്റ് ചെയ്തിരിക്കുന്നു.
- ആപ്പ് ലോക്ക്: ക്രമീകരണം → സുരക്ഷയും സ്വകാര്യതയും → ആപ്പ് ലോക്കിൽ ഒരു പാസ്‌വേഡ് അല്ലെങ്കിൽ പാറ്റേൺ സജ്ജീകരിക്കുക. ZYRAXON നിങ്ങൾ അത് തുറക്കുമ്പോഴോ പശ്ചാത്തലത്തിൽ നിന്ന് മടങ്ങുമ്പോഴോ ലോക്ക് ചെയ്യുന്നു. "ലോക്ക് നീക്കം ചെയ്യുക" സംരക്ഷിച്ച പാസ്‌വേഡ് അല്ലെങ്കിൽ പാറ്റേൺ ഇല്ലാതാക്കുന്നു.
- കോഡിലെ ഓരോ ടൂൾ കോളിനും അംഗീകാര ലെവലുകൾ കാവൽ നിൽക്കുന്നു (അംഗീകാരം ലെവലുകൾ കാണുക). അജ്ഞാത ഉപകരണങ്ങൾ എപ്പോഴും ചോദിക്കുന്നു.
- നിങ്ങൾക്ക് മായ്‌ക്കാനാകും: എല്ലാ മെമ്മറിയും ചാറ്റ് ചരിത്രവും നിങ്ങളുടെ GitHub ടോക്കണും, ഓരോന്നിനും സ്വകാര്യതയിലും ഡാറ്റയിലും ഒരു ബട്ടൺ.
- സുരക്ഷ: ആരെങ്കിലും നിങ്ങളെ ഭീഷണിപ്പെടുത്തുകയോ പിന്തുടരുകയോ ചെയ്യുകയാണെങ്കിലോ നിങ്ങളുടെ ഫോണോ ഡാറ്റയോ വേണമെങ്കിൽ, ഏജൻ്റ് ആദ്യം ഫോൺ ലോക്ക് ചെയ്യും (ഉപകരണ-അഡ്മിൻ അനുമതി ഓണാണെങ്കിൽ) തുടർന്ന് നിങ്ങളുമായി ശാന്തമായി സംസാരിക്കും.
- പേയ്‌മെൻ്റുകൾ: ഏതെങ്കിലും പേയ്‌മെൻ്റ് അല്ലെങ്കിൽ കൈമാറ്റം ചെയ്യുന്നതിനുമുമ്പ്, എന്താണ് നൽകേണ്ടതെന്ന് ഏജൻ്റ് പറയുകയും സ്ഥിരീകരിക്കാൻ നിങ്ങളോട് ആവശ്യപ്പെടുകയും ചെയ്യുന്നു.
- സത്യസന്ധത: ഫലം കണ്ടതിന് ശേഷം മാത്രമേ എന്തെങ്കിലും പ്രവർത്തിച്ചുവെന്ന് ഏജൻ്റ് പറയുന്നു. ഇത് ഒരിക്കലും ലിങ്കുകളോ ഫയലുകളോ ഫലങ്ങളോ കണ്ടുപിടിക്കുന്നില്ല.
- ഉള്ളടക്ക ഷീൽഡ്: ഏജൻ്റ് പുറത്ത് നിന്ന് വായിക്കുന്നതെന്തും — മറ്റൊരു ആപ്പിൻ്റെ സ്‌ക്രീൻ, ഒരു വെബ് പേജ്, ഒരു സന്ദേശം, ഒരു ഫയൽ, കണക്‌റ്റ് ചെയ്‌ത സെർവർ - ഏജൻ്റിന് ഓർഡറുകൾ നൽകാൻ ശ്രമിക്കുന്ന ടെക്‌സ്‌റ്റിനായുള്ള കോഡിൽ ചെക്ക് ചെയ്‌തിരിക്കുന്നു (പല ഭാഷകളിലും, അദൃശ്യ പ്രതീകങ്ങളാൽ മറഞ്ഞിരിക്കുന്ന വാചകം ഉൾപ്പെടെ). സംശയാസ്പദമായ ടെക്‌സ്‌റ്റ് വേലി കെട്ടിയിരിക്കുന്നതിനാൽ മോഡൽ അതിനെ ഡാറ്റയായി മാത്രം കണക്കാക്കുന്നു. ഇത് എത്രത്തോളം കർശനമാണ് നിങ്ങളുടെ അംഗീകാര നില പിന്തുടരുന്നത്: ലോക്ക്ഡ് സംശയാസ്പദമായ എന്തും ശത്രുതയായി കണക്കാക്കുന്നു; മേൽനോട്ടത്തിലുള്ള വേലി സംശയാസ്പദമായ ടെക്‌സ്‌റ്റ്, ടെക്‌സ്‌റ്റ് വ്യക്തമായി ശത്രുതയുള്ളതായിരിക്കുമ്പോൾ, ആ ടേണിൻ്റെ ബാക്കി ഭാഗം ലോക്ക് ചെയ്യുന്നു, അങ്ങനെ മാറുന്ന ഓരോ ഉപകരണവും നിങ്ങളോട് ആദ്യം ചോദിക്കും (കാര്‌ഡ് എന്തുകൊണ്ടെന്ന് പറയുന്നു); സമതുലിതമായ പ്രവൃത്തികൾ വ്യക്തമായും പ്രതികൂലമായ ടെക്‌സ്‌റ്റിൽ മാത്രം, സിസ്റ്റം-ലെവൽ ടൂളുകൾ മാത്രം ചോദിക്കുന്നത് നിർത്തുന്നു; യാന്ത്രികമായി ഷീൽഡ് പൂർണ്ണമായും ഓഫ് ചെയ്യുന്നു - ഒന്നും സ്കാൻ ചെയ്യുകയോ നിർത്തുകയോ അടയാളപ്പെടുത്തുകയോ മാറ്റുകയോ ചെയ്യില്ല. നിങ്ങളിൽ നിന്നുള്ള ഒരു പുതിയ സന്ദേശം അത് മായ്‌ക്കുന്നു.
