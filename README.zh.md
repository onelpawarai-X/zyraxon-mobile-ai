### 世界上最强大的全能移动 AI 助手

ZYRAXON 不只是一个聊天应用——它是你口袋里的完整智能体。它会说话、会思考、会使用工具、会写代码、会创建文件，还能在你的手机里运行完整的 Linux 系统。全部功能，尽在一个应用。

---

## ZYRAXON 为何与众不同

### 1. 智能体，而非聊天机器人
ZYRAXON 不只是回答——它**真正把事情做完**。它理解你话语背后的意图，自己判断需要哪个工具，执行它，查看结果，然后把任务完成。写文件、跑代码、从网上取数据、看你的屏幕——全部自动完成。

### 2. 内置完整 Linux
应用内打包了完整的 Linux 环境——`apt`、`dpkg`、`git`、`python`、`node`，一应俱全。**无需 Shizuku，也无需 root** 即可运行。想装什么就装什么，想跑什么就跑什么，就像 Termux——但无需单独的应用，就在 ZYRAXON 里面。

### 3. 真正的“思考”，看得见
任务一开始，ZYRAXON 就会显示它正在**思考**。点击思考内容，就能逐步读到它真实的推理过程——毫无隐藏，亲眼看看它如何决策。随后它开始工作时，**working** 状态实时可见。

### 4. 工具一个接一个，实时可见
每个工具都是单独发送的，因此 ZYRAXON 清楚何时需要哪一个。屏幕上你能看到每一步——跑了什么、得到了什么、改动了什么。没有黑箱。

### 5. 孟加拉语是一等公民
界面和终端都能完美渲染孟加拉语。代码保持等宽，孟加拉语正确成形——两者共存于同一行。

### 6. 美，但不挡路
每一个动画——光环球体、背景、过渡——都保留了，但**没有任何 bug**。动画永远不会拖慢工作。

### 7. 一个应用，整个世界
- **语音** — 你说它听，你打字它读
- **MCP 支持** — 连接外部工具服务器
- **Aura WebView** — 内置浏览器与网页应用
- **Aura Studio** — 处理图片与媒体
- **离线 AI** — 无网络也能做基本工作
- **一键更新** — 应用内即可升级新版本
