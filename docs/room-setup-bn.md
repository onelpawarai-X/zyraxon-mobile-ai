# রুম সেটআপ — কোনটা কোথায়, কোনটার সাথে কী

> তিন GPU-র সার্ভার, এসি, জেনারেটর, সোলার, UPS — পুরো ঘরটা কীভাবে সাজাবে।
> কোনটা কোথায় বসবে, কোন তার কোনটায় যাবে, কোনটা আগে করবে।

---

## ১. ঘরটা কেমন হবে

| জিনিস | মাপ | কেন |
|---|---|---|
| **ঘরের আকার** | ছোট হলেও চলে, ১০ × ১২ ফুট ভালো | ৩টা GPU + এসির তাপ বেরোতে জায়গা দরকার |
| **উচ্চতা** | ৮ ফুট+ | গরম বাতাস উপরে জমে, বেরোনোর পথ লাগে |
| **জানালা** | বন্ধ আর সিল করা | ধুলো ঢুকলে কার্ড নষ্ট হয় |
| **দরজা** | সিল করা | ধুলো আর বাইরের গরম আটকায় |
| **মেঝে** | শুকনো, সমান | তার ছড়ানো থাকবে, হোঁচট লাগবে না |
| **তাপমাত্রা** | **২২-২৫°C** | GPU থাকবে **৪৫-৫৫°C** |
| **ধুলো** | সবচেয়ে বড় শত্রু | ফিল্টার + মাসে একবার পরিষ্কার |

**ঘরের ভিতরে যত কম আসবাব, তত ভালো** — বাতাস চলাচলের পথ খালি থাকবে।

---

## ২. ঘরের ম্যাপ — কোনটা কোথায়

```
                    ← ১২ ফুট →
      ┌──────────────────────────────────────┐
      │   জানালা (বন্ধ, সিল করা, পর্দা)        │
      │                                      │
      │  ┌──────────┐        ┌────────────┐  │
      │  │  এসি      │  ঠান্ডা │   র‍্যাক     │  │
      │  │  (উঁচুতে) │  ──→   │  ৩টা GPU    │  │
      │  │  ১.৫ টন   │  বাতাস  │  সার্ভার    │  │
      │  └──────────┘        └────────────┘  │
      │                       ↑ ৩০ সেমি ফাঁক │
      │  ┌──────────┐        ┌────────────┐  │
      │  │  UPS     │        │  সুইচ      │  │
      │  │  + ATS   │        │  + রাউটার   │  │
      │  └──────────┘        └────────────┘  │
      │  ┌──────────────────────────────┐    │
      │  │   মেইন বোর্ড (MCB + RCCB)     │    │
      │  └──────────────────────────────┘    │
      │        দরজা (সিল করা)                │
      └──────────────────────────────────────┘
                        │
              বাইরে ↓   │   ↓ ছাদে
        ┌──────────┐    │   ┌──────────────┐
        │ জেনারেটর  │    │   │ সোলার প্যানেল │
        │ (খোলা হাওয়ায়)│  │   │  ২৪টা         │
        └──────────┘    │   └──────────────┘
```

**তিনটা নিয়ম:**

1. **এসি আর র‍্যাক — মুখোমুখি।** এসি উঁচুতে, ঠান্ডা বাতাস সরাসরি সার্ভারের দিকে নামে।
2. **র‍্যাক দেয়াল থেকে ৩০ সেমি, মেঝে থেকে ১০ সেমি।** পেছন থেকে গরম বাতাস বেরোবে, নিচ দিয়ে ধুলো ঢুকবে না।
3. **জেনারেটর কখনো ঘরের ভিতরে না।** বাইরে, জানালা-দরজা থেকে **৩-৫ মিটার দূরে**, চিমনি বাইরে বের করে দিতে হবে।

## ৩. বিদ্যুতের চেইন — কোনটা কোথা থেকে টাকা পায়

```
   ☀️ সোলার প্যানেল (২৪টা)
          │  DC তার
          ↓
   ┌──────────────┐
   │ চার্জ কন্ট্রোলার│
   └──────┬───────┘
          ↓
   ┌──────────────┐        ┌─────────────┐
   │  ব্যাটারি     │───────→│  ইনভার্টার   │──┐
   │  ২৪ kWh      │        │  ১০ kW      │  │
   └──────────────┘        └─────────────┘  │
                                            │
   ⚡ গ্রিড (DPDC) ──────────────────────────┤
                                            ├─→ ┌─────────┐
   ⛽ জেনারেটর (বাইরে) ─────────────────────┘   │  ATS /  │
                                               │ চেঞ্জওভার│
                                               └────┬────┘
                                                    ↓
                                              ┌──────────┐
                                              │   UPS    │
                                              │ ৩০ মিনিট │
                                              └────┬─────┘
                                                   ↓
                                             ┌──────────┐
                                             │  সার্ভার  │
                                             │  ৩ GPU   │
                                             └──────────┘
```

**ATS কী করে:** কারেন্ট গেলে নিজে থেকেই গ্রিড থেকে জেনারেটরে বদলায়, আবার এলে ফিরিয়ে দেয়। কেউ কিছু চাপতে হয় না।

**UPS কী করে:** ATS বদলাতে ৫-১০ সেকেন্ড নেয় — ওই সময় UPS সার্ভারকে বাঁচায়। তাই UPS সবার শেষে, সার্ভারের ঠিক আগে।

## ৪. কোন তার কোনটায় — পুরো তালিকা

| # | থেকে | তার | কত | দিকে |
|---|---|---|---|---|
| ১ | সোলার প্যানেল | সোলার DC | ৬ mm² | চার্জ কন্ট্রোলার |
| ২ | চার্জ কন্ট্রোলার | DC | ৬ mm² | ব্যাটারি |
| ৩ | ব্যাটারি | DC মোটা | **২৫ mm²** | ইনভার্টার |
| ৪ | ইনভার্টার | AC | ৬ mm² | ATS |
| ৫ | গ্রিড (মিটার) | AC | ৬ mm² | ATS |
| ৬ | জেনারেটর | AC | ৬ mm² | ATS |
| ৭ | ATS | AC | ৬ mm² | UPS ইনপুট |
| ৮ | UPS | AC | ৪ mm² | মেইন বোর্ড |
| ৯ | মেইন বোর্ড | AC | ৪ mm² | সার্ভার |
| ১০ | মেইন বোর্ড | AC | ৪ mm² | এসি |
| ১১ | সার্ভার | LAN | CAT6 | সুইচ |
| ১২ | সুইচ | LAN | CAT6 | রাউটার |
| ১৩ | রাউটার | ফাইবার | — | ONT (ইন্টারনেট) |
| ১৪ | সার্ভার | HDMI/DP | — | মনিটর |
| ১৫ | সব ধাতব বডি | **আর্থ তার** | ৬ mm² | আর্থ রড |

**সবচেয়ে মোটা তার ব্যাটারির (২৫ mm²)** — কারণ ওখানে কারেন্ট সবচেয়ে বেশি, আর DC।

## ৫. কত ওয়াট, কত ব্রেকার

| জিনিস | চলার সময় | চালু হওয়ার সময় | ব্রেকার | তার |
|---|---|---|---|---|
| ৩ GPU সার্ভার | ১,৮০০ W | ২,২০০ W | ১৬ A | ৪ mm² |
| এসি ১.৫ টন | ১,৬০০ W | ৪,৫০০ W | ২০ A | ৪ mm² |
| মনিটর + নেটওয়ার্ক | ১৮০ W | — | ১০ A | ২.৫ mm² |
| লাইট + ফ্যান | ১৩৫ W | — | ১০ A | ২.৫ mm² |
| **সব মিলে** | **৩,৭১৫ W** | **~৬,৮০০ W** | **৩২ A মেইন** | **৬ mm²** |

**মেইন ব্রেকার ৩২ A** — ২২০ ভোল্টে ৭,০৪০ W ধরে। সব চলার সময় ৩,৭১৫ W, তাই অর্ধেক খালি থাকে।

**RCCB (৩০ mA) অবশ্যই লাগাবে** — কারেন্ট কোথাও লিক করলে সাথে সাথে কেটে দেয়। এটা মানুষের প্রাণ বাঁচায়, জিনিসের না।

## ৬. আর্থিং — সবার আগে এটা

**আর্থিং ছাড়া বিদ্যুতের কাজ শুরু করবে না।** এটাই সবচেয়ে আগের কাজ।

| জিনিস | মাপ |
|---|---|
| তামার রড | ৮ ফুট × ২টা |
| রডের ফাঁক | ৬ ফুট |
| রেজিস্ট্যান্স | **৫ ওহমের কম** |
| তার | ৬ mm² তামা |
| গর্ত | রডের চারপাশে কয়লা + লবণ |

**কেন:** বজ্রপাত, স্ট্যাটিক, বা তার ছিঁড়ে গিয়ে বডিতে লাগলে — কারেন্ট মাটিতে চলে যায়, কার্ড বা মানুষ কিছুই নষ্ট হয় না।

**যা যা আর্থ হবে:** সার্ভার কেস, র‍্যাক, UPS, ATS, এসির বডি, মেইন বোর্ড, সোলার ইনভার্টার।

## ৭. এসি — কোথায়, কেমন

| জিনিস | মান |
|---|---|
| **সাইজ** | ১.৫ টন (১৮,০০০ BTU) |
| **জায়গা** | উঁচুতে, সার্ভারের **বিপরীত দেয়ালে** |
| **তাপমাত্রা সেটিং** | **২৪°C** |
| **বাতাসের দিক** | সরাসরি র‍্যাকের দিকে |
| **ফিল্টার** | মাসে একবার ধোয়া |
| **সার্ভিস** | বছরে ২ বার গ্যাস + কয়েল পরিষ্কার |

**কেন সার্ভারের উপরে না:** এসির নিজের ঠান্ডা বাতাস নিচে নামে; সরাসরি উপরে বসালে বাতাস সোজা সার্ভারে গিয়ে পানি জমাতে পারে। **বিপরীত দেয়াল** থেকে ঠান্ডা বাতাস এসে সার্ভার ছুঁয়ে গরম হয়ে উপরে উঠে যায় — এটাই সবচেয়ে ভালো পথ।

**গরম বাতাস বেরোনোর পথ:** দরজার উপরে বা দেয়ালের উপরে একটা **এক্সহস্ট ফ্যান** (৬-৮ ইঞ্চি)। গরম বাতাস উপরে জমে, ওখান থেকে বেরিয়ে যায়।

## ৮. জেনারেটর — বাইরে, কত দূরে

| জিনিস | মান |
|---|---|
| **সাইজ** | **৬ kVA** (৪ kW লোডের জন্য, চালু হওয়ার ঝাঁকুনি ধরে) |
| **জায়গা** | বাইরে, খোলা হাওয়ায়, ছাউনির নিচে |
| **দূরত্ব** | জানালা-দরজা থেকে **৩-৫ মিটার** |
| **চিমনি** | দূরে বের করা, জানালার বিপরীত দিকে |
| **তেল** | ডিজেল, মাসে একবার চেক |
| **চালু** | ATS নিজে করে, হাতে লাগে না |

**কেন বাইরে:** জেনারেটরের ধোঁয়ায় কার্বন মনোক্সাইড থাকে। ঘরের ভিতরে চালালে প্রাণঘাতী। **এটা কোনো শর্ত নয়, এটা নিয়ম।**

**কেন ৬ kVA:** লোড ৩.৭ kW, কিন্তু AC আর GPU একসাথে চালু হলে ঝাঁকুনি ৬,৮০০ W পর্যন্ত যায়। ৬ kVA সেই ঝাঁকুনি ধরে।

## ৯. সোলার — ফ্রি বিদ্যুৎ

| জিনিস | মান |
|---|---|
| **প্যানেল** | ২৪টা × ৫৫০ W = **১৩.২ kW** |
| **জায়গা** | ছাদ, দক্ষিণ দিকে, ছায়া নেই |
| **ইনভার্টার** | ১০ kW |
| **ব্যাটারি** | ২৪ kWh (লিথিয়াম) |
| **দিনে তৈরি** | ~৫৯ kWh |

**হিসাব:**

| খরচ | দিনে |
|---|---|
| সার্ভার (২ kW × ২৪ ঘণ্টা) | ৪৮ kWh |
| এসি (১.৬ kW × ১০ ঘণ্টা) | ১৬ kWh |
| বাকি সব | ৫ kWh |
| **মোট** | **~৬৯ kWh** |

**সোলার দেয় ৫৯ kWh, বাকি ১০ kWh গ্রিড থেকে।** তাই **বিদ্যুৎ বিল প্রায় শূন্য** — মাসে ২৬,৮৮৮ টাকার বিল নেমে কয়েকশো টাকায়।

**দিনে সূর্য, রাতে ব্যাটারি** — রাতে সার্ভার ব্যাটারিতেই চলে।

## ১০. র‍্যাক আর তারের পথ (ড্রয়ার / ট্রে)

| জিনিস | কী |
|---|---|
| **র‍্যাক** | ৪-ইউ ক্যাবিনেট, লক করা |
| **মেঝে থেকে** | ১০ সেমি উঁচুতে (প্লিন্থে) |
| **দেয়াল থেকে** | ৩০ সেমি ফাঁক |
| **কেবল ট্রে** | দেয়াল বরাবর, মেঝে থেকে ২০ সেমি উপরে |
| **তার বাঁধা** | প্রতি ৩০ সেমিতে বেল্ট, আলাদা রং |
| **রং নিয়ম** | লাল = পাওয়ার, নীল = নেটওয়ার্ক, হলুদ = আর্থ |

**কেন মেঝে থেকে উঁচু:** ধুলো আর পানি মেঝের দিকেই জমে। ১০ সেমি উপরে থাকলে কার্ড নিরাপদ।

**কেন তার আলাদা:** পাওয়ার আর নেটওয়ার্ক একসাথে বাঁধলে ইন্টারনেটে ঝামেলা হয়। **পাওয়ারের তার আর CAT6 কখনো একসাথে না।**

## ১১. নিরাপত্তা — যা প্রাণ বাঁচায়

| **সার্জ প্রোটেক্টর** | বজ্রপাতে জিনিস বাঁচায় |
| **তাপমাত্রা সেন্সর** | ঘরের তাপ ২৮°C পার হলে ফোনে বার্তা |

| **ডিজিটাল মিটার** | কত ওয়াট চলছে, চোখের সামনে |

## ১২. কোনটা আগে — ধাপে ধাপে

| ধাপ | কাজ | কেন এই ক্রমে |
|---|---|---|
| **১** | ঘর ঠিক করা (সিল, ধুলো, তাপ) | সব কিছুর আগে ঘর |
| **২** | **আর্থিং** | বিদ্যুতের কাজ শুরুই হয় এখান থেকে |
| **৩** | মেইন লাইন + মিটার + MCB + RCCB | ঘরে বিদ্যুৎ আসবে |
| **৪** | ATS + UPS | ব্যাকআপের ভিত |
| **৫** | **এসি** | সার্ভার বসার আগে ঘর ঠান্ডা থাকতে হবে |
| **৬** | র‍্যাক + কেবল ট্রে | জিনিস রাখার জায়গা |
| **৭** | সার্ভার র‍্যাকে + মনিটর | আসল কাজ |
| **৮** | নেটওয়ার্ক (সুইচ + রাউটার + CAT6) | সার্ভার অনলাইনে |
| **৯** | সোলার (ছাদে) | ফ্রি বিদ্যুৎ |
| **১০** | জেনারেটর (বাইরে) | দীর্ঘ কাটতির জন্য |
| **১১** | ফায়ার + সেন্সর + মিটার | নিরাপত্তা |
| **১২** | পুরো টেস্ট | সব একসাথে চালু |

**আর্থিং কখনো পিছিয়ে দেবে না।** আর **এসি সার্ভারের আগে** — নইলে প্রথম দিনেই গরমে কার্ড ওঠে যাবে।

## ১৪. সেটআপের পর — টেস্ট

| টেস্ট | কী দেখবে |

| **আর্থিং টেস্ট** | রেজিস্ট্যান্স ৫ ওহমের কম |
| **লোড টেস্ট** | সব চালু করে কত ওয়াট, মিটারে দেখো |
| **AC টেস্ট** | ১ ঘণ্টা চালিয়ে ঘরের তাপ ২২-২৫°C-তে থাকে কি না |
| **GPU টেস্ট** | পূর্ণ লোডে GPU ৪৫-৫৫°C-তে থাকে কি না |
| **কারেন্ট কাট** | মেইন বন্ধ করো — UPS সার্ভার ধরে রাখল কি না |
| **জেনারেটর টেস্ট** | মেইন কেটে দাও — ATS নিজে বদলাল কি না |
| **সোলার টেস্ট** | দুপুরে ইনভার্টারে কত তৈরি হচ্ছে দেখো |
| **নেটওয়ার্ক টেস্ট** | সার্ভার থেকে ইন্টারনেট ঠিকঠাক |
| **ফায়ার টেস্ট** | সেন্সর ছুঁয়ে দেখো — বাজে কি না |

## ১৫. এক পাতায় পুরো ঘর

```
        ছাদ ─── সোলার ২৪টা (১৩.২ kW)
         │
        ঘর ──┬── এসি ১.৫ টন (উঁচুতে, বিপরীত দেয়াল)
             ├── র‍্যাক (৩ GPU, ৩০ সেমি ফাঁক, ১০ সেমি উঁচু)
             ├── UPS + ATS
             ├── সুইচ + রাউটার
             ├── মেইন বোর্ড (৩২ A + RCCB)
             ├── কেবল ট্রে (লাল/নীল/হলুদ)
             └── এক্সহস্ট ফ্যান (উপরে)
         │
       বাইরে ── জেনারেটর ৬ kVA (৩-৫ মিটার দূরে)
         │
        মাটি ── আর্থ রড ৮ ফুট × ২ (৫ ওহমের কম)

   চেইন:  সোলার → ইনভার্টার ─┐
          গ্রিড ──────────────┼→ ATS → UPS → সার্ভার
          জেনারেটর ───────────┘
```

**ঘরের তাপ ২২-২৫°C · GPU ৪৫-৫৫°C · আর্থ ৫ ওহমের কম · মেইন ৩২ A · জেনারেটর ৩-৫ মিটার দূরে।**
