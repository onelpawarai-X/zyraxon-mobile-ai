# এসেম্বল ও টেস্ট — খোলা থেকে চালু পর্যন্ত

> ৩টা RTX 3090 খোলা, থার্মাল প্যাড বদল, ফ্রেমে বসানো, BIOS, OS, ড্রাইভার,
> আর পুরো টেস্ট। কোনটার পরে কোনটা — একটার পর একটা।
> সাথে **টেস্ট কম্পিউটার** — যেটা ছাড়া কিছুই টেস্ট হয় না।

## ০. কেন একটা আলাদা কম্পিউটার লাগবেই

**সার্ভার নিজে নিজেকে টেস্ট করতে পারে না।** এটা কোনো ঝামেলা না, এটা নিয়ম — পৃথিবীর সব ডেটা সেন্টার এভাবেই চলে।

| কাজ | কেন আলাদা মেশিন লাগে |
|---|---|
| **OS ইনস্টল** | USB বুট করতে মনিটর + কীবোর্ড লাগে, আর BIOS-এ ঢুকতে হয় |
| **SSH** | সার্ভারে ঢুকতে একটা ক্লায়েন্ট লাগে |
| **ড্যাশবোর্ড দেখা** | Grafana/Prometheus অন্য স্ক্রিনে খোলা থাকে |
| **অ্যাপ টেস্ট** | ফোন থেকে সার্ভারে হিট দিতে হয় — ফোন দিয়ে কোড লিখবে না |
| **ব্যাকআপ** | সার্ভার ওঠে গেলে বাইরে থেকে ঢুকতে হয় |
| **ড্রাইভার নামানো** | সার্ভারে হেডলেস, ব্রাউজার নেই |

**সার্ভার হবে হেডলেস** — সেটআপের পরে কারও সামনে থাকবে না, দরজা বন্ধ। সব কাজ হবে SSH দিয়ে, কম্পিউটার থেকে।

**কম্পিউটার কী হবে:**

| ধরন | দাম | কেন |
|---|---|---|
| **ল্যাপটপ (নতুন)** | ৳৫৫,০০০ | ব্যাকআপ, ক্যাম্পাসে নেওয়া যায়, ডেমো |
| **ডেস্কটপ (ব্যবহৃত)** | ৳৩৫,০০০ | সস্তা, কিন্তু এক জায়গায় বাঁধা |

**সুপারিশ: ল্যাপটপ।** কারণ —
1. সার্ভার ঘরে তুমি থাকবে না সব সময়, ল্যাপটপ নিয়ে ঘরে বা ক্যাম্পাসে যাবে
2. সার্ভার ওঠে গেলে ল্যাপটপ দিয়েই ঢুকবে
3. পিচ ডেক বানানো, ডেমো ভিডিও — সব এই একটা মেশিনেই
4. রেকর্ডিং, এডিটিং, ব্রাউজার — সব একসাথে

**কম্পিউটারে যা লাগবে:**

| জিনিস | ন্যূনতম |
|---|---|
| RAM | ১৬ GB (৮ GB-ও চলবে) |
| SSD | ৫১২ GB |
| প্রসেসর | i5 / Ryzen 5 |
| পোর্ট | LAN (সার্ভারে লাগাতে), USB ৩টা |
| OS | Ubuntu 24.04 (সার্ভারের সাথে মিল) |

**সার্ভারের জন্য মনিটর + কীবোর্ড লাগবেই** — শুধু সেটআপের সময়। BIOS-এ ঢুকতে, OS ইনস্টল করতে। এরপর খুলে ফেলবে।

| জিনিস | দাম |
|---|---|
| মনিটর ২৪" | ৳১১,০০০ |
| কীবোর্ড + মাউস | ৳১,৫০০ |
| **মোট** | **৳১২,৫০০** |

## ২. RTX 3090 খোলা — কেন খুলতেই হবে

**ব্যবহৃত কার্ড মাইনিং থেকে আসে।** মাইনে কার্ড ২৪ ঘণ্টা ৭০-৮৫°C-তে চলে, মাসের পর মাস। ফল:

| কী হয় | কেন খারাপ |
|---|---|
| **থার্মাল প্যাড শুকিয়ে যায়** | তাপ আর ঠিকঠাক যায় না |
| **পেস্ট শক্ত হয়ে যায়** | GPU ডাই গরম হয় |
| **পাখার বেয়ারিং শুকায়** | শব্দ করে, ঘোরে না |
| **ধুলো জমে** | বাতাস আটকে দেয় |

**নতুন প্যাড + পেস্ট দিলে:**

| আগে | পরে |
|---|---|
| মেমরি **১০০-১১০°C** | মেমরি **৮০-৮৫°C** |
| GPU **৭৫-৮৫°C** | GPU **৬৫-৭২°C** |
| কার্ডের আয়ু ১-২ বছর | **৬-৮ বছর** |

**RTX 3090-এ একটা বিশেষ ব্যাপার:** মেমরি চিপ **পেছনেও আছে**। তাই শুধু সামনের দিক ঠিক করলে চলবে না — **পেছনের ব্যাকপ্লেটের নিচেও প্যাড লাগবে।** এটাই ৩০৯০-এর সবচেয়ে বড় গরমের কারণ, আর যারা জানে না তারাই কার্ড পুড়িয়ে ফেলে।

## ৩. GPU খোলার ধাপ — একটা একটা

```
   ① স্ক্রু খোলা          ② কুলার আলাদা         ③ পরিষ্কার
   ┌─────────────┐        ┌─────────────┐       ┌─────────────┐
   │ [X][X][X][X]│        │   ╔═══════╗ │       │  ═══════    │
   │ [X][X][X][X]│  →     │   ║ কুলার ║ │  →    │  খালি PCB   │
   │  পেছনের     │        │   ╚═══════╝ │       │  ═══════    │
   │  ব্যাকপ্লেট  │        │  ↑ উপরে     │       │  ↑ IPA দিয়ে │
   └─────────────┘        └─────────────┘       └─────────────┘
   ④ নতুন প্যাড           ⑤ নতুন পেস্ট          ⑥ বন্ধ
   ┌─────────────┐        ┌─────────────┐       ┌─────────────┐
   │ ▓▓▓▓▓▓▓▓▓▓ │        │     ███     │       │ [X][X][X][X]│
   │ VRAM-এ প্যাড │        │  GPU ডাইতে  │  →    │ [X][X][X][X]│
   │ ▓▓▓▓▓▓▓▓▓▓ │        │    পেস্ট    │       │  বন্ধ!       │
   └─────────────┘        └─────────────┘       └─────────────┘
```

### ① স্ক্রু খোলা

- কার্ড সমান মেঝেতে, অ্যান্টি-স্ট্যাটিক ব্যান্ড হাতে
- **ব্যাকপ্লেটের স্ক্রু আগে** — পেছনের দিকের ৮-১০টা স্ক্রু
- স্ক্রুগুলো আলাদা বাটিতে, হারালে নতুন খুঁজতে হবে
- **ফ্যান কেবল খুলতে ভুলো না** — টানাটানি করলে ছিঁড়ে যাবে

### ② কুলার আলাদা

- পেছনের ৪টা বড় স্ক্রু (GPU ডাইয়ের চারপাশে) **X আকারে ঢিলা করবে** — একটার পর একটা, একেবারে শেষ না করে
- কেন X আকারে: একদিকের স্ক্রু পুরো খুললে ডাই বেঁকে যেতে পারে
- তারপর আস্তে করে কুলারটা উপরে তুলবে
- **সোজা উপরে তুলবে, পাশে টানবে না**

### ③ পরিষ্কার

| জায়গা | কীভাবে |
|---|---|
| GPU ডাই | IPA ৯৯% + কটন বাড, আস্তে |
| VRAM চিপ | একইভাবে |
| কুলার কপার | একইভাবে |
| পুরোনো প্যাড | স্প্যাজার দিয়ে তুলে, IPA দিয়ে মুছে |
| ধুলো | কমপ্রেসড এয়ার, বাইরে গিয়ে |

**সাবধান:** IPA ৯৯% লাগবে। ৭০% দিলে পানি থেকে যায়, আর সেটাই কার্ড নষ্ট করে। **সম্পূর্ণ শুকাতে ১০ মিনিট দেবে।**

### ④ নতুন প্যাড — কোথায় কত

| জায়গা | পুরুত্ব | কতটা |
|---|---|---|
| **সামনের VRAM চিপ** (১০টা) | **২.০ mm** | প্রতি চিপে কেটে |
| **সামনের MOSFET** | **১.০ mm** | সারি করে |
| **পেছনের VRAM চিপ** (১০টা) | **২.৫ mm** | ব্যাকপ্লেটের নিচে |
| **পেছনের MOSFET** | **১.০ mm** | সারি করে |

**প্যাড কাটার নিয়ম:** চিপের মাপে হুবহু কাটবে, একটু বড় নয়। বড় হলে অন্য চিপে চাপ পড়ে, কুলার ঠিক বসে না।

**একটা টিপস:** প্যাডের উপরে হালকা পেস্ট লাগালে তাপ আরও ভালো যায়।

### ⑤ GPU ডাইতে পেস্ট

- **মটরশুঁটির সমান** একটা ডট মাঝখানে
- ছড়াবে না — কুলার চাপলে নিজেই ছড়িয়ে যাবে
- **PTM7950 ব্যবহার করলে পেস্ট লাগবে না** — প্যাডটা কেটে বসাবে, আর এটা ৩০৯০-এর জন্য সবচেয়ে ভালো (একবার বসালে ৫ বছর টেকে)

### ⑥ বন্ধ করা

- কুলার সোজা নামাবে, স্ক্রু **X আকারে ক্রস করে টাইট করবে**
- একটার পর একটা, পুরো টাইট না করে — দুইবার ঘুরে সব টাইট
- ফ্যান কেবল লাগাতে ভুলো না
- ব্যাকপ্লেটের স্ক্রু
- **টাইট করার সময় জোরে টানবে না** — PCB ফাটে

### ধাপ ১ — মাদারবোর্ড বক্সের উপরে

মাদারবোর্ডটা বক্সের উপরে রাখবে, ভিতরের থলেতে। এতে স্ট্যাটিক লাগে না, আর নিচে কিছু ছোটে না।

### ধাপ ২ — প্রসেসর

- Socket-এর লক হ্যান্ডেল তুলবে
- **ত্রিভুজ চিহ্ন মিলিয়ে** বসাবে — কোণায় কোণায়
- **চাপ দেবে না** — নিজেই বসে যাবে
- হ্যান্ডেল নামাবে

### ধাপ ৩ — RAM

- **A2 আর B2 স্লটে** বসাবে (সাধারণত ২য় আর ৪র্থ) — মাদারবোর্ডের ম্যানুয়ালে দেখে
- ক্লিপ খুলে, দুই প্রান্তে সমান চাপ
- **ঠক করে শব্দ হবে** — না হলে বসেনি

### ধাপ ৪ — CPU কুলার

- পেস্ট লাগাবে (মটরশুঁটির সমান)
- ক্রস করে টাইট করবে
- ফ্যান কেবল **CPU_FAN** হেডারে

### ধাপ ৫ — NVMe SSD

- M.2 স্লটে, ৩০ ডিগ্রি কোণে ঢুকিয়ে, তারপর চাপ দিয়ে স্ক্রু
- **মডেলের SSD আগে** (৪TB), ডেটারটা পরে (২TB)

### ধাপ ৬ — ফ্রেম

- ওপেন-এয়ার ফ্রেম সমান জায়গায়
- মাদারবোর্ড ফ্রেমে স্ক্রু (স্ট্যান্ডঅফ দিয়ে)
- **পেছনের দিক খোলা রাখবে** — GPU-র গরম বাতাস বেরোবে

### ধাপ ৭ — PSU (দুইটা)

- দুইটা PSU ফ্রেমে, পেছনে
- **একটা GPU-দের জন্য, একটা বাকি সিস্টেমের জন্য**
- PSU কেবল **আগে থেকেই** গুছিয়ে রাখবে

### ধাপ ৮ — রাইজার

- ৩টা রাইজার মাদারবোর্ডের PCIe x16 স্লটে
- রাইজারের USB-এর মতো তারটা GPU-তে যাবে
- **PCIe 4.0 রাইজার লাগবে** — ৩.০ দিলে কাজ করবে, কিন্তু ধীর

### ধাপ ৯ — GPU বসানো

| ধাপ | কাজ |
|---|---|
| ১ | ফ্রেমে GPU-র জায়গা ঠিক করো, ফাঁক রেখে |
| ২ | রাইজারের তার GPU-তে লাগাও |
| ৩ | GPU-তে PSU-র ৮-পিন কেবল (প্রতি কার্ডে ২টা) |
| ৪ | **GPU সাপোর্ট স্ট্যান্ড** লাগাও — কার্ড ভারী |
| ৫ | GPU-র ফাঁকে আঙুল ঢুকবে কি না দেখো — তাপ বেরোবে |

**GPU-র ফাঁক:** দুই কার্ডের মাঝে অন্তত **৪ সেমি**। কম হলে উপরের কার্ডের গরম বাতাস নিচেরটা টেনে নেয়।

### ধাপ ১০ — কেবল গোছানো

| রং | কী |
|---|---|
| **লাল** | পাওয়ার |
| **নীল** | নেটওয়ার্ক |
| **হলুদ** | আর্থ |

- পাওয়ার আর CAT6 **কখনো একসাথে বাঁধবে না**
- প্রতি ৩০ সেমিতে বেল্ট

### ধাপ ১১ — প্রথম চালু (ফ্রেমেই, কেসে না)

- মনিটর HDMI/DP দিয়ে
- কীবোর্ড-মাউস USB-তে
- **GPU ছাড়া প্রথমে চালু করবে** — শুধু বোর্ড, CPU, RAM
- BIOS-এ ঢুকবে (Delete / F2)
- ঠিক থাকলে GPU বসাবে, আবার চালু

### ধাপ ১২ — PDU + UPS

- PDU-তে PSU দুইটা, মনিটর
- PDU → UPS → মেইন
- **সার্জ প্রোটেক্টর UPS-এর আগে**

## ৫. BIOS সেটআপ — চালু হয়ে যা করতে হবে

| সেটিং | মান | কেন |
|---|---|---|
| **Above 4G Decoding** | **Enabled** | ৩টা GPU-র জন্য জরুরি, না হলে একটা কাজ করবে না |
| **Resizable BAR** | Enabled | GPU মেমরি দ্রুত |
| **PCIe Speed** | **Gen3** | রাইজার Gen4 নাও নিতে পারে, Gen3 নিরাপদ |
| **CSM** | Disabled | UEFI বুটের জন্য |
| **Boot Mode** | UEFI | |
| **Boot Order** | NVMe আগে | |
| **Fan Control** | Full Speed | GPU-র ফাঁকে বাতাস চলবে |
| **XMP/DOCP** | Profile 1 | RAM পুরো গতিতে |

**Above 4G Decoding বাদ দিলে:** ৩টা GPU-র একটা চিনবে না, আর মডেল ওখানে বসবে না।

**X570 বোর্ডে:** BIOS আপডেট করতে হবে (F37 বা তার উপরে), নইলে Ryzen 5 5600 চিনবে না।
